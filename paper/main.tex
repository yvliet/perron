\begin{abstract}
Local developer agents must retrieve relevant code context within tight prompt budgets ($K \le 4{,}096$ tokens). While Personalized PageRank (PPR) over code dependency graphs is commonly deployed to discover unmentioned symbols, its empirical efficacy is widely debated. Through a systematic $2\times 2$ factorial evaluation on SWE-bench Lite ($N=237$) alongside a continuous dose-response surface across 186 prior configurations on SWE-bench Verified ($N=344$, 63,984 evaluations), I demonstrate that unconstrained PPR failure is driven primarily by \textbf{teleport prior dispersion} rather than scale-free hub absorption alone. Diffusion accuracy collapses onto an invariant dose-response curve governed by effective prior entropy support $n_{\text{eff}} = \exp(H(p_0))$ ($R^2 = 0.197$ binary logit cross-validation, with the analytical GLMM vertex at $n_{\text{eff}}^* \approx 8.8$ and the calibrated library default at $n_{\text{eff}} \approx 6.0$), with Two One-Sided Tests (TOST) showing no evidence of hub-presence harm within a sample-powered $\pm 9.3$ pp equivalence margin on hub-bearing tasks ($p < .001$, $N=109$). Under diffuse linear priors, PPR collapses to \FactLinRawStdFnAcc, whereas concentrating query priors via top-25 softmax ($\tau=0.15$) rescues standard PPR to \FactSoftSanStdFnAcc. \textbf{Perron} adapts stationary-normalized rooted PageRank via post-walk Decoupled Specificity ($\boldsymbol{\pi}_q / (\boldsymbol{\pi}_g + \epsilon)^\gamma$), providing an adaptive prior regularizer that rescues diffuse priors by +24.1 pp (\FactLinRawPerronFnAcc\ vs.\ \FactLinRawStdFnAcc) while restoring hub suppression to \VerifPerronStaticHSI\ (reducing hub contamination from \VerifStdPPRHubContam\ in Standard PPR to \VerifPerronStaticHubContam, matching lexical BM25's \VerifBMTwentyFiveHSI\ HSI). In a pre-registered confirmatory evaluation on SWE-bench Verified ($N=\VerifNumCallable$), Perron achieves \VerifPerronStaticFnAcc\ Function Acc@10, showing no statistically detectable difference from lexical BM25 at top-10 (\VerifBMTwentyFiveFnAcc, paired bootstrap difference $[-3.5, +2.3]$ percentage points, non-inferiority inconclusive against a $-2.0$ pp margin) while BM25 leads at top-5 retrieval (\VerifBMTwentyFiveFnAccFive\ vs.\ \VerifPerronStaticFnAccFive). In candidate context packing for Gemma 4 ($K \le 3{,}480$), lightweight AST breadcrumbs consume an average of \PromptPackAvgTokens\ words ($\sim 370\text{--}425$ SentencePiece BPE tokens), preserving \PromptPackReasoningHeadroom\ reasoning headroom for generation, with Perron achieving \PromptPackPerronTopFnAcc\ gold function inclusion vs.\ \PromptPackBMTwentyFiveTopFnAcc\ for BM25, and slot fusion balancing both (\PromptPackSlotTopFileAcc\ file, \PromptPackSlotTopFnAcc\ function). I release \texttt{perron-core} and \texttt{perron-mcp} under Apache 2.0.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Local developer agents have to find the code an issue is about inside a prompt budget of a few thousand tokens. Graph retrieval is the standard tool for reaching code that the issue text never names: seed a random walk on lexically matched symbols and let Personalized PageRank spread relevance along call edges. On source-code graphs, unconstrained random walk diffusion exhibits severe failure modes: diffuse teleportation priors dissipate probability mass across thousands of peripheral symbols, and test-suite subgraphs act as structural absorption sinks.

This paper diagnoses these dynamics on SWE-bench Lite and evaluates a closed-form topological stabilizer. The contributions are:
\begin{enumerate}
    \setlength{\itemsep}{1.5pt}
    \setlength{\parskip}{0pt}
    \item \textbf{Factorial diagnosis and continuous dose-response surface.} A $2\times 2$ factorial evaluation on SWE-bench Lite ($N=237$) and a continuous dose-response evaluation across 186 prior configurations on SWE-bench Verified (63,984 SpMM solves in 26~min) demonstrate that diffusion accuracy collapses onto an invariant curve governed predominantly by effective prior entropy support $n_{\text{eff}} = \exp(H(p_0))$, with Two One-Sided Tests confirming no detectable hub-presence penalty within a sample-powered $\pm 9.3$ pp equivalence margin on hub-bearing tasks (Section~\ref{sec:retrieval_benchmark} and Section~\ref{sec:dose_response}).
    \item \textbf{Decoupled specificity damping as an adaptive prior regularizer.} Adapting stationary-normalized rooted PageRank with exponent $\gamma$ ($\boldsymbol{\pi}_q / (\boldsymbol{\pi}_g + \epsilon)^\gamma$) acts as an adaptive prior regularizer: it provides an accuracy safety net under uncalibrated diffuse priors (+24.1 pp gain) while enforcing \VerifPerronStaticHSI\ hub suppression without mutating memory-mapped CSR storage (Section~\ref{sec:specificity}).
    \item \textbf{Pre-registered confirmatory evaluation.} On SWE-bench Verified ($N=\VerifNumCallable$), Perron achieves \VerifPerronStaticFnAcc\ Function Acc@10, yielding no statistically detectable difference compared to Okapi BM25 at top-10 (\VerifBMTwentyFiveFnAcc, paired difference $[-3.5, +2.3]$ pp; strict non-inferiority remains inconclusive against the pre-registered $-2.0$ pp margin), while BM25 maintains an advantage in top-5 retrieval (\VerifBMTwentyFiveFnAccFive\ vs.\ \VerifPerronStaticFnAccFive) (Section~\ref{sec:verified_evaluation}).
    \item \textbf{AST breadcrumb packing and open deliverables.} Candidate AST breadcrumb skeletons bound context occupancy to an average of \PromptPackAvgTokens\ words ($\sim 370\text{--}425$ BPE tokens), preserving \PromptPackReasoningHeadroom\ reasoning headroom for local developer agents. I release \texttt{perron-core} and \texttt{perron-mcp} under Apache~2.0 (Section~\ref{sec:resources}).
\end{enumerate}
Evaluation uses SWE-bench Lite~\cite{jimenez2024swebench} and SWE-bench Verified.

\subsection{Physical Hardware Envelope}
A central premise of developer agent democratization is enabling individual engineers to run agents locally on standard developer laptops without cloud API costs or private IP leakage.

Perron bounds the active per-turn working context to $K_{\text{effective}} = 3,480$ tokens ($K \le 4,096$). Measured on the reference laptop (\HostRAMGiB\ RAM, \HostAvailGiB\ available), the standalone engine peaks at \EnginePeakRSSMB\ resident memory, of which graph loading accounts for \EngineGraphLoadDeltaMB. Live execution of \texttt{gemma-4-e2b-it} (2B dense parameter model with native Per-Layer Embeddings, unquantized FP16 compute weights, SHA-256: \texttt{66fe83f1\dots}) was evaluated on an Nvidia Tesla T4 GPU under a Controlled Contrast Protocol across $N=100$ stratified tasks, consuming \GemmaPeakVRAMGiB\ peak generation VRAM with a mean Time-To-First-Token of \GemmaMeanTTFTMs\ and \GemmaDecodeTokensSec\ tokens/sec decode throughput. Transmission testing reveals $\kappa = 0.0$ due to unconstrained Chain-of-Thought reader truncation under a 256-token budget before emitting closing target tags (Section~\ref{sec:gemma4_packing}), confirming the operational necessity for decoupled reasoning and extraction budgets in compact edge models.

\subsection{The Topological Bottleneck: Scale-Free Dependency Graphs}
Source code dependency networks are scale-free graphs characterized by power-law degree distributions ($P(k) \sim k^{-\gamma}$). Ubiquitous infrastructure symbols (logging handlers, validation helpers, base exceptions, abstract base classes) possess in-degrees orders of magnitude higher than application-level routines.
When an agent initiates graph traversal from candidate nodes identified by dense semantic similarity:
\begin{enumerate}
    \item The search frontier encounters a hub node within 1 to 2 hops.
    \item Outgoing and incoming edges create an exponential branch explosion, pulling thousands of unrelated callers and callees into the retrieval pool.
    \item A standard 2-hop Breadth-First Search (BFS) on a 6,000-symbol codebase (such as SymPy) expands to over 2,500 nodes ($>$50,000 tokens), instantly overflowing the context window.
    \item Uniform degree truncation severs causal execution chains across multi-module boundaries.
\end{enumerate}

Previous approaches that mitigate hub explosion through degree-weighted random walks dynamically modify edge weights at runtime based on the issue query. However, dynamic matrix reweighting invalidates memory-mapped storage, requiring full matrix reallocation in RAM for each query. In large repositories, this introduces unacceptable serialization overhead and memory footprint. Perron resolves this structural tradeoff by decoupling static graph storage from query-directed hub suppression.

\section{Related Work}
\label{sec:related}
\textbf{Repository-Level Code Retrieval and Developer Agents}: Dense bi-encoders and lexical search engines (BM25) suffer from vocabulary mismatch and lack structural execution context. RepoCoder~\cite{zhang2023repocoder} showed that iterative retrieval loops improve completion but create multi-turn token inflation. AutoCodeRover~\cite{zhang2024autocoderover} navigates AST representations via iterative agent search queries. Aider~\cite{gauthier2023aider} introduced repository maps using PageRank over Tree-sitter tags; however, unconstrained PageRank amplifies global utility hubs, crowding out issue-specific definitions. Graph agents like RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent} employ multi-turn LLM reasoning over code graphs. In SWE-agent~\cite{yang2024sweagent}, custom ACI commands with immediate syntax feedback boost resolve rates by +10.7\% over bare shells. Agentless~\cite{xia2025agentless} demonstrated that hierarchical localization with test-filtered patch generation achieves 27.3\% on SWE-bench Lite without complex multi-turn loops. Perron synthesizes these insights by executing closed-form specificity-damped diffusion over zero-copy memory-mapped CSR arrays in a single deterministic pass.

\textbf{Graph-RAG and Random Walk Diffusion}: In information retrieval and graph learning, scalable diffusion builds on push-based approximate Personalized PageRank~\cite{andersen2006local}, decoupled propagation architectures such as APPNP~\cite{klicpera2019predict}, and scalable indexing frameworks like PPRGo~\cite{bojchevski2020scaling}. In link prediction, stationary-normalized rooted PageRank~\cite{liben2007link} discounts popular target nodes by global stationary reachability. HippoRAG~\cite{gutierrez2024hipporag} demonstrated that Personalized PageRank over knowledge graphs outperforms iterative retrieval, formulating node specificity as inverse passage frequency $s_i = |P_i|^{-1}$ applied as a pre-walk multiplier onto query teleport priors ($\mathbf{p}_0(i) \leftarrow \mathbf{p}_0(i) \cdot s_i$). However, in scale-free software call graphs, high in-degree hubs (e.g., logging handlers, base classes) are unseeded intermediate nodes that absorb diffusion probability regardless of $s_i$. Perron resolves this structural gap by decoupling the random walk from a post-walk stationary baseline ratio over zero-copy CSR matrices. Furthermore, Haveliwala and Kamvar~\cite{haveliwala2003second} proved that for any row-stochastic matrix $\bar{T}$ and rank-1 perturbation $M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top$, the spectrum satisfies $\lambda_1(M) = 1$ and $\lambda_i(M) = \beta \lambda_i(\bar{T})$ for all $i \ge 2$, so that the second eigenvalue satisfies $|\lambda_2(M)| \le \beta$ and power iteration converges at rate $\mathcal{O}(\beta^t)$ independently of graph structure.

\textbf{AST Subgraph Slicing and Fault Localization}: Classical program slicing~\cite{weiser1984program} computes backward executable slices on statement-level Program Dependence Graphs (PDGs). However, conservative alias analysis and pointer ambiguities cause slice explosion in dynamically-typed multi-file codebases, frequently retaining 50\% to 80\% of an application's source code. Spectrum-Based Fault Localization (SBFL)~\cite{pearson2017evaluating,zou2021empirical} evaluates test coverage matrices to score suspiciousness (e.g., Ochiai, Tarantula). Evaluating 395 faults (Pearson et al.~\cite{pearson2017evaluating}) and 357 faults (Zou et al.~\cite{zou2021empirical}) on Defects4J, empirical studies reported that SBFL requires executing hundreds of test cases (incurring multi-minute runtime) and produces tied suspiciousness ranks in over 40\% of localized statements due to identical coverage vectors along shared paths. Perron bypasses dynamic test execution during retrieval and implements context-budgeted AST subgraph slicing, extracting symbol-level multigraphs to pack causal execution scopes into tight prompt budgets ($K \le 4,096$) with high-throughput CPU diffusion (\ReqConvergeMs\ on Requests, \SymConvergeMs\ on SymPy).

\subsection{Multiplex Transition Matrix Construction}
A codebase is represented as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where $\mathcal{V}$ denotes AST code symbols (classes, functions, methods) and $\mathcal{E}$ spans multiple semantic relations $r \in \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$. Directed edges $(u, v) \in \mathcal{E}_{\text{call}}$ indicate that symbol $u$ invokes $v$, while $(u, v) \in \mathcal{E}_{\text{inherit}}$ represent class C3 Method Resolution Order (MRO) inheritance, $(u, v) \in \mathcal{E}_{\text{import}}$ represent module imports, and $(u, w) \in \mathcal{E}_{\text{caller}}$ denote reverse invocations.

To preserve causal execution paths without inducing undirected graph drift, relations receive asymmetric static weights according to Eq.~(\ref{eq:edge_weight}):
\begin{equation}
W_{uv} = \omega_{\text{call}} A^{(\text{call})}_{uv} + \omega_{\text{inherit}} A^{(\text{inherit})}_{uv} + \omega_{\text{import}} A^{(\text{import})}_{uv} + \omega_{\text{caller}} A^{(\text{caller})}_{uv},
\label{eq:edge_weight}
\end{equation}
where $\boldsymbol{\omega} = [0.50, 0.25, 0.15, 0.10]$ and $A^{(r)}_{uv} = \mathbb{I}((u, v) \in \mathcal{E}_r)$.

Let $D_u = \sum_{v} W_{uv}$ be the out-degree sum. The row-stochastic transition matrix $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ and dangling indicator vector $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ are defined in Eq.~(\ref{eq:stochastic_matrix}):
\begin{equation}
T_{uv} = \begin{cases} \frac{W_{uv}}{D_u}, & D_u > 0 \\ 0, & D_u = 0 \end{cases}, \quad d_u = \begin{cases} 1.0, & D_u = 0 \\ 0.0, & D_u > 0 \end{cases}.
\label{eq:stochastic_matrix}
\end{equation}

The graph structures are serialized into raw binary arrays on disk. At inference, memory-mapped ingestion via \texttt{numpy.load} with \texttt{mmap\_mode='r'} constructs the \texttt{scipy.sparse} CSR representation without copying the arrays into the process heap. Profiling across a synthetic graph of $|V|=10^6$ nodes and $|E|=7.4 \times 10^6$ edges (\CsrBinarySizeMB\ binary CSR) demonstrates that post-walk specificity ratio evaluation requires only $\mathcal{O}(|V|)$ vector arithmetic, whereas dynamic edge reweighting incurs a \ReweightMs\ transition reweighting overhead (\ReweightOverheadPct\ of diffusion runtime). Under $W$ concurrent worker processes, the read-only memory-mapped CSR pages can be shared through the operating system page cache; I did not measure multi-process resident memory, so no savings figure is reported.

\paragraph{Language-Agnostic CSR Multigraph Formulation}
Perron formulates repository diffusion over abstract directed multigraphs $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, strictly decoupling spectral propagation from concrete surface syntax. The production reference implementation (\texttt{perron/\allowbreak graph.py}) extracts AST call graphs via Python's standard library \texttt{ast.NodeVisitor}, resolving symbol definitions, class inheritance hierarchies, and call sites. Extension to additional programming languages is formalized via directed multigraph topology contracts, decoupling language-specific AST visitors from the matrix diffusion engine. Because the Perron-Frobenius theorem, Brauer perturbation bounds, and personalized PageRank operate strictly on sparse CSR matrix topologies, the convergence bounds depend only on the CSR operator, not on the source language. Polyglot extensibility is demonstrated via an architectural proof-of-concept smoke test for TypeScript (\texttt{perron/\allowbreak polyglot/\allowbreak treesitter.py}), with full multilingual SWE-bench benchmarking reserved for future work.

\subsection{Traceback-Augmented BM25 Teleportation Prior}
Given an issue description $q$ and candidate symbols $v \in \mathcal{V}$, lexical relevance is evaluated using candidate scoring (supporting zero-dependency Okapi BM25 and deterministic token overlap) over qualified symbol names, file paths, docstrings, and code bodies. The production engine (\texttt{perron/\allowbreak retriever.py}) provides complete Okapi BM25 scoring with exact traceback frame extraction, evaluated alongside competitive graph and lexical baselines in Section~\ref{sec:retrieval_benchmark}.

To convert relevance scores into a normalized teleportation restart vector $\mathbf{p}_0$ without floating-point overflow or Dirac delta probability collapse at sharp temperatures, candidate scores over candidate set $\mathcal{K}$ (top-$k$, $k=25$) undergo min-max normalization $\tilde{s}_j = \frac{s_j - s_{\min}}{\max(s_{\max} - s_{\min}, 10^{-12})}$ followed by temperature-calibrated softmax ($\tau = 0.15$) using shift constant $c = \max_{j \in \mathcal{K}} (\tilde{s}_j / \tau)$ in Eq.~(\ref{eq:p0_softmax}):
\begin{equation}
p_{\text{BM25}}(i) = \begin{cases} \frac{\exp\left(\frac{\tilde{s}_i}{\tau} - c\right)}{\sum_{j \in \mathcal{K}} \exp\left(\frac{\tilde{s}_j}{\tau} - c\right)}, & i \in \mathcal{K} \\ 0.0, & i \notin \mathcal{K} \end{cases}.
\label{eq:p0_softmax}
\end{equation}

Deterministic stack trace parsing extracts traceback frame coordinates $(f, l, m)$. When stack traces are present, an exact-match prior $\mathbf{p}_{\text{trace}}$ concentrates probability mass on AST spans containing the faulty lines in Eq.~(\ref{eq:p0_hybrid}):
\begin{equation}
\mathbf{p}_0 = \begin{cases} 0.50 \mathbf{p}_{\text{trace}} + 0.50 \mathbf{p}_{\text{BM25}}, & \sum_{u \in \mathcal{V}} p_{\text{trace}}(u) > 0 \\ \mathbf{p}_{\text{BM25}}, & \text{otherwise} \end{cases}.
\label{eq:p0_hybrid}
\end{equation}
This ensures $\sum_{u \in \mathcal{V}} p_0(u) = 1.0$ and strictly bounds entries within $[0, 1.0]$.

The retrieval benchmark in Table~\ref{tab:retrieval_benchmark} uses a simpler prior shared by every diffusion method: $p_0(v) = \max(s_v, 0) / \sum_u \max(s_u, 0)$ over BM25 scores (\texttt{benchmarks/\allowbreak baseline\_\allowbreak retrievers.py}). The softmax prior above, with $k=25$ and $\tau=0.15$, is the default of the \texttt{PerronRetriever} library.

\subsection{Sparse Personalized PageRank Diffusion}
Random walk diffusion models the propagation of bug relevance across call hierarchies. The Google transition operator $M$ with damping factor $\beta = 0.85$ is formulated in Eq.~(\ref{eq:google_matrix}):
\begin{equation}
M = \beta \cdot (T + \mathbf{d} \mathbf{p}_0^\top) + (1 - \beta) \cdot \mathbf{1} \mathbf{p}_0^\top.
\label{eq:google_matrix}
\end{equation}

\paragraph{Proposition 1 (Brauer Rank-1 Spectral Radius Bound \& Invariant Spectral Gap)}
\label{prop:spectral_gap}
The stationary probability vector $\boldsymbol{\pi}_{\text{query}}$ satisfies $\boldsymbol{\pi}_{\text{query}} = \boldsymbol{\pi}_{\text{query}} M$. By Brauer's rank-1 perturbation theorem~\cite{brauer1952limits,haveliwala2003second}, given the stochastic matrix $\bar{T} = T + \mathbf{d} \mathbf{p}_0^\top$ where $\bar{T} \mathbf{1} = \mathbf{1}$, the spectrum of the rank-1 perturbed operator $M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top$ satisfies $\lambda_1(M) = 1$ and $\lambda_i(M) = \beta \lambda_i(\bar{T})$ for all $i \ge 2$. Because $\bar{T}$ is row-stochastic, all eigenvalues lie within the unit disk ($|\lambda_i(\bar{T})| \le 1$). Consequently, even if $T$ possesses disconnected communicating classes or defective Jordan blocks, the second-largest eigenvalue is strictly bounded by $|\lambda_2(M)| \le \beta = 0.85$.

Consequently, the spectral gap is invariant as stated in Eq.~(\ref{eq:spectral_gap}):
\begin{equation}
1 - |\lambda_2(M)| \ge 1 - \beta = 0.15.
\label{eq:spectral_gap}
\end{equation}
This ensures a uniform geometric convergence rate $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance. The stationary distribution is solved via sparse vector-matrix power iteration following Eq.~(\ref{eq:power_iteration}):
\begin{equation}
\boldsymbol{\pi}^{(t+1)} = \beta \cdot (\boldsymbol{\pi}^{(t)} T) + \left(\beta \cdot (\boldsymbol{\pi}^{(t)} \mathbf{d}) + 1 - \beta\right) \cdot \mathbf{p}_0^\top.
\label{eq:power_iteration}
\end{equation}
When $\bar{T}$ has more than one closed communicating class (mutually recursive groups with no outgoing calls, or disconnected components), eigenvalue $1$ has multiplicity greater than one and the bound is attained: $|\lambda_2(M)| = \beta$. For two probability vectors the error $\mathbf{e}^{(t)} = \boldsymbol{\pi}^{(t)} - \boldsymbol{\pi}^{*}$ sums to zero, so $\mathbf{e}^{(t+1)} = \beta\,\mathbf{e}^{(t)}\bar{T}$ and $\|\mathbf{e}^{(t)}\|_1 \le \beta^{t}\|\mathbf{e}^{(0)}\|_1 \le 2\beta^{t}$, because $\bar{T}$ is row-stochastic and two distributions are at most $2$ apart in $L_1$. Reaching $\epsilon = 10^{-6}$ therefore takes at most $\lceil \ln(2/\epsilon)/\ln(1/\beta) \rceil = \SpectralMaxIter$ iterations. Algorithm~\ref{alg:perron} stops on the residual $\|\boldsymbol{\pi}^{(t+1)} - \boldsymbol{\pi}^{(t)}\|_1 < \epsilon$; since $\|\mathbf{e}^{(t)}\|_1 \le \|\boldsymbol{\pi}^{(t+1)} - \boldsymbol{\pi}^{(t)}\|_1 + \beta\|\mathbf{e}^{(t)}\|_1$, the stopped iterate lies within $\epsilon/(1-\beta) \approx 6.7 \times 10^{-6}$ of the fixed point. On real repository graphs the residual rule stops after \ReqPowerIters\ iterations on Requests (\ReqConvergeMs) and \SymPowerIters\ on SymPy (\SymConvergeMs).

\paragraph{Proposition 2 (Barycentric Convex Hull Placement \& Warping Bound)}
\label{prop:convex_hull}
Let $\mathbf{p}_0 = \sum_{i=1}^K w_i \mathbf{e}_{s_i}$ be any convex combination of query seed nodes with $w_i \ge 0$ and $\sum_{i=1}^K w_i = 1.0$. The stationary distribution $\boldsymbol{\pi}(\mathbf{p}_0)$ lies in the convex hull of the basis distributions:
\begin{equation}
\boldsymbol{\pi}(\mathbf{p}_0) = \sum_{i=1}^K \tilde{w}_i \boldsymbol{\pi}(\mathbf{e}_{s_i}) \in \operatorname{conv}\left(\{\boldsymbol{\pi}(\mathbf{e}_{s_i})\}_{i=1}^K\right),
\label{eq:convex_hull}
\end{equation}
where the mass-normalized barycentric weights $\tilde{w}_i$ satisfy:
\begin{equation}
\tilde{w}_i = \frac{w_i m_i}{\mathbf{w}^\top \mathbf{m}}, \quad \text{with basis mass } m_i = \|\mathbf{u}(\mathbf{e}_{s_i})\|_1 = \|(1-\beta) \mathbf{e}_{s_i} (I - \beta T)^{-1}\|_1.
\label{eq:barycentric_weights}
\end{equation}
Because transition operator $T$ is row-substochastic on directed multigraphs with dangling sinks ($\mathbf{d} \neq \mathbf{0}$), basis masses satisfy $1 - \beta \le m_i \le 1.0$. Consequently, the maximum coordinate warping ratio is bounded by:
\begin{equation}
\frac{\max_i m_i}{\min_j m_j} \le \frac{1}{1 - \beta} = \frac{1}{0.15} \approx 6.67.
\label{eq:warping_bound}
\end{equation}
This bound explains why unnormalized superposition incurs severe error on graphs with absorbing leaf sinks, whereas mass-normalized barycentric superposition is exact to machine precision ($L_1 \le 10^{-10}$).

\subsection{Decoupled Specificity Ratio Hub-Damping}
\label{sec:specificity}
Personalized PageRank accumulates probability mass on high-in-degree hub nodes due to graph topology. While HippoRAG~\cite{gutierrez2024hipporag} introduced pre-walk node specificity ($s_i = |P_i|^{-1}$) to scale the query teleport prior, pre-walk scaling cannot prevent unseeded intermediate hubs from absorbing probability mass during random walk transitions on scale-free graphs. To suppress structural popularity without mutating the static matrix $T$, Perron adapts stationary-normalized rooted PageRank~\cite{liben2007link} with an adjustable power-law exponent $\gamma_q$, establishing a repository-wide stationary baseline $\boldsymbol{\pi}_{\text{global}}$, computed once per codebase using a uniform prior $\mathbf{p}_{\text{uniform}} = \frac{1}{|V|} \mathbf{1}$.

For any query, the node-level Specificity Score is defined in Eq.~(\ref{eq:specificity}):
\begin{equation}
\text{Specificity}(v) = \frac{\pi_{\text{query}}(v)}{(\pi_{\text{global}}(v) + \epsilon)^{\gamma_q}},
\label{eq:specificity}
\end{equation}
where $\epsilon = 10^{-8}$. In the primary static configuration (\textbf{Perron Static}), the exponent is fixed at $\gamma_q = \gamma = 0.70$. In the query-adaptive variant (\textbf{Perron Adaptive}), the exponent $\gamma_q$ adjusts dynamically to candidate query teleport priors $\mathbf{p}_0$ according to Eq.~(\ref{eq:dynamic_gamma}):
\begin{equation}
\gamma_q = \gamma \cdot \left(1 - \frac{1}{2} \mathbb{I}(\eta_q \ge \tau_{\text{lex}})\right), \quad \eta_q = \frac{\max_{h \in \mathcal{H}_{25}} p_0(h)}{\max_{v \in \mathcal{V}} p_0(v)},
\label{eq:dynamic_gamma}
\end{equation}
where $\tau_{\text{lex}} = 0.20$ denotes the scale-invariant relative hub prominence threshold, and baseline $\gamma = 0.70$. When a query focuses on domain-specific leaves ($\eta_q < \tau_{\text{lex}}$), $\gamma_q$ defaults to the baseline exponent $\gamma = 0.70$, aggressively penalizing unseeded structural hubs. Conversely, when an issue query explicitly targets a central architectural class ($\eta_q \ge 0.20$), $\gamma_q$ is uniformly relaxed across the entire graph to $0.5 \gamma = 0.35$. Because $\gamma_q$ is relaxed uniformly across all symbols, it compresses the denominator dynamic range without inducing per-node denominator inversion on sub-unitary probabilities ($\pi_{\text{global}} < 1$), successfully preventing false-positive suppression of verified defect targets. Both configurations are benchmarked in Section~\ref{sec:verified_evaluation}.

\paragraph{Proposition 3 (Exact Asymptotic PMI Decomposition on Query Support)}
\label{prop:pmi_decomposition}
For any symbol $v$ on query support $\mathcal{V}_q^+ = \{v \in \mathcal{V} \mid \pi_{\text{query}}(v) > 0\}$, the log-transformed Specificity score satisfies:
\begin{equation}
\ln \text{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \text{PMI}(v; q) - \gamma \ln\left(1 + \frac{\epsilon}{\pi_{\text{global}}(v)}\right).
\label{eq:pmi_decomposition}
\end{equation}
For reachable symbols ($\pi_{\text{global}}(v) \gg \epsilon$), the residual $\mathcal{R}_\epsilon(v) = -\gamma \ln(1 + \epsilon / \pi_{\text{global}}(v))$ vanishes, yielding an exact convex log-linear interpolation between reachability ($\gamma=0$) and surprise ($\gamma=1$):
$\ln \text{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \text{PMI}(v; q)$.

Mathematically, in the stationary limit, the ratio $\pi_{\text{query}}(v) / \pi_{\text{global}}(v)$ maps directly to the likelihood ratio $P(V_\infty = v \mid Q = q) / P(V_\infty = v) = e^{\text{PMI}(v; q)}$. This pointwise mutual information interpretation assumes a uniform query prior over starting symbols, $P(Q=q) = 1/|\mathcal{V}|$, consistent with the uninformative stationary baseline $\boldsymbol{\pi}_{\text{global}}$. The sub-linear exponent $\gamma = 0.70$ acts as a power-law smoothed structural Inverse Document Frequency (IDF), analogous in structural discounting behavior to popularity-discounted random walks in bipartite recommender systems~\cite{zhou2010solving} and unigram frequency discounting in Word2Vec Skip-Gram negative sampling~\cite{mikolov2013distributed,levy2014neural}. The design choice that matters is decoupling: keeping the row-stochastic transition matrix $T$ strictly static, binary, and zero-copy in memory, while applying smoothed PMI popularity discounting in $\mathcal{O}(|\mathcal{V}|)$ time without runtime edge mutations or memory reallocation.

Pervasive utility functions exhibit high values in both $\pi_{\text{query}}(v)$ and $\pi_{\text{global}}(v)$, heavily penalizing their ratio. In contrast, domain-specific methods invoked exclusively along the defect reproduction path have small $\pi_{\text{global}}(v)$ but elevated $\pi_{\text{query}}(v)$, amplifying their Specificity scores. The sub-linear exponent $\gamma = 0.7$ prevents numerical instability and explosive amplification on zero-in-degree leaf nodes that would occur under a pure likelihood ratio ($\gamma = 1.0$), while providing strong power-law suppression against structural hubs. Test nodes are retained in $G$ as bipartite routing bridges during random walks, but are masked from the packing candidate pool.

\paragraph{Hub Suppression Index Formulation}
To rigorously evaluate resistance to scale-free hub context saturation, I formalize the Hub Suppression Index ($\text{HSI}$) for query $q$ across top-$K$ candidate rankings ($K=10$) in Eq.~(\ref{eq:hsi}):
\begin{equation}
\text{HSI}(q) = 1 - \frac{|\mathcal{R}_{10}(q) \cap \mathcal{H}_{25}|}{10},
\label{eq:hsi}
\end{equation}
where $\mathcal{R}_{10}(q)$ denotes the ordered set of top-10 retrieved AST symbols for query $q$, and $\mathcal{H}_{25}$ is the structural hub set defined in Eq.~(\ref{eq:hub_set}) comprising the top-25 highest in-degree symbols of transition operator $T$:
\begin{equation}
\mathcal{H}_{25} = \underset{S \subset \mathcal{V}, \, |S|=25}{\arg\max} \sum_{v \in S} \text{deg}_{\text{in}}(v).
\label{eq:hub_set}
\end{equation}
On SWE-bench Verified ($N=\VerifNumCallable$), Standard PPR places \VerifStdPPRHubContam\ of its top-10 candidate slots in $\mathcal{H}_{25}$ ($\text{HSI} = \VerifStdPPRHSI$), and HippoRAG-style pre-walk prior scaling ($\mathbf{p}_0'(v) \propto \mathbf{p}_0(v) / (\pi_{\text{global}}(v) + \epsilon)^\gamma$) yields $\text{HSI} = \VerifHippoHSI$. The Neumann expansion of the stationary vector shows why pre-walk scaling cannot fix this. Writing $m$ for the truncation order:
\begin{equation}
\boldsymbol{\pi} = (1-\beta)\,\mathbf{p}_0'^{\top}(I-\beta\bar{T})^{-1} = (1-\beta)\sum_{t=0}^{\infty}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t},
\qquad
\Big\|\boldsymbol{\pi} - (1-\beta)\sum_{t=0}^{m}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t}\Big\|_1 = \beta^{m+1}.
\label{eq:neumann}
\end{equation}
The reweighted prior $\mathbf{p}_0'$ enters every term, but term $t$ is the distribution of a $t$-step walk, and walks of length at least $t$ carry a fraction $\beta^{t}$ of the total mass ($\beta^{3} \approx 0.61$ at $\beta = 0.85$; mean walk length $\beta/(1-\beta) \approx 5.7$). Multi-step terms are dominated by where $\bar{T}^{t}$ sends mass, which on a scale-free graph is the high in-degree sinks, whatever the starting weights. Perron's post-walk ratio divides the converged $\boldsymbol{\pi}$ itself, so it rescales the contribution of every walk length at once and enforces \VerifPerronStaticHSI\ hub suppression. Algorithm~\ref{alg:perron} formalizes the end-to-end diffusion and packing pipeline.

\begin{algorithm}[t]
\caption{Perron Diffusion and Versioned Packing}
\label{alg:perron}
\begin{algorithmic}[1]
\REQUIRE Graph $G=(V, E)$, transition matrix $T$, stationary vector $\boldsymbol{\pi}_{\text{global}}$, query $q$, candidate scoring function $\text{Score}$, budget $K_{\text{effective}}$, exponent $\gamma_q$ (fixed at $\gamma=0.70$ in Perron Static; dynamically computed via Eq.~(\ref{eq:dynamic_gamma}) in Perron Adaptive).
\ENSURE Context subgraph $S \subset V$ with AST breadcrumbs.
\STATE $s_v \leftarrow \text{Score}(q, v)$ for all $v \in V$ \COMMENT{Supports BM25, token overlap, or dense cosine similarity}
\STATE $\mathcal{K} \leftarrow \text{top-}k(s, k=25)$
\STATE $c \leftarrow \max_{j \in \mathcal{K}} (s_j / \tau)$
\STATE Compute shift-invariant prior $\mathbf{p}_0$ via Eq.~(\ref{eq:p0_softmax})
\STATE $\boldsymbol{\pi}^{(0)} \leftarrow \mathbf{p}_0$
\REPEAT
    \STATE $\boldsymbol{\pi}^{(t+1)} \leftarrow \beta (\boldsymbol{\pi}^{(t)} T) + (\beta (\boldsymbol{\pi}^{(t)} \mathbf{d}) + 1 - \beta) \mathbf{p}_0$
\UNTIL{$\|\boldsymbol{\pi}^{(t+1)} - \boldsymbol{\pi}^{(t)}\|_1 < 10^{-6}$}
\STATE $\boldsymbol{\pi}_{\text{query}} \leftarrow \boldsymbol{\pi}^{(t+1)}$
\FOR{each $v \in V$}
    \STATE $\text{Specificity}(v) \leftarrow \pi_{\text{query}}(v) / (\pi_{\text{global}}(v) + \epsilon)^{\gamma_q}$
\ENDFOR
\STATE $\{C_1, \dots, C_m\} \leftarrow \text{Components}(\{v \mid \text{Specificity}(v) > 0\})$
\STATE Allocate component budgets $K_i \propto \sum_{u \in C_i} \text{Specificity}(u)$ s.t. $\sum K_i \le K_{\text{effective}}$
\STATE $S \leftarrow \text{VersionedPacking}(\{C_i\}, \{K_i\})$
\RETURN Subgraph $S$ with AST breadcrumbs
\end{algorithmic}
\end{algorithm}

\section{Systems Engineering Implementation}
\label{sec:system}

\subsection{Component-Budget Partitioning and Versioned Frontier Packing}
In SWE-bench, Jimenez et al.~\cite{jimenez2024swebench} observed that reference developer patches span an average of 1.7 files and 3.0 functions. Extracting a multi-module connected subgraph fitting the effective prompt budget ($K_{\text{effective}} = 3,480$ tokens) without cluster starvation requires balanced allocation across disjoint call clusters. Perron partitions positive-specificity candidate symbols into connected components $\{C_1, \dots, C_m\}$. Each component receives a proportional token budget according to Eq.~(\ref{eq:comp_budget}):
\begin{equation}
K_i = \max\left(K_{\text{min}}, \left\lfloor K_{\text{effective}} \cdot \frac{\sum_{u \in C_i} \text{Specificity}(u)}{\sum_{v \in V} \text{Specificity}(v)} \right\rfloor\right).
\label{eq:comp_budget}
\end{equation}

Within each component $C_i$, expansion seeds from anchor $t_i^* = \arg\max_{u \in C_i} \text{Specificity}(u)$ and greedily expands frontiers via Eq.~(\ref{eq:frontier_score}):
\begin{equation}
\text{score}(v) = \frac{\text{Specificity}(v)}{c(v)} \cdot \left(1 + \mu \cdot \min\left(1.0, \frac{|\text{edges}(v, S)|}{\text{deg}(v)}\right)\right),
\label{eq:frontier_score}
\end{equation}
where $c(v)$ is token cost including AST breadcrumb overhead, $S$ is the current set of selected symbols, $\text{deg}(v) = \text{deg}_{\text{in}}(v) + \text{deg}_{\text{out}}(v)$, and $\mu = 0.5$.

Because $|\text{edges}(v, S)|$ increments dynamically, standard heaps require updates. Python's \texttt{heapq} does not support \texttt{decrease\_key}. Perron uses a Versioned Heap Pattern:
\begin{samepage}
\begin{itemize}
    \setlength{\itemsep}{1pt}
    \setlength{\parskip}{0pt}
    \item Each node maintains an integer counter \texttt{version[v]}.
    \item When an edge to $S$ is formed, \texttt{version[v]} increments, and \texttt{(-score, v, version[v])} is pushed onto the heap.
    \item On pop, entries with $\texttt{entry\_version} < \texttt{version[v]}$ are discarded in $\mathcal{O}(1)$.
    \item Total heap updates are bounded by $\mathcal{O}(|E| \log |V|)$, avoiding full rescans.
\end{itemize}
\end{samepage}

\subsection{Hierarchical AST Breadcrumbs}
Extracting isolated method bodies without enclosing class context breaks Python scoping and variable binding. Perron traverses the AST to generate hierarchical breadcrumbs:
\begin{lstlisting}[language=Python]
class QuerySet:
    """QuerySet representation."""
    # ... [preceding methods omitted] ...
    def filter(self, **kwargs):
        ...
\end{lstlisting}
This keeps the edited block parseable, preserves indentation levels, and keeps \texttt{self} references intact.

\subsection{Shared Read-Only Graph Storage}
The transition matrix is stored as raw CSR arrays (\texttt{indices.npy}, \texttt{indptr.npy}, \texttt{data.npy}) and accessed via \texttt{numpy.load(mmap\_mode='r')}. Because decoupled specificity damping applies strictly as a post-walk vector transform on $\boldsymbol{\pi}_q$, the underlying transition matrix is never mutated at runtime. Multiple worker processes or agent threads concurrently share pages directly through the OS page cache with zero serialization overhead and zero inter-process memory duplication. Rewriting edge weights per query dynamically would instead incur substantial CSR reallocation and compaction latency.

\subsection{AST Context-Budgeted Breadcrumb Packing}
To deliver actionable localized context without exceeding prompt budgets ($K \le 4{,}096$), Perron packs candidate symbols using AST breadcrumb skeletons (\texttt{perron/packer.py}). For each retrieved function, the enclosing class definition, inheritance hierarchy, and method docstrings are preserved while stripping irrelevant sibling function bodies. Breadcrumb skeletons bound the context footprint to $<100$ tokens per symbol, preserving lexical scope, indentation levels, and \texttt{self} bindings while leaving the vast majority of the prompt budget available for language model reflection and generation.

\subsection{Topological Reachability and Relation-Stratified Null Models}
\label{sec:null_models}
To evaluate whether graph diffusion is constrained by ranking dynamics or structural disconnection, I analyzed multi-source Boolean reachability from lexical seeds across SWE-bench Verified ($N=\VerifNumCallable$ callable tasks). Lexical top-10 seeds directly hit \VerifBMTwentyFiveFnAcc\ (\VerifBMTwentyFiveFnAccKN) of gold target functions. Expanding along code graph edges to 1-hop reachability covers \ReachabilityOneHopPct\ of targets (199 of 344, median $|N_1|=\ReachabilityMedianNOne$), while expanding to 2 hops reaches \ReachabilityTwoHopPct\ (230 of 344, median $|N_2|=\ReachabilityMedianNTwo$ symbols). Structural expansion can therefore add at most $7.0\text{--}16.0$ percentage points over seeds, but requires ranking those targets against 27 to 324 candidate symbols. Pruning intermediate hubs reduces 2-hop reachability to \ReachabilityPrunedPct\ (214 of 344), while size-matched lexical expansion reaches \ReachabilityLexicalPct\ (186 of 344).

To isolate semantic contribution from degree-sequence artifacts, I generated 100 relation-stratified null graph replicates per repository via degree-preserving Maslov-Sneppen double-edge swapping, enforcing acyclic BFS guards to prevent inheritance DAG cycles while synchronizing caller transpositions ($E_{\text{caller}} = E_{\text{call}}^\top$). Null graph replicates yield \ReachabilityNullMeanPct\ 2-hop reachability. The empirical difference of $+3.02$ percentage points ($z_E = +\ReachabilityZScore$) corresponds to a paired risk difference with 95\% bootstrap confidence interval of $[-0.42, +6.41]$ pp (paired $t(343) = 1.740, p = 0.0828$), indicating that topological reachability is constrained largely by the degree sequence rather than high-order semantic organization.

Notably, same-file containment captures \ReachabilitySameFilePct\ (230 of 344), numerically matching 2-hop graph reachability. This parity is an exact symmetric discordance: the methods achieve 90.1 percent concordance (310 of 344 tasks), with 17 targets reached across files via 2-hop graph paths outside the seed files, perfectly offset by 17 targets located within seed files that lack static AST call edges within 2 hops. Structural graph reachability thus bounds retrieval capacity without providing an unconstrained shortcut over lexical and file-level heuristics.

As shown in Figure~\ref{fig:neff_dose_response}, retrieval accuracy collapses onto an invariant dose-response curve governed by prior effective support $n_{\text{eff}} = \exp(H(\mathbf{p}_0))$ across the operating regime $n_{\text{eff}} \in [4, 8]$, rather than by individual hyperparameter choices. To formalize this relationship, I fitted a binomial Generalized Linear Mixed Model:
\begin{equation}
\operatorname{logit} P(Y_{ij} = 1) = \beta_0 + \beta_1 \ln n_{\text{eff}} + \beta_2 (\ln n_{\text{eff}})^2 + a \ln k + b \ln \tau + \gamma_j,
\label{eq:glmm_dose_response}
\end{equation}
where $\gamma_j \sim \mathcal{N}(0, \sigma^2)$ is a per-task random intercept, $k$ is candidate pool cutoff, and $\tau$ is softmax temperature. The fit yields $\beta_1 = 0.325 \pm 0.035$ ($p < 0.001$), $\beta_2 = -0.075 \pm 0.007$ ($p < 0.001$), setting the analytical parabola optimum at $\ln(n_{\text{eff}}^*) = -\beta_1 / (2\beta_2) \approx 2.167 \implies n_{\text{eff}}^* \approx 8.7\text{--}8.8$ (\VerifBMTwentyFiveFnAcc\ hit rate). The calibrated operational default ($k=25, \tau=0.15 \implies n_{\text{eff}} \approx 6.035$, \VerifDegPPRFnAcc\ hit rate) sits intentionally on the conservative side of the broad plateau ($n_{\text{eff}} \in [4, 8]$) to minimize sink leakage. Candidate cutoff vanishes ($a = \DoseResponseCoeffA \pm 0.013$, $p = 0.536$) and temperature exerts minor residual sensitivity ($b = \DoseResponseCoeffB \pm 0.016$, $p = 0.023$). Task-level binary leave-one-family-out cross-validation yields pseudo-$R^2 = 0.197$ (while the aggregate dose-response curve exhibits tight collapse across prior families), confirming \textbf{Hypothesis H1} (Support Law): retrieval performance is governed primarily by effective support.

To test whether the functional form of the prior exerts independent influence beyond entropy, I evaluated \textbf{Hypothesis H2 (Iso-Entropy Contrast)}: paired comparisons between power-law and softmax priors matched on $n_{\text{eff}} \approx 6.0$ but divergent in support cutoff $k$ ($k=10$ vs.\ $k=50$) exhibit no significant divergence (paired McNemar $p\DoseResponseIsoEntropyPVal$, discordance rate of 8.9 percent).

Finally, I tested \textbf{Hypothesis H3 (Hub Impact and Equivalence)}: for tasks where structural hubs ($\mathcal{H}_{25}$) occupy top-10 slots under Standard PPR ($N=\DoseResponseHubSubtasks$), paired McNemar ($p\DoseResponseHubMcNemarPVal$, $n_{01}=4, n_{10}=2$) and sample-powered Two One-Sided Tests (TOST) show no evidence of defect localization harm within a $\pm 9.3$ pp equivalence margin ($p\DoseResponseHubTOSTPVal$). Across the full benchmark ($N=344$), equivalence holds within $\pm 5.0$ pp ($p < 0.001$; a tighter $\pm 3.0$ pp margin is unpowered, $p = 0.302$). Notably, graph diffusion achieves zero positive ranking lift over lexical seeds (seeds hit \VerifBMTwentyFiveFnAcc, while walks reach \VerifPerronStaticFnAcc). Hubs alter cosmetic candidate ranking without displacing gold defect targets. Perron's Decoupled Specificity serves primarily as a topological regularizer under diffuse teleportation (+24.1 pp gain under linear priors; Table~\ref{tab:factorial_benchmark}) and an aesthetic hub filter (\VerifPerronStaticHSI\ HSI), rather than an accuracy remedy for structural hub bias.

As detailed in Table~\ref{tab:verified_evaluation}, the confirmatory evaluation tests three pre-registered hypotheses:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Hypothesis P1 (Perron vs.\ Standard PPR at $\beta=0.85$)}: Difference $+0.3$ percentage points (\VerifPerronStaticFnAccKN\ vs.\ \VerifStdPPRFnAccKN, paired bootstrap CI $[-2.9, +3.5]$ pp, Holm $p = 1.000$). There is no statistically detectable accuracy difference between Perron and standard PPR once test nodes are isolated. Crucially, Standard PPR exhibits \VerifStdPPRHubContam\ hub contamination (HSI@10 = \VerifStdPPRHSI), whereas Perron sustains \VerifPerronStaticHSI\ hub suppression.
    \item \textbf{Hypothesis P2 (Perron Parity to BM25)}: Difference $-0.6$ percentage points with a 95\% paired bootstrap CI of $[-3.5, +2.3]$ percentage points. Because the lower bound crosses the pre-registered $-2.0$ pp non-inferiority margin, strict non-inferiority is \textbf{statistically inconclusive}. While top-10 point estimates are close (\VerifPerronStaticFnAcc\ vs.\ \VerifBMTwentyFiveFnAcc), strict non-inferiority cannot be asserted, and BM25 maintains an explicit advantage in top-5 function retrieval (\VerifBMTwentyFiveFnAccFive\ vs.\ \VerifPerronStaticFnAccFive, $\Delta = -4.7$ pp) and file retrieval (\VerifBMTwentyFiveFileAccFive\ vs.\ \VerifPerronStaticFileAccFive, $\Delta = -5.7$ pp).
    \item \textbf{Hypothesis P3 (Boundary Jitter and Fusion Failure)}: Of the \VerifNumCallable\ callable tasks on SWE-bench Verified, BM25 and Perron Static achieve concordant hits on \VerifCompBoth\ instances and concordant misses on \VerifCompBothMiss\ instances. Perron retrieves \VerifCompPerronOnly\ exclusive targets while BM25 retrieves \VerifCompBMOnly\ exclusive targets ($p = 0.8450$, two-sided McNemar). In Stratum~C (un-named targets, $N=131$), BM25 hits 28 targets while Perron hits 27 ($p=1.0000$, discordant: 2 Perron wins vs.\ 3 BM25 wins). While an unconstrained oracle union reaches \VerifOracleFnAccKN\ (\VerifOracleFnAcc), practical Reciprocal Rank Fusion ($k_0=60$) attains only \VerifRRFPRFnAccKN\ (\VerifRRFPRFnAcc), failing to surpass standalone BM25 (\VerifBMTwentyFiveFnAccKN). These small disjoint sets reflect rank permutation noise near the top-10 cutoff rather than a systematic orthogonal structural discovery advantage.
\end{itemize}

\subsection{Ablation Study}
To evaluate the contribution of individual mechanisms under controlled conditions:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Without Specificity Ratio ($\gamma = 0$)}: Perron at $\gamma=0$ reduces identically to Standard PPR. Under diffuse linear teleportation on raw graphs ($N=237$), unweighted diffusion collapses Function Acc@10 from \FactLinRawPerronFnAcc\ (\FactLinRawPerronHitsKN) to \FactLinRawStdFnAcc\ (\FactLinRawStdHitsKN, $\Delta = -24.1$ pp) as test-node contamination rises to \FactLinRawStdTestPct. On SWE-bench Verified ($N=\VerifNumCallable$), removing specificity weighting drops HSI@10 from \VerifPerronStaticHSI\ to \VerifStdPPRHSI\ (introducing \VerifStdPPRHubContam\ hub contamination), while top-10 accuracy remains at \VerifPerronStaticFnAcc\ vs.\ \VerifStdPPRFnAcc.
    \item \textbf{Without Graph Sanitization (Raw vs.\ Sanitized)}: Retaining un-sanitized test subgraphs under diffuse priors funnels random-walk mass into testing harnesses, reducing Function Acc@10 by 3.8 pp (\FactLinSanStdFnAcc\ vs.\ \FactLinRawStdFnAcc). Concentrating the teleport prior via top-25 softmax eliminates test-sink vulnerability even without structural pruning.
\end{itemize}

\section{Discussion and Limitations}
\label{sec:discussion}
While Perron acts as an invariant topological stabilizer under noisy priors and sustains robust hub suppression (\VerifPerronStaticHSI\ HSI), several limitations remain: (1)~static call graphs miss dynamic runtime dispatch, reflection (\texttt{getattr}), or monkey-patching; (2)~across disconnected modules, diffusion relies entirely on the teleport prior; (3)~structural diffusion alone does not outperform lexical BM25 on issue descriptions that explicitly quote target identifiers; (4)~while reader transmission was benchmarked on Gemma 4 E2B ($N=100$), unconstrained generative patch synthesis was not evaluated, as small-model reflection loops require higher generation budgets than the 256-token transmission envelope; and (5)~the reference engine targets Python AST; while an initial polyglot Tree-sitter interface smoke test is implemented for TypeScript (\texttt{perron/polyglot/treesitter.py}) to verify CSR protocol extensibility, large-scale multilingual SWE-bench evaluation remains an open research direction.

\section{Conclusion}
\label{sec:conclusion}
\enlargethispage{3.5\baselineskip}
On scale-free code graphs, Personalized PageRank collapse under default damping ($\beta=0.85$) is driven by teleport prior dispersion and test-node sink absorption. Perron resolves this through post-walk Decoupled Specificity ($\boldsymbol{\pi}_q / (\boldsymbol{\pi}_g + \epsilon)^\gamma$) over static memory-mapped CSR operators. In a pre-registered confirmatory evaluation on SWE-bench Verified (\VerifNumCallable\ callable tasks), Perron exhibits no statistically detectable difference from BM25 at top-10 (\VerifPerronStaticFnAcc\ vs.\ \VerifBMTwentyFiveFnAcc, non-inferiority inconclusive against a $-2.0$ pp margin). While their theoretical oracle union reaches \VerifOracleFnAcc\ (\VerifOracleFnAccKN), unrouted rank fusion fails to surpass standalone BM25, demonstrating that disjoint hits reflect top-10 boundary rank permutations rather than a systematic orthogonal structural discovery mechanism. The code, graphs, and reproduction harness are available at \url{https://github.com/yvliet/perron} and \url{https://www.kaggle.com/code/yvliet/perron-gemma-4-workstation}.
