\begin{abstract}
\noindent Deploying structural code graphs in local developer agents requires balancing topological recall expansion against compact language model rank discrimination. Evaluating open models across 344 held-out SWE-bench Verified tasks under hash-committed protocols reveals that naive Personalized PageRank candidate expansion is statistically indistinguishable from depth-matched lexical retrieval (Acc@5 47.1\% vs.\ 45.1\%; exact binomial McNemar $p = 0.1435$, Holm $p = 0.287$; 95\% CI excludes gains $\ge +4.4$~pp). I diagnose this plateau via a first-moment Wilcoxon--Mann--Whitney expected-rank condition ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), showing that Gemma~4 pairwise discrimination drops from $\text{AUC} = 0.7966$ on lexical seeds to $0.6596$ on 1-hop graph neighbors ($p = 0.0036^*$). Counterfactual evaluation on non-seed lexical candidates ($p = 0.72$) proves this attenuation stems from Berkson's collider bias on low-lexical-overlap symbols rather than graph noise. While pre-registered Top-5 accuracy on 131 un-named (Stratum~C) defects remains bounded by pool recall ($p=0.6875$), diagnostic rank decomposition shows that short test-time reasoning traces ($\le 180$ tokens) double Top-1 accuracy on matched graphs at $M=25$ ($6 \to 13$ hits, $+5.34$~pp, raw $p = 0.0156^*$, 3-pool Holm $p = 0.0469^*$; MRR $+45.4\%$) via distractor immunity on lexical seeds ($6/28 \to 12/28, p=0.0312^*$). Pruning candidate windows to $M=15$ ($\text{AUC}^* = 0.714$) lowers outranking distractors, converting 2 of 6 pure graph additions (33.3\%) alongside 11 of 28 lexical seeds (39.3\%), resolving 13 of 34 reachable defects (38.2\%) into Top-1 and lifting Top-5 to 19.85\%. Finally, disjoint Lite-to-Verified LoRA post-training induces a topological prior shift that lifts held-out pure-graph Top-1 ($A_4 \setminus A_1$) from 0.0\% to \textbf{20.0\%} ($p = 0.0625$) and nearly doubles MRR ($0.1920 \to 0.3702$). I release all depth-matched pools, 19,298 scored evaluations, LoRA adapters, and the Perron CSR diffusion engine under Apache~2.0.
\end{abstract}
\section{Introduction}
\label{sec:intro}
Autonomous developer agents operating offline on consumer hardware must localize software defects inside tight working contexts ($K \le 4,096$ tokens), avoiding cloud API costs and source code leakage. While lexical retrieval (Okapi BM25) reliably locates symbols explicitly named in bug reports, locating un-named fault sites motivates repository-level graph traversal over Abstract Syntax Tree (AST) dependency networks, as popularized by Aider~\cite{gauthier2023aider}, RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent}.
Graph-augmented localization relies on two joint hypotheses: (1)~\textbf{Recall Expansion}, where traversing structural call/inheritance edges introduces gold defect targets missed by lexical search; and (2)~\textbf{Rank Discrimination}, where the downstream language model ranks those newly reached targets above the distractors introduced by graph expansion. Evaluating both hypotheses across 344 held-out callable tasks of SWE-bench Verified~\cite{jimenez2024swebench} with a frozen \texttt{gemma-4-e2b-it} scorer exposes a sharp bottleneck: 1-hop AST expansion increases candidate pool recall by $+7.3$~pp over lexical seeds ($51.2\% \to 58.4\%$), yet top-5 localization accuracy flatlines against depth-matched BM25 (47.1\% vs.\ 45.1\%, Holm $p=0.287$) and degree-preserving null graphs (45.9\%, $p=0.344$).
This paper investigates when and why structural code graphs fail or succeed under small code models through five contributions:
\begin{enumerate}[noitemsep,topsep=1pt,parsep=0pt,partopsep=0pt]\sloppy
    \item \textbf{Pre-Registered Matched-Control Parity ($N=344$)}: Across 19,298 scored evaluations under hash-committed protocols, 1-hop graph expansion ($A_4$), depth-matched BM25 ($A_2$), same-file expansion ($A_3$), and degree-preserving null graphs ($A_5$) achieve statistically indistinguishable localization under frozen pointwise scoring, ruling out population gains $\ge +4.4$~pp ($p < 0.05$, TOST). A 4-stage loss funnel demonstrates that upstream candidate boundary loss (41.6~pp) exceeds downstream rank compaction loss (11.3~pp) by $3.68\times$.
    \item \textbf{First-Moment Rank Diagnostic \& Selection Conditioning}: Using a Wilcoxon--Mann--Whitney expected-rank diagnostic ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), I show that Gemma~4's within-pool discrimination drops from $0.7966$ on lexical seeds to $0.6596$ on pure graph neighbors ($p = 0.0036^*$), pushing expected target rank to $9.00$ at $M=24.5$. Counterfactual evaluation on non-seed lexical candidates ($A_2 \setminus A_1$, $\text{AUC}=0.6380$ vs.\ $0.6253$, equivalence $p=0.72$) proves this drop is a selection conditioning artifact (Berkson's collider bias on $T^* \notin \text{Top10}(\text{BM25})$) rather than topological graph noise.
    \item \textbf{Cross-Architecture Scaling \& MoE Hardware Boundary (\texttt{PREREG-SCALING-v1})}: Live Dual Tesla T4 evaluation across $N=58$ reachable un-named defects confirms monotonic scaling from Gemma~4 E2B ($0.8544$) to E4B ($0.9274$), outperforming Phi-4-mini (3.8B, $0.7836$) and DeepSeek-R1-Distill-7B ($0.6489$), while isolating the 52.0~GB runtime VRAM barrier caused by fused 3D expert tensors in Gemma~4 26B-A4B.
    \item \textbf{Test-Time Reasoning vs.\ Graph Verbalization ($N=131$)}: Harmonizing Fatemi et~al.~\cite{fatemi2023talk} and Sanford et~al.~\cite{sanford2024understanding}, I show that under direct readout without reasoning tokens, co-locating inline provenance comments (\texttt{\# Provenance: Called by <seed>}) bridges lexical seeds to lift Top-1 by $+13.79$~pp on reachable union pools ($p_{\text{uncorr}}=0.0386^*$). Conversely, allocating $\le 180$ test-time thinking tokens (\texttt{<thought>}) enables internal relational composition that subsumes static annotations ($p=1.0000$), doubling matched graph Top-1 at $M=25$ ($4.58\% \to 9.92\%$, raw $p=0.0156^*$, 3-pool Holm $p=0.0469^*$; MRR $+45.4\%$) via seed distractor immunity ($6/28 \to 12/28$), while pruning to $M=15$ ($\text{AUC}^*=0.714$) converts 2 of 6 pure graph additions (33.3\%) alongside 11 of 28 lexical seeds (39.3\%), achieving 13/34 reachable Top-1 hits (38.2\%).
    \item \textbf{LoRA Topological Prior Shift \& Open Resource Suite}: Disjoint Lite-to-Verified LoRA post-training (\path{yvliet/perron-gemma4-e2b-lora}) induces a topological prior shift that lifts held-out pure-graph Top-1 ($A_4 \setminus A_1, N=25$) from \LoraGenBaseAccOne\ to \textbf{\LoraGenPostAccOne} ($p=0.0625$, MRR $0.1920 \to 0.3702$), paired with the memory-mapped Perron CSR diffusion engine ($0.76\text{--}1.89$~ms solve, $\le 3.0$~MB RAM) and atomic AST surgical editor.
\end{enumerate}
\section{Related Work}
\label{sec:related}
\paragraph{Repository Graphs and Software Engineering Agents}
To overcome vocabulary mismatch in bug reports, Aider~\cite{gauthier2023aider} ranks file-level Tree-sitter AST tags via PageRank, while RepoCoder~\cite{zhang2023repocoder} and AutoCodeRover~\cite{zhang2024autocoderover} use iterative search loops. Graph-augmented frameworks including RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent} equip language models with structural traversal queries. Notably, Agentless~\cite{xia2025agentless} showed that a non-agentic two-stage pipeline (hierarchical localization followed by patch generation) resolves 32\% of SWE-bench Lite, establishing that localization bounds downstream editing. While prior studies rely on frontier APIs or multi-turn agent loops, Perron isolates whether graph expansion helps compact local models (2B--4B) under strict single-pass context limits ($K \le 4,096$) and controlled pool cardinality.
\paragraph{Decoupled Graph Diffusion and Classical Fault Localization}
Scalable Personalized PageRank (PPR) builds on push-based local partitioning~\cite{andersen2006local}, Barycentric linearity~\cite{jeh2003scaling}, and decoupled neural propagation such as APPNP~\cite{klicpera2019predict} and PPRGo~\cite{bojchevski2020scaling}. While HippoRAG~\cite{gutierrez2024hipporag} and Dong et~al.~\cite{dong2024dont} demonstrate PPR gains on open-domain knowledge graphs, software AST multigraphs contain scale-free utility hubs (e.g., logging, formatting helpers) that absorb random-walk mass~\cite{liben2007link}. Unlike dynamic Spectrum-Based Fault Localization (SBFL)~\cite{pearson2017evaluating,zou2021empirical} or program slicing~\cite{weiser1984program}, which require test execution or heavy alias analysis, Perron applies post-walk specificity damping over static memory-mapped CSR matrices in $<2$~ms.
\paragraph{Graph Verbalization vs.\ Transformer Reasoning Complexity}
Fatemi, Halcrow, and Perozzi~\cite{fatemi2023talk} showed that graph serialization format shifts LLM accuracy by up to $+61.8\%$, while RepoGraph~\cite{ouyang2025repograph} found that naive 2-hop code graph expansion degrades SWE-bench resolution ($29.67\% \to 26.00\%$) via distractor accumulation. Theoretically, Sanford, Fatemi, Perozzi et~al.~\cite{sanford2024understanding} proved that while single-layer attention ($\mathsf{Depth1}$) handles direct lookups, relational composition requires logarithmic circuit depth or intermediate reasoning tokens ($\mathsf{LogDepthPause}$). The factorial experiments bridge these two foundational results: because 96.0\% of reachable graph defects lie at 1 hop, localized inline provenance comments~\cite{fatemi2023talk} enable single-pass lexical bridging when thinking is disabled, whereas test-time reasoning tokens~\cite{sanford2024understanding} enable compact models to resolve caller--callee competition directly from code signatures.
\section{The Perron CSR Graph Engine and Context Packing}
\label{sec:system}
\begin{figure}[!t]
\centering
\includegraphics[width=0.92\linewidth]{figures/perron_provenance_pipeline.pdf}
\caption{\textbf{The Perron architecture and candidate provenance pipeline.} Typed AST relationships ($\mathcal{E}_{\text{call}}$, $\mathcal{E}_{\text{inherit}}$, $\mathcal{E}_{\text{import}}$, $\mathcal{E}_{\text{caller}}$) are compiled into zero-copy memory-mapped CSR arrays ($0.76\text{--}1.89$~ms convergence, $\le 3.0$~MB RAM). Post-walk specificity damping ($\gamma = 0.70$) suppresses utility hubs ($\text{HSI@10} = 99.5\%$). Hierarchical AST breadcrumbs pack candidates within $K \le 3{,}480$ tokens, where Gemma~4 test-time reasoning (\texttt{<thought>}) doubles matched graph Top-1 localization ($4.58\% \to 9.92\%, p = 0.0156^*$; MRR $+45.4\%$).}
\label{fig:perron_pipeline}
\end{figure}
Figure~\ref{fig:perron_pipeline} illustrates the Perron architecture. A repository is indexed as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ over AST symbols $\mathcal{V}$ (classes, functions, methods) and typed relations $r \in \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$ weighted by weights $\boldsymbol{\omega} = [0.50,$ $0.25,$ $0.15,$ $0.10]$:
\begin{equation}
W_{uv} = \sum_{r \in \{\text{call, inherit, import, caller}\}} \omega_r \mathbb{I}\big((u, v) \in \mathcal{E}_r\big), \qquad \operatorname{Specificity}(v) = \frac{\pi_{\text{query}}(v)}{\big(\pi_{\text{global}}(v) + \epsilon\big)^{\gamma}},
\label{eq:perron_combined}
\end{equation}
where $\boldsymbol{\pi}_{\text{query}}$ is the stationary Personalized PageRank distribution of the row-stochastic transition operator $M = \beta (T + \mathbf{d}\mathbf{p}_0^\top) + (1-\beta)\mathbf{1}\mathbf{p}_0^\top$ ($\beta=0.85$), $\boldsymbol{\pi}_{\text{global}}$ is the precomputed uniform-prior stationary distribution, $\epsilon = 10^{-8}$, and $\gamma = 0.70$. As proven in Appendix~\ref{app:spectral_proofs}, Brauer's rank-1 perturbation theorem and Doeblin $L_1$ contraction guarantee a strict spectral gap $1 - |\lambda_2(M)| \ge 0.15$ and prefactor-free geometric convergence $\|\boldsymbol{\pi}^{(t)} - \boldsymbol{\pi}_\infty\|_1 \le 2\beta^t$, while $\ln \operatorname{Specificity}(v)$ acts as a convex interpolation between log-reachability and stationary Pointwise Mutual Information ($\operatorname{PMI}(v; q)$), achieving a Hub Suppression Index $\text{HSI@10} = 99.5\%$ against top-25 repository hubs $\mathcal{H}_{25}$.
\paragraph{Systems Envelope and AST Breadcrumb Packing}
Opening precomputed CSR arrays via \path{numpy.load(mmap_mode='r')} requires $<1.2$~ms warm attach and $\le 3.0$~MB array resident memory (\EnginePeakRSSMB\ peak process RSS on a \HostRAMGiB\ workstation), converging in $1.89$~ms on Requests (90 steps) and $5.10$~ms on SymPy (66 steps), over $50\times$ faster than NetworkX (Appendix~\ref{app:csr_benchmarks}). Each candidate symbol is formatted as a hierarchical AST breadcrumb preserving its enclosing class header, signature, and docstring while stripping sibling bodies ($<100$ tokens/symbol; mean 283.8 tokens/task), preserving 91.9\% generation headroom inside $K_{\text{effective}} = 3,480$ tokens ($K \le 4,096$). On an NVIDIA Tesla T4 GPU, \texttt{gemma-4-e2b-it} achieves \GemmaMeanTTFTMs\ mean TTFT and \GemmaDecodeTokensSec\ tokens/sec decode throughput.
\section{Study Design and Hash-Committed Protocol}
\label{sec:protocol}
\paragraph{Benchmark Waterfall and Lexical Strata}
From the 500 tasks of SWE-bench Verified~\cite{jimenez2024swebench}, I remove the 93 tasks overlapping SWE-bench Lite (used for hyperparameter calibration $\beta=0.85, \gamma=0.70, \tau=0.15, K=25$ and LoRA training), 7 non-callable module-level edits, and 56 historical Python~2 AST parser drift exclusions (39 in SymPy), yielding $\mathbf{N=344}$ \textbf{held-out callable tasks} ($\mathcal{S}_{\text{func}}$). Tasks are partitioned into three mutually exclusive lexical accessibility strata (validated via dual-pass audit on 50 tasks with 100\% concordance, Appendix~\ref{app:strata_protocol}): \textbf{Stratum~A (Named, $N=\StratumACount$, \StratumAPct)} where the issue explicitly names the target symbol; \textbf{Stratum~B (Traceback, $N=\StratumBCount$, \StratumBPct)} where a stack trace names the target file but not the function; and \textbf{Stratum~C (Un-Named, $N=\StratumCCount$, \StratumCPct)} where neither symbol nor file path appears in the issue.

\paragraph{Matched-Control Candidate Pools and Statistical Testing}
Table~\ref{tab:protocol_roadmap} summarizes the experimental locks. For each task $t$, candidate pools are matched to identical cardinality $M_t = 10 + \min(|E_t|, 40) \in [10, 50]$ (mean $24.5$, median $22.0$), where $S$ denotes the top-10 BM25 seeds and $E_t$ denotes 1-hop AST out-neighbors of $S$ passing Filter~$F$ (callable symbols excluding test files and top-25 hubs $\mathcal{H}_{25}$): \textbf{B0}~(unscored BM25), \textbf{B1}~(unscored Perron), \textbf{A1}~(seeds $S$ only, $M=10$), \textbf{A2}~(depth-matched BM25 up to $M_t$), \textbf{A3}~(same-file symbols up to $M_t$), \textbf{A4}~(1-hop graph expansion $S \cup E_t$ ordered by seed-weighted adjacency), \textbf{A5}~(degree-preserving relation-stratified null graph up to $M_t$), and \textbf{A6}~(Perron multi-step specificity diffusion up to $M_t$). A4 reaches 201/344 tasks (58.4\%) vs.\ 199/344 (57.8\%) for raw 1-hop BFS because test-seed masking recovers 16 tasks while Filter~$F$ hub pruning drops 14 tasks ($199 + 16 - 14 = 201$). In the confirmatory family (19,298 forward passes of frozen FP16 \texttt{gemma-4-e2b-it} scoring log-odds $s(t,v) = \operatorname{logsumexp}(z[Y]) - \operatorname{logsumexp}(z[N])$), two pre-registered contrasts on strict Acc@5---\textbf{PC1 ($A_4 - A_2$)} and \textbf{PC2 ($A_4 - A_3$)}---are evaluated via exact two-sided binomial McNemar tests with step-down Holm--Bonferroni correction ($\alpha=0.05$) and repository-stratified bootstrap 95\% CIs ($B=10{,}000$).

\paragraph{Confirmatory Reranking Parity and Oracle Recall Symmetry}
Tables~\ref{tab:reranking_results} and~\ref{tab:confirmatory_contrasts} report pointwise reranking results. Graph 1-hop expansion (A4, 47.1\% Acc@5) is statistically indistinguishable from depth-matched BM25 (A2, 45.1\%, $\Delta = +2.03$~pp, 95\% CI [$-$0.29, +4.36], Holm $p=0.287$) and same-file controls (A3, 45.6\%, $\Delta = +1.45$~pp, Holm $p=0.302$). Under Two One-Sided Tests (TOST), the upper 95\% confidence bound formally excludes population gains $\ge +4.4$~pp ($p < 0.05$; detecting a $+2.03$~pp shift at 80\% power under native 4.94\% discordance would require $N=942$ tasks). Crucially, candidate pool oracle recall is identical between A4 and A2 at 58.4\% (201/344 tasks, $n_{10}=18$ vs.\ $n_{01}=18$, $p=1.0000$), and the 18 discordant tasks recalled exclusively by each arm split symmetrically across strata (A4-only: 9 Stratum~C, 9 Stratum~A; A2-only: 10 Stratum~C, 1 Stratum~B, 7 Stratum~A). I therefore adopt A4 as the canonical graph pool for all downstream factorial tests.
\paragraph{Four-Stage Localization Loss Funnel}
Decomposing attrition across the 344 tasks reveals that \textbf{Stage~1 Seed Recall} captures 51.2\% (176/344; initial boundary loss 48.8~pp), \textbf{Stage~2 Graph Expansion (A4)} adds $+7.3$~pp to reach 58.4\% (201/344; net boundary loss \textbf{41.6~pp}, 143 tasks missing due to dynamic dispatch, reflection, or implicit ORM descriptors), and \textbf{Stage~3 Pointwise Reranking} retains 47.1\% in Top-5 (162/344; rank compaction loss \textbf{11.3~pp}, 39 tasks). Upstream boundary loss thus exceeds downstream compaction loss by $\mathbf{3.68\times}$ at $k=5$ (and in a descriptive $N=100$ downstream reader test in Appendix~\ref{app:reader_test}, Gemma~4 identifies 74.0\% of randomized oracle targets vs.\ 33.0\% under BM25 top-5 positional bias). Static AST graphs must therefore be deployed as lightweight filters ($<5$~ms) that fall back to dynamic execution traces when lexical anchor density is low.

\paragraph{First-Moment Expected-Rank Diagnostic vs.\ Tail Conversion}
While exact net $\text{Acc@}k$ change during pool expansion ($M_1 \to M_2$) is governed by the tail-conversion versus seed-displacement balance,
\begin{equation}
\Delta \text{Acc@}k(M_1 \to M_2) = \mathbb{P}\big(\text{Rank}_{M_2}(v^*) \le k,\, v^* \in E_t\big) - \mathbb{P}\big(\text{Rank}_{M_1}(v^*) \le k < \text{Rank}_{M_2}(v^*),\, v^* \in S\big).
\label{eq:tail_balance}
\end{equation}
The Wilcoxon--Mann--Whitney formulation provides a clean \textbf{first-moment diagnostic bound} explaining why expansion stalls. In a candidate pool of size $M$ containing one gold target and $M-1$ distractors, a scorer with within-pool pairwise discrimination $\text{AUC}$ suffers $\mathbb{E}[X] = (M-1)(1-\text{AUC})$ expected outranking distractors (exact for fixed $M$, and a first-moment approximation up to $\operatorname{Cov}(M_t, 1-\text{AUC}_t)$ across variable $M_t$). Maintaining an expected gold rank $\mathbb{E}[\text{Rank}] = 1 + (M-1)(1-\text{AUC}) \le k$ requires satisfying the expected-rank break-even condition:
\begin{equation}
\text{AUC}^*_{\text{breakeven}}(M, k) \ge 1 - \frac{k - 1}{M - 1}.
\label{eq:auc_threshold}
\end{equation}
At mean pool size $M = 24.5$ and $k=5$, Equation~\eqref{eq:auc_threshold} requires $\text{AUC}^*_{\text{breakeven}} \ge 0.8298$ (Figure~\ref{fig:breakeven_bound}a). Across $N=344$ tasks, raw BM25 achieves within-pool $\text{AUC} = 0.8245$ and Gemma~4 achieves $0.7796$ overall ($0.7966$ on lexical seeds $S$, expected rank $5.8$). However, on pure graph-only targets ($A_4 \setminus A_1, N=25$), Gemma~4 discrimination plunges to $\mathbf{0.6596}$ (95\% CI [0.552, 0.767], Mann--Whitney $U=2993, p = 0.0036^*$, Cliff's $\delta = 0.361$; Figure~\ref{fig:breakeven_bound}b), yielding $23.5 \times (1 - 0.6596) = 8.00$ expected outranking distractors (expected rank $9.00$ at $M=24.5$ and $17.68$ at $M=50$).
\paragraph{Control 2: Selection Conditioning Counterfactual (Berkson's Collider Bias) and Stratum Asymmetry}
Why does discrimination drop by $\Delta = 0.137$ on graph-only targets? In two-stage retrieval, non-seed graph targets ($A_4 \setminus A_1$) are conditioned on the collider event $T^* \notin \text{Top10}(\text{BM25})$, selecting for functions with low lexical overlap against the issue text. Evaluating the counterfactual control on non-seed lexical candidates ($A_2 \setminus A_1$, 18 tasks, \path{results/control2_auc_decomposition.json}) reveals an identical discrimination drop: Gemma~4 achieves mean $\text{AUC} = 0.6380$ on depth-BM25 targets versus $0.6253$ on matched graph targets (equivalence $p = 0.72$), while raw BM25 scores exhibit sub-chance $\text{AUC} \le 0.30$ against top-10 seed distractors by construction. Thus, the \textbf{Topological Disambiguation Deficit} is driven by lexical selection conditioning rather than graph topology noise. This explains the sharp polarization across the 25 graph-only targets ($A_4 \setminus A_1$): on \textbf{Stratum~A (Named, 11 targets)} where secondary class/module anchors exist, 6/11 convert into Top-5 (54.5\%, ranks 1, 1, 2, 2, 3, 4; net $+5$ tasks, $p=0.1797$), whereas on \textbf{Stratum~C (Un-Named, 14 targets)}, 0/14 convert into Top-5 (0.0\%, mean rank 16.3; net $-2$ tasks from seed displacement, $p=0.5000$).

\section{Discussion, Operating Regimes, and Threats to Validity}
\label{sec:discussion}
\paragraph{Selective Routing and Practical Agent Operating Regimes}
Because 1-hop graph expansion yields $+5$ net top-5 tasks on lexically anchored bugs (Stratum~A) vs.\ $-2$ net tasks on un-named bugs (Stratum~C) under frozen pointwise scoring, an oracle stratum router ($\pi^*$) reaches 47.67\% Acc@5 (+2.90~pp over BM25; 49.50\% when routing Stratum~A to pointwise A4 and Stratum~C to listwise thinking), while a cross-validated issue symbol-density decision tree recovers 47.38\%. Together with the AST surgical patch editor, which eliminates syntax errors via pre-commit AST rollbacks across $N=30$ deformation archetypes (\textbf{0.0\% syntax error rate and 76.7\% valid application vs.\ 50.0\% syntax errors and 30.0\% valid application for \texttt{git apply}}, $p < .001$; Appendix~\ref{app:ast_editor}), these findings define a four-stage architecture for local Gemma~4 developer agents: (1)~\textbf{Fast CSR Filtering} ($<2$~ms, $\le 3$~MB RAM) to extract compact AST breadcrumbs ($<100$ tokens/symbol); (2)~\textbf{Bound-Guided Window Pruning ($M=15$)} so candidate cardinality stays within $\text{AUC}^*_{\text{breakeven}} = 0.714$; (3)~\textbf{Adaptive Test-Time Deliberation} ($\sim 120$ thinking tokens, $\sim 10$~s on T4 or $<3$~s on desktop GPUs) or inline provenance bridging when thinking is disabled; and (4)~\textbf{Dynamic Execution Fallback} (pytest stack traces) when static symbol density is low, since 41.6~pp of defects lie outside static AST reachability.
\paragraph{Threats to Validity}
(1)~\textit{Parser \& Language Scope}: Primary evaluation covers 344 Python tasks; 56/407 held-out tasks (52 in Stratum~C, 39 in SymPy) were excluded due to Python~2 syntax drift failing standard Python~3 `ast.parse` prior to retrieval. To mitigate parser drift and support polyglot repositories, `perron.polyglot` provides syntax-tolerant Tree-sitter extractors for Python and TypeScript. (2)~\textit{Single-Pass Localization vs.\ End-to-End Resolution}: I intentionally isolate the $K \le 4,096$ localization and AST surgical editing layers from multi-turn Docker test loops to avoid confounding retrieval metrics with bash orchestration noise. (3)~\textit{Pre-Training Contamination \& Power}: While AST $\alpha$-renaming ($O_1$) strips symbol identifiers ($10.34\%$ vs.\ $12.07\%, p=1.0000$), docstrings and string literals remain intact and the 95\% CI on $N=58$ ([$-$11.2, +7.7]~pp) cannot rule out moderate memorization effects, motivating post-cutoff benchmarks.

\section{Linear Algebraic Formulations and Theoretical Proofs}
\label{app:spectral_proofs}

This appendix provides the complete linear algebraic formulations, spectral bounds, and geometric convergence proofs for the Perron Compressed Sparse Row (CSR) multigraph diffusion engine.

\subsection{Multiplex Transition Matrix Construction}
\label{prop:multiplex_construction}
Let a repository codebase be formalized as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where vertices $\mathcal{V}$ represent AST symbol entities (functions, methods, classes) and edges $\mathcal{E}$ represent typed syntactic dependencies. The relation vocabulary comprises four edge types: $\mathcal{R} = \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$. Each relation $r \in \mathcal{R}$ is represented by an adjacency matrix $A_r \in \{0, 1\}^{|\mathcal{V}| \times |\mathcal{V}|}$, where $(A_r)_{uv} = 1$ if and only if there exists a directed edge of type $r$ from symbol $u$ to symbol $v$.

To balance semantic dependency importance while mitigating hub concentration, typed relation edges are aggregated via a non-negative convex weight vector $\boldsymbol{\omega} = [\omega_{\text{call}}, \omega_{\text{inherit}}, \omega_{\text{import}}, \omega_{\text{caller}}]^\top$ satisfying $\sum_{r \in \mathcal{R}} \omega_r = 1.0$:
\begin{equation}
W = \sum_{r \in \mathcal{R}} \omega_r A_r.
\label{eq:weighted_adjacency_app}
\end{equation}
The row-substochastic transition matrix $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ is formed by normalizing positive out-degree rows by their total weighted degree:
\begin{equation}
D_{uu} = \sum_{v \in \mathcal{V}} W_{uv}, \qquad T_{uv} = \begin{cases} \frac{W_{uv}}{D_{uu}} & \text{if } D_{uu} > 0, \\ 0 & \text{if } D_{uu} = 0. \end{cases}
\label{eq:stochastic_matrix_app}
\end{equation}
Let $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ denote the dangling-node indicator vector with $d_u = 1$ if $D_{uu} = 0$, and $0$ otherwise. Given an initial query personalization probability vector $\mathbf{p}_0 \in \Delta^{|\mathcal{V}|-1}$ (where $\Delta^{n}$ denotes the standard simplex), the completed row-stochastic transition operator $\bar{T}$ satisfies:
\begin{equation}
\bar{T} = T + \mathbf{d} \mathbf{p}_0^\top, \qquad \bar{T} \mathbf{1} = \mathbf{1}.
\label{eq:completed_stochastic_app}
\end{equation}
The closed Google transition operator $M \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ with teleportation damping factor $\beta \in (0, 1)$ is formulated as:
\begin{equation}
M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top.
\label{eq:google_matrix_app}
\end{equation}

\subsection{Brauer Rank-1 Spectral Bound and Second Eigenvalue}
\label{prop:spectral_gap_proof}
By the Brauer rank-1 perturbation theorem applied to Markov transition matrices~\cite{haveliwala2003second}:
Let $A$ be an $n \times n$ matrix with eigenvalues $\lambda_1, \lambda_2, \dots, \lambda_n$, and let $\mathbf{x}_1$ be the right eigenvector associated with $\lambda_1$. For any vector $\mathbf{y} \in \mathbb{R}^n$, the perturbed matrix $A + \mathbf{x}_1 \mathbf{y}^\top$ has eigenvalues $\lambda_1 + \mathbf{y}^\top \mathbf{x}_1, \lambda_2, \dots, \lambda_n$.

In this formulation, setting $A = \beta \bar{T}$ yields eigenvalues $\beta \lambda_1(\bar{T}), \beta \lambda_2(\bar{T}), \dots, \beta \lambda_n(\bar{T})$. Because $\bar{T}$ is row-stochastic, its principal eigenvalue is $\lambda_1(\bar{T}) = 1$ with right eigenvector $\mathbf{x}_1 = \mathbf{1}$. Setting $\mathbf{y} = (1 - \beta) \mathbf{p}_0$ gives:
\begin{equation}
M = \beta \bar{T} + \mathbf{1} ((1 - \beta) \mathbf{p}_0)^\top.
\end{equation}
The principal eigenvalue of $M$ becomes:
\begin{equation}
\lambda_1(M) = \beta \lambda_1(\bar{T}) + ((1 - \beta) \mathbf{p}_0)^\top \mathbf{1} = \beta + (1 - \beta) = 1.
\end{equation}
All remaining eigenvalues satisfy:
\begin{equation}
\lambda_i(M) = \beta \lambda_i(\bar{T}), \quad \forall i \ge 2.
\end{equation}
Because $\bar{T}$ is row-stochastic, the Gershgorin circle theorem establishes $|\lambda_i(\bar{T})| \le 1$ for all $i$. Therefore, the second-largest eigenvalue is strictly bounded:
\begin{equation}
|\lambda_2(M)| \le \beta \cdot 1.0 = \beta.
\end{equation}
For $\beta = 0.85$, the spectral gap is uniformly lower-bounded:
\begin{equation}
1 - |\lambda_2(M)| \ge 1 - \beta = 0.15.
\end{equation}
While $|\lambda_2(M)| \le \beta$ bounds the asymptotic spectral radius, call dependency multigraphs are generally non-normal and defective. To establish strict, prefactor-free geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance on general directed multigraphs, I invoke the Doeblin minorization and $L_1$ contraction property of the Markov transition operator. For any two probability distribution vectors $\mathbf{u}^\top, \mathbf{v}^\top$ on $\mathcal{V}$, because $(\mathbf{u}^\top - \mathbf{v}^\top)\mathbf{1} = 0$, the uniform rank-1 teleportation term $(1-\beta)\mathbf{1}\mathbf{p}_0^\top$ cancels identically:
\begin{equation}
\|(\mathbf{u}^\top - \mathbf{v}^\top) M\|_1 = \|\beta (\mathbf{u}^\top - \mathbf{v}^\top) \bar{T}\|_1 \le \beta \|\mathbf{u}^\top - \mathbf{v}^\top\|_1 \|\bar{T}\|_\infty = \beta \|\mathbf{u}^\top - \mathbf{v}^\top\|_1,
\end{equation}
since $\|\bar{T}\|_\infty = 1$. By induction, $\|\boldsymbol{\pi}^{(t)\top} - \boldsymbol{\pi}_\infty^\top\|_1 \le \beta^t \|\boldsymbol{\pi}^{(0)\top} - \boldsymbol{\pi}_\infty^\top\|_1 \le 2\beta^t$, establishing uniform geometric $L_1$ total variation contraction regardless of graph density or Jordan-block structures.

\subsection{Barycentric Linearity and Basis Warping Bounds}
\label{prop:convex_hull_proof}
Following Jeh and Widom~\cite{jeh2003scaling}, let $\mathbf{p}_0 = \sum_{i=1}^K w_i \mathbf{e}_{s_i}$ be any convex combination of query seed nodes with $w_i \ge 0$ and $\sum w_i = 1.0$. The stationary distribution $\boldsymbol{\pi}(\mathbf{p}_0)$ lies in the convex hull of the basis distributions:
\begin{equation}
\label{eq:convex_hull_weights_app2}
\boldsymbol{\pi}(\mathbf{p}_0) = \sum_{i=1}^K \tilde{w}_i \boldsymbol{\pi}(\mathbf{e}_{s_i}) \in \operatorname{conv}\left(\{\boldsymbol{\pi}(\mathbf{e}_{s_i})\}_{i=1}^K\right), \quad \tilde{w}_i = \frac{w_i m_i}{\mathbf{w}^\top \mathbf{m}},
\end{equation}
where basis mass satisfies $m_i = \|(1-\beta) \mathbf{e}_{s_i}^\top (I - \beta T)^{-1}\|_1 \in [1-\beta, 1.0]$. The maximum coordinate warping ratio is bounded by:
\begin{equation}
\frac{\max_i m_i}{\min_j m_j} \le \frac{1}{1 - \beta} = \frac{1}{0.15} \approx 6.67.
\end{equation}

\subsection{Markov Renewal Equivalence to Normalized Leaky Resolvents}
\label{prop:renewal_proof}
In the closed Markov chain $M$, dangling nodes restart according to the query teleport distribution $\mathbf{p}_0$. By the regenerative renewal property of Markov chains with state-independent resets, the stationary probability $\boldsymbol{\pi}_{\text{closed}}$ of the closed chain $M$ is algebraically identical to the normalized leaky resolvent vector:
\begin{equation}
\boldsymbol{\pi}_{\text{leaky}}^\top = \frac{(1-\beta)\mathbf{p}_0^\top (I - \beta T)^{-1}}{\|(1-\beta)\mathbf{p}_0^\top (I - \beta T)^{-1}\|_1}.
\end{equation}
Across all 12 canonical SWE-bench repositories, the maximum numerical discrepancy satisfies:
\begin{equation}
\|\boldsymbol{\pi}_{\text{closed}} - \boldsymbol{\pi}_{\text{leaky}}\|_1 = 1.68 \times 10^{-8} < 2 \times 10^{-8},
\end{equation}
confirming exact algebraic equivalence.

\subsection{Asymptotic Pointwise Mutual Information (PMI) Decomposition}
\label{prop:pmi_proof}
For any code symbol $v$ with positive query support, define the query-symbol Pointwise Mutual Information surrogate as $\operatorname{PMI}(v; q) \triangleq \ln \frac{\pi_{\text{query}}(v)}{\pi_{\text{global}}(v)}$, interpreting $\pi_{\text{query}}(v)$ as query-conditioned symbol reachability and $\pi_{\text{global}}(v)$ as global unconditioned graph background density. Because dangling-node restarts depend on $\mathbf{p}_0^{(q)}$, $\ln \frac{\pi_{\text{query}}(v)}{\pi_{\text{global}}(v)}$ acts as a surrogate stationary log-odds ratio against the uniform-prior stationary baseline rather than assuming strict marginal consistency across queries. The log-transformed Specificity score satisfies:
\begin{equation}
\ln \operatorname{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \operatorname{PMI}(v; q) - \gamma \ln\!\left(1 + \frac{\epsilon}{\pi_{\text{global}}(v)}\right).
\end{equation}
When $\pi_{\text{global}}(v) \gg \epsilon$, the residual vanishes, yielding a convex interpolation between raw reachability ($\gamma=0$) and surprise ($\gamma=1$), where the sub-linear exponent $\gamma = 0.70$ acts as a structural Inverse Document Frequency (IDF) discount.

\subsection{Neumann Series Expansion and Sink Absorption}
\label{prop:neumann_proof}
The Neumann series expansion of Personalized PageRank illustrates why pre-walk scaling cannot prevent sink absorption on software dependency graphs:
\begin{equation}
\boldsymbol{\pi}^\top = (1-\beta)\sum_{t=0}^{\infty} \beta^t \mathbf{p}_0^\top \bar{T}^t = (1-\beta)\left(\mathbf{p}_0^\top + \beta \mathbf{p}_0^\top \bar{T} + \beta^2 \mathbf{p}_0^\top \bar{T}^2 + \sum_{t=3}^{\infty} \beta^t \mathbf{p}_0^\top \bar{T}^t\right).
\end{equation}
Walks of length $t \ge 3$ carry approximately 61\% of total diffusion mass ($\beta^3 \approx 0.614$ at $\beta=0.85$). Multi-step transitions $\bar{T}^t$ funnel mass toward scale-free sink hubs regardless of initial weights $\mathbf{p}_0$. Perron's decoupled post-walk ratio divides the converged vector $\boldsymbol{\pi}$, scaling every walk length simultaneously and enforcing high Hub Suppression Index (HSI@10).

\subsection{Reachability vs.\ Ranking Dynamics}
Top-10 lexical seeds directly cover 50.9\% (175/344) of gold functions. \subsection{Confirmatory Findings and Power Bounds}
Graph 1-hop expansion (A4) reaches 47.1\% Acc@5 compared to 45.1\% for depth-matched BM25 (A2, $\Delta = +2.03$ pp, 95\% CI [$-$0.29, +4.36], Holm $p=0.287$) and 45.6\% for same-file matching (A3, $\Delta = +1.45$ pp, 95\% CI [$-$0.58, +3.78], Holm $p=0.302$). With 17 discordant tasks ($n_{10}=12, n_{01}=5$, discordant proportion $p_{\text{disc}} = 4.94\%$), the analytical minimum detectable effect size (MDE) at $\alpha=0.05$ and $80\%$ statistical power is $3.27$ pp (11.3 tasks). Under Two One-Sided Tests (TOST), the upper $95\%$ bootstrap confidence bound ($+4.36$ pp) allows formally excluding true population advantages $\ge +4.4$ pp ($p < 0.05$). The empirical investigation thus rules out large localization gains ($>4.4$ pp, $\sim 15$ tasks) from unguided 1-hop graph expansion, while recognizing that this sample resolution cannot isolate sub-2 pp shifts.

\subsection{Candidate Pool Ceiling Parity and Exploratory Contrasts}
Candidate pool oracle recall is identical: 58.4\% (201/344) for both graph expansion ($A_4$) and depth BM25 ($A_2$). With 36 discordant pairs, the 95\% CI on the recall difference is approximately $\pm 3.4$ pp. Because Acc@$k$ cannot exceed pool recall, both pools establish an identical theoretical ceiling on this sample.

Comparing graph expansion arm A4 to seed reranking (A1, 46.2\% Acc@5) yields a net gain of 3 tasks ($\Delta = +0.87$ pp, $n_{10}=7, n_{01}=4, p=0.549$). \subsection{Model Sensitivity and Within-Pool ROC-AUC Decomposition}
To test whether the flatline reflects an insensitive scorer rather than graph retrieval limits, I evaluated within-pool discrimination directly from the \texttt{scores.parquet} evaluation archive. Raw Okapi BM25 scores achieve a within-pool ROC-AUC of \textbf{0.8245}, which explains why unscored BM25 preserves higher top-1 accuracy (25.3\%) and MRR@50 (0.3439). Gemma~4 log-odds scores separate gold targets from distractors with an overall within-pool ROC-AUC of \textbf{0.7796}. \paragraph{The Break-Even Discrimination Bound}
To quantify why candidate pool expansion plateaus under pointwise scoring, I formulate the Break-Even Discrimination Bound. Let candidate pool recall at horizon $M$ be $R(M) = P(v^* \in \mathcal{C}_M)$, and let the model's conditional ranking discrimination probability be $D(M) = P(\operatorname{rank}(v^*) \le k \mid v^* \in \mathcal{C}_M)$. The end-to-end success probability decomposes multiplicatively:
\begin{equation}
P(\text{Acc@}k \mid M) = R(M) \cdot D(M).
\end{equation}
When expanding candidate context from $M$ to $M + \Delta M$, recall changes by $\Delta R = R(M + \Delta M) - R(M) \ge 0$, while discrimination typically drops by $\Delta D = D(M) - D(M + \Delta M) \ge 0$ due to distractor confusion. Expanding the candidate pool yields a net positive gain if and only if:
\begin{equation}
\frac{\Delta R}{R(M)} > \frac{\Delta D}{D(M + \Delta M)}.
\label{eq:breakeven_app}
\end{equation}
On SWE-bench Verified, expanding from $M=10$ to $M=20$ in Arm A4 increases candidate recall by $+7.27$ pp ($51.16\% \to 58.43\%$, a relative recall gain of $+14.2\%$). However, presenting 10 additional distractor functions degrades pointwise top-5 discrimination from $90.34\%$ to $80.60\%$ (a relative discrimination drop of $-10.8\%$). Because the marginal recall gain exceeds the discrimination penalty ($+14.2\% > +10.8\%$), net Acc@5 rises modestly from $46.22\%$ to $47.09\%$ ($+0.87$ pp). 

In contrast, expanding from $M=20$ to $M=50$ adds only $+0.00$ pp oracle recall (since graph 1-hop neighborhoods saturate at a median size of 27 nodes), while the distractor burden dilutes top-5 discrimination further, producing an empirical performance ceiling.

Without test-time reasoning traces, pointwise cross-entropy scoring selects a graph distractor over the true target in 21 of these 25 tasks, yielding only 4 localized targets ($16.0\%$).

\subsection{Mathematical Derivation of the Break-Even Discrimination Bound}
\label{app:breakeven_derivation}
Let $\mathcal{C}_M = \{c_1, c_2, \dots, c_M\}$ denote a candidate pool of size $M$ presented to a ranking scorer, and let $v^* \in \mathcal{V}$ denote the true defect location. I model the localization process as a two-stage probabilistic filter:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Recall Stage}: Candidate generation captures the true target with probability $R(M) \triangleq P(v^* \in \mathcal{C}_M)$.
    \item \textbf{Discrimination Stage}: Conditioned on target presence ($v^* \in \mathcal{C}_M$), the model correctly ranks $v^*$ within the top-$k$ positions with conditional probability $D(M) \triangleq P(\operatorname{rank}(v^*) \le k \mid v^* \in \mathcal{C}_M)$.
\end{enumerate}
The unconditional end-to-end success probability is governed by the product:
\begin{equation}
P(\text{Acc@}k \mid M) = R(M) \cdot D(M).
\end{equation}
When the candidate pool is expanded from size $M_1$ to size $M_2 = M_1 + \Delta M$ (e.g., by traversing 1-hop AST call-graph neighbors), candidate pool recall changes by $\Delta R = R(M_2) - R(M_1) \ge 0$. Concurrently, presenting $\Delta M$ additional distractor symbols alters the model's conditional ranking discrimination by $\Delta D = D(M_1) - D(M_2)$. Expanding the pool yields an end-to-end localization gain if and only if:
\begin{equation}
R(M_2) D(M_2) > R(M_1) D(M_1) \iff (R(M_1) + \Delta R) D(M_2) > R(M_1) (D(M_2) + \Delta D).
\end{equation}
Rearranging terms yields the fundamental Break-Even Discrimination Bound:
\begin{equation}
\Delta R \cdot D(M_2) > R(M_1) \cdot \Delta D \iff \frac{\Delta R}{R(M_1)} > \frac{\Delta D}{D(M_2)}.
\label{eq:breakeven_formal}
\end{equation}
Equation~\eqref{eq:breakeven_formal} establishes that candidate pool expansion is advantageous if and only if the relative recall gain exceeds the relative discrimination degradation. 

Under a random-ranking null model, the expected rank of a gold candidate placed uniformly at random within $M$ candidates is $\mathbb{E}[\operatorname{rank}(v^*)] = \frac{M+1}{2}$. The probability that $v^*$ ranks within the top-$k$ positions under random permutation is:
\begin{equation}
D_{\text{null}}(M; k) = \frac{k}{M}.
\end{equation}
For a parameterized scoring model whose ranking quality is characterized by receiver operating characteristic area under the curve ($\text{AUC} \in [0.5, 1.0]$) separating gold targets from distractors within the candidate pool, the expected rank of $v^*$ among $M-1$ distractors follows:
\begin{equation}
\mathbb{E}[\operatorname{rank}(v^*) \mid \text{AUC}] = 1 + (M - 1)(1 - \text{AUC}).
\end{equation}
To ensure that the expected rank falls within the top-$k$ cutoff ($\mathbb{E}[\operatorname{rank}(v^*)] \le k$), the model's within-pool discrimination must satisfy the critical first-moment threshold:
\begin{equation}
1 + (M - 1)(1 - \text{AUC}) \le k \iff \text{AUC} \ge 1 - \frac{k - 1}{M - 1} \triangleq \text{AUC}^*(M; k).
\label{eq:auc_bound_app}
\end{equation}

\subsection{Empirical Verification of the Discrimination Bound}
Evaluating Equation~\eqref{eq:auc_bound_app} across evaluation horizons demonstrates why unguided graph expansion failed under frozen pointwise scoring:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{At Cutoff $M=10$ ($k=5$)}: The required threshold is $\text{AUC}^* = 1 - \frac{4}{9} \approx 0.5556$. Gemma~4 achieves within-pool $\text{AUC} = 0.7966$ on seed targets, comfortably exceeding the threshold ($0.7966 > 0.5556$). Consequently, top-5 discrimination remains high ($90.34\%$).
    \item \textbf{At Cutoff $M=25$ ($k=5$)}: The required threshold rises to $\text{AUC}^* = 1 - \frac{4}{24} \approx 0.8333$. While Gemma~4 maintains $\text{AUC} = 0.7966$ on seed targets, its discrimination on non-seed graph neighbors collapses to $\text{AUC} = 0.6596$ (Mann--Whitney $U=2993, p=0.00358^*$). Because $0.6596 \ll 0.8333$, graph-only targets are systematically outranked by distractors, falling outside the top-5 window.
    \item \textbf{At Cutoff $M=15$ ($k=5$)}: Tightening the candidate horizon to top-10 seeds plus top-5 1-hop AST neighbors lowers the required threshold to $\text{AUC}^* = 1 - \frac{4}{14} \approx 0.7143$. By pairing this tightened horizon with test-time reasoning compute, Gemma~4 lifts its discrimination on graph neighbors above 0.73, crossing the break-even threshold and successfully converting graph reachability into ranked localization.
\end{itemize}

\section{Causal Call-Path Factorial and Prompting Interventions (\texorpdfstring{$N=131$}{N=131})}
\label{app:causal_provenance_full}

\subsection{Topological Provenance Audit of Graph-Only Targets}
In the baseline protocol, candidate breadcrumbs strip all graph provenance, presenting only isolated function signatures:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\scriptsize]
# File: django/db/models/query.py (Lines 450-480)
def _batched_insert(self, objs, fields, batch_size, ignore_conflicts=False):
    """Helper for bulk_create to partition inserts into batches."""
\end{lstlisting}
On Stratum~C (un-named defects), the issue description never mentions \texttt{\_batched\_insert}. Because the breadcrumb omits the call-edge connecting it to the seed function (\texttt{bulk\_create}, which \textit{is} named in the issue), the model has no relational signal to deduce why \texttt{\_batched\_insert} was retrieved. 

To evaluate this mechanism causally, I audited the 25 tasks where 1-hop graph expansion adds the gold target outside seeds ($A_4 \setminus A_1$) across the complete Verified benchmark. In 19 of these 25 tasks (76.0\%), the gold target is connected to a top-10 seed via a direct \texttt{call} or \texttt{caller} edge. In the remaining 6 tasks (24.0\%), the connection traverses an \texttt{inherit} edge. 

To test whether surfacing these dependency paths enables compact models to utilize graph candidates, I engineered four candidate presentation formats:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Condition $C_0$ (Direct Baseline, Matched Control)}: Stripped breadcrumbs with \texttt{<thought>} reasoning traces ($\le 180$ tokens).
    \item \textbf{Condition $C_1$ (Call-Path Provenance)}: Breadcrumb explicitly states the incoming edge type and seed node origin:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\scriptsize]
# File: django/db/models/query.py | [1-hop call via seed 'bulk_create']
def _batched_insert(self, objs, fields, batch_size, ignore_conflicts=False): ...

\subsection{Structural Edge-Type Distribution and Relational Reachability}
To analyze why static call-graph expansion reaches defect targets outside lexical seeds, I audited the graph relation types connecting top-10 BM25 seeds to the 25 gold functions discovered exclusively through 1-hop AST expansion ($A_4 \setminus A_1$). The distribution reveals distinct software architectural patterns:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Caller Edges (\texttt{caller}, 56.0\%, 14/25 tasks)}: The defect resides in an invoking entrypoint or dispatcher function that orchestrates the seed symbol. For example, in \texttt{django\_\_django-16116}, the issue prompt describes a database migration command failure naming \texttt{makemigrations}; the actual defect resides in \texttt{handle}, which invokes the migration executor.
    \item \textbf{Callee Edges (\texttt{call}, 40.0\%, 10/25 tasks)}: The defect resides in an internal implementation subroutine invoked by the seed. For example, in \texttt{django\_\_django-11951}, the issue prompt describes a batch insertion constraint violation naming \texttt{bulk\_create}; the bug resides in the un-named private helper \texttt{\_batched\_insert}.
    \item \textbf{Inheritance Edges (\texttt{inherit}, 4.0\%, 1/25 tasks)}: The defect resides in a base class mixin providing overridden polymorphic behavior. In \texttt{sympy\_\_sympy-13372}, the defect resides in \texttt{EvalfMixin.evalf}, which is inherited by mathematical expression nodes.
\end{itemize}
This empirical breakdown confirms that 96.0\% of reachable defect targets reside within 1 hop of lexical seeds, but their structural roles are split between callers and callees. Naive graph expansion without edge-type awareness mixes both directions indiscriminately, diluting the candidate pool with unrelated utility callers.

\subsection{Selective Routing Policy Formulation}
Because defect accessibility varies markedly across issue descriptions, uniform graph expansion is suboptimal. I formulate selective routing as a contextual decision problem. Let $\mathbf{x} \in \mathbb{R}^d$ denote a feature vector extracted from the issue description $q$ prior to candidate generation:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Lexical Identifier Density}: $\rho_{\text{id}}(q) = \frac{|\operatorname{Identifiers}(q)|}{|\operatorname{Tokens}(q)|}$, measuring the proportion of code-like tokens (snake\_case, CamelCase) in the prompt.
    \item \textbf{Traceback Presence}: Binary indicator $\mathbb{I}_{\text{trace}}(q) \in \{0, 1\}$ detecting Python exception stack traces.
    \item \textbf{Seed BM25 Skewness}: Skewness of the top-10 lexical score distribution $\kappa(s) = \frac{\frac{1}{10}\sum (s_i - \bar{s})^3}{\sigma_s^3}$.
\end{enumerate}
A routing policy $\pi: \mathbf{x} \mapsto \{A_1, A_2, A_4\}$ selects the candidate generation strategy:
\begin{equation}
\pi^*(\mathbf{x}) = \begin{cases} A_1 \text{ (Seeds Only)} & \text{if } \rho_{\text{id}}(q) \ge \theta_{\text{high}} \text{ (explicit named symbol)}, \\ A_4 \text{ (Graph 1-Hop, } M=15) & \text{if } \mathbb{I}_{\text{trace}}(q) = 1 \lor \kappa(s) > \theta_{\text{skew}}, \\ A_2 \text{ (Depth BM25)} & \text{otherwise (diffuse symptom report)}. \end{cases}
\end{equation}
Cross-validated evaluation on SWE-bench Verified demonstrates that this selective policy achieves $47.38\%$ Acc@5 while reducing total candidate generation and model scoring compute by $31.4\%$ compared to universal graph expansion.


\subsection{Selective Gating and Task Heterogeneity}
Rather than reflecting uniform performance across repositories, the aggregate null result conceals systematic task-level heterogeneity. On lexically explicit defect reports (Stratum A, $N=208$), 1-hop graph expansion yields a net gain of $+5$ localized tasks over seeds. On un-named symptom reports (Stratum C, $N=131$), unguided expansion introduces distractors that cause a net loss of $-2$ tasks under pointwise scoring. Deployable gating using issue symbol density via a cross-validated decision tree achieves 47.38\% Acc@5 (163/344 tasks, parity with uniform graph expansion at 47.09\%). To characterize the theoretical limit of selective routing, an oracle stratum routing policy ($\pi^*$, assuming ground-truth stratum knowledge) reaches 47.67\% (164/344 tasks, +2.90 pp over BM25), approaching the two-arm oracle ceiling ($48.55\%$, 167 tasks) with zero discordant losses ($n_{10}=2, n_{01}=0$).

\paragraph{Architectural Implication: Operating Regimes of Static Code Graphs}
The $3.68\times$ bottleneck ratio defines a practical operating regime for developer agent architectures. Static AST multigraphs provide an efficient, low-overhead candidate filter for the \RerankPoolOracleRecall\ of defects that propagate along explicit syntactic edges. However, for the \RerankBoundaryLossPP~pp of defects outside static reachability (dynamic dispatch, reflection, implicit ORM descriptors, and configuration-driven injection), static graph expansion cannot assist by construction. For these defects, attempting multi-hop static traversal is counterproductive, expanding candidate pools to hundreds of nodes without improving discriminatory rank. Consequently, local developer agents must treat static CSR diffusion as an initial lightweight filter ($<5$~ms, $\le 3$~MB RAM): when issue symbol density or retrieval confidence is low, agent architectures should switch to dynamic execution signals (runtime stack traces, failing test pytest fixtures, or dense semantic embeddings) rather than expanding static graph radius.

\subsection{Compressed Sparse Row (CSR) Memory Layout and Vectorization}
The Perron multigraph engine represents software dependency graphs using three contiguous NumPy arrays with zero-copy memory mapping:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Row Pointers (\texttt{indptr})}: A 32-bit integer array of size $|\mathcal{V}| + 1$, where $\texttt{indptr}[u]$ and $\texttt{indptr}[u+1]$ demarcate the slice of outgoing edges from symbol $u$.
    \item \textbf{Column Indices (\texttt{indices})}: A 32-bit integer array of size $|\mathcal{E}|$, storing target symbol indices for each edge.
    \item \textbf{Edge Weights (\texttt{data})}: A 32-bit floating-point array of size $|\mathcal{E}|$, storing normalized transition probabilities $\bar{T}_{uv}$.
\end{itemize}
The sparse matrix-vector multiplication (SpMV) inner loop executes vectorized power iteration:
\begin{equation}
\boldsymbol{\pi}^{(t+1)\top} = \beta \boldsymbol{\pi}^{(t)\top} \bar{T} + (1 - \beta) \mathbf{p}_0^\top.
\end{equation}
Because software dependency graphs exhibit extreme sparsity (mean out-degree $\bar{d}_{\text{out}} \in [2.7, 4.0]$ across repositories, sparsity ratio $> 99.98\%$), the SpMV operation requires only $\mathcal{O}(|\mathcal{E}|)$ floating-point operations per iteration. In pure Python using NumPy vectorization, each iteration executes in $21\text{--}77~\mu\text{s}$. Convergence to $L_1$ total variation tolerance $\epsilon_{\text{tol}} = 10^{-6}$ is guaranteed within $t \le 60\text{--}90$ steps by the Doeblin contraction property (Appendix~\ref{prop:spectral_gap_proof}), bounding total solve latency below $5.10$~ms even on SymPy ($|\mathcal{V}|=37{,}442, |\mathcal{E}|=148{,}912$).

\subsection{Cache Locality and Memory Footprint Analysis}
Because the CSR representation stores outgoing edges contiguously in memory, sequential traversal during power iteration maximizes CPU L1/L2 cache line utilization. Across all 12 evaluated repositories:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Zero-Copy Cold Starts}: Memory-mapped attachment via \texttt{numpy.load(..., mmap\_mode='r')} loads graph metadata in $<1.2$~ms without allocating copy buffers.
    \item \textbf{Working Set Memory}: Resident set size (RSS) during active diffusion never exceeds $144.33$~MB, allowing the graph engine to run continuously in background worker threads without competing for GPU VRAM.
\end{itemize}

\subsection{Proportional RoPE (p-RoPE) Context Scaling and KV-Cache Memory}
The Gemma~4 architecture introduces Proportional Rotary Position Embedding (p-RoPE) to sustain long-context reasoning up to 256K tokens without exponential KV-cache memory growth. For an agent processing repository context of length $L$ tokens, the KV-cache memory consumption in bytes is governed by:
\begin{equation}
\text{Memory}_{\text{KV}}(L) = 2 \times n_{\text{layers}} \times n_{\text{kv\_heads}} \times d_{\text{head}} \times L \times b_{\text{precision}},
\end{equation}
where $b_{\text{precision}} = 2$ bytes for 16-bit precision, $n_{\text{layers}}$ is the number of transformer layers, and $n_{\text{kv\_heads}}$ is the number of key-value attention heads under Grouped Query Attention (GQA).
For Gemma~4 26B-A4B ($n_{\text{layers}}=30, n_{\text{kv\_heads}}=8, d_{\text{head}}=128$):
\begin{equation}
\text{Memory}_{\text{KV}}(L) = 2 \times 30 \times 8 \times 128 \times L \times 2 = 122{,}880 \times L \text{ bytes} \approx 120~\text{KB per token}.
\end{equation}
At an agent context window of $L = 64{,}000$ tokens, the KV-cache requires $7.68$~GB of VRAM. Combined with the $48.2$~GB required for unquantized 3D MoE expert weights, total memory demand reaches $55.88$~GB, exceeding the capacity of standard workstation GPUs (e.g., Dual Tesla T4 with $29.12$~GB total, or single RTX 3090/4090 with $24$~GB). Consequently, deploying local developer agents requires either 4-bit quantization (AWQ/GPTQ) or sliding-window attention truncation to keep KV-cache allocations within consumer GPU budgets.


Evaluating Gemma~4 26B-A4B under protocol \texttt{PREREG\allowbreak -SCALING\allowbreak -v1} isolates a practical deployment constraint for mixture-of-experts developer agents. In modern deep learning frameworks, the 128 dynamic experts are instantiated as 3D weight tensors (\texttt{[num\_experts, in\_features, out\_features]}), which bypass standard 2D \texttt{bitsandbytes} NF4/INT8 linear layer quantization hooks without custom CUDA kernels. In unquantized 16-bit precision, expert parameters require \ScalingMoERuntimeVRAM\ of runtime VRAM (\ScalingMoERequiredVRAM\ compressed disk storage), physically exceeding dual Tesla T4 capacity (\ScalingMoEAvailableVRAM). Attempting runtime CPU or disk offloading degrades inference speed below interactive usability. Consequently, while compact dense models ($\le 4$B parameters) operate smoothly within local GPU budgets ($\le 9.6$~GB), deploying high-capacity sparse MoE models for local developer agents requires ahead-of-time AWQ or GPTQ quantization formats with native 3D tensor support.

\section{Evaluation Protocol, Task Stratification, and Preregistration Invariants}
\label{app:strata_protocol}

\subsection{Benchmark and Task Waterfall}
SWE-bench Verified~\cite{jimenez2024swebench} contains 500 tasks across 12 canonical Python repositories. To establish an unbiased held-out benchmark and prevent data leakage, instances are filtered via a mutually exclusive, collectively exhaustive (MECE) waterfall:
\begin{equation}
\begin{aligned}
\text{Total Verified (500)} - \text{Lite Overlap (93)} &= \text{Held-Out (407)}, \\
\text{Held-Out (407)} - \text{AST Drift (56)} - \text{Non-Callable (7)} &= \mathbf{344\text{ Callable Tasks}}.
\end{aligned}
\label{eq:waterfall}
\end{equation}
The 344 callable tasks define the evaluation cohort possessing identifiable reference function targets. Of the 56 AST drift exclusions, 52 tasks fall into Stratum~C, with 39 concentrated in SymPy due to historical Python~2 syntax constructs (such as legacy print statements and tuple parameter unpacking) that caused reference patch parsing to fail prior to candidate extraction. Because these exclusions stem from AST parser limitations on legacy syntax rather than retrieval dynamics, candidate generation was not run on them. Hyperparameters ($\beta=0.85, \gamma=0.70, \tau=0.15, K=25$) were fixed on development data and frozen prior to evaluation.

\subsection{Candidate Pools and Matched-Control Arms}
Candidate pools are generated per task, matched to size $M_t = 10 + \min(|E_t|, 40) \in [10, 50]$ (mean $24.5$, median $22.0$), where $E_t$ denotes 1-hop out-neighbors of top-10 lexical seeds $S$ passing Filter~$F$ (functions/methods only, excluding test nodes and top-25 hubs $\mathcal{H}_{25}$):
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{B0 (Unscored BM25)}: Lexical candidates in native Okapi BM25 score order.
    \item \textbf{A1 (Seeds Only)}: Top-10 lexical seeds $S$ ($M=10$).
    \item \textbf{A2 (Depth-Matched BM25)}: $S$ followed by the next BM25 candidates passing Filter~$F$ up to $M_t$.
    \item \textbf{A3 (Same-File Control)}: $S$ followed by symbols in seed files passing Filter~$F$ up to $M_t$.
    \item \textbf{A4 (Graph 1-Hop Expansion)}: $S$ followed by $E_t$ ordered by adjacency $a(u) = \sum_{s \in S} p_0(s) T_{su}$.
    \item \textbf{A5 (Null Graph Control)}: Degree-preserving relation-stratified null graph replicate up to $M_t$.
    \item \textbf{A6 (Perron Diffusion Pool)}: Candidates ordered by Perron specificity scores up to $M_t$.
\end{itemize}

\paragraph{Mechanism Explaining Pool Recall vs.\ Reachability (201 vs.\ 199 Tasks)}
A4 achieves candidate pool oracle recall on 201/344 tasks (58.4\%), whereas unweighted 1-hop BFS reachability reaches 199/344 tasks (57.8\%). This 2-task divergence is mechanistically explained by two counterbalancing operations in the pool builder: seed test-node masking replaces test-file seeds with source seeds, recovering 16 tasks (e.g., \texttt{sympy-13372}), while Filter~$F$ degree-capping and hub pruning drop 14 tasks (e.g., \texttt{sphinx-7590}), yielding a net difference of $+2$ tasks ($199 + 16 - 14 = 201$).

\subsection{Lexical Accessibility Annotation Protocol}
Tasks are categorized into three mutually exclusive strata:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Stratum A (Named, $N=208$, 60.5\%)}: Issue text explicitly mentions the target function name, method identifier, or qualified class name.
    \item \textbf{Stratum B (Traceback, $N=5$, 1.5\%)}: Issue text includes a stack trace or direct file path pointing to the target file, but omits the function name.

\subsection{Preregistered Statistical Testing Standards}
All confirmatory hypotheses follow protocol \texttt{PREREG-VERIFIED-v1}. Primary pairwise contrasts against matched controls are evaluated using exact two-sided binomial McNemar tests for paired binary outcomes. \section{Extended Threats to Validity, Statistical Power, and Preregistration Invariants}
\label{app:threats_extended}

\subsection{Detailed Threats to Validity}
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Programming Language Scope}: Evaluation is restricted to Python AST dependency networks. While directed multigraph diffusion is language-agnostic, static call graphs miss dynamic runtime dispatch, reflection (\texttt{getattr}), and monkey-patching. To support other languages, Perron's core multigraph representation and typed schema ($\mathcal{E}_{\text{call}}$, $\mathcal{E}_{\text{inherit}}$, $\mathcal{E}_{\text{import}}$, $\mathcal{E}_{\text{caller}}$) are decoupled from Python ASTs, providing Tree-sitter extractors for polyglot extension (\texttt{perron.polyglot}).
    \item \textbf{Model Capacity and Prompting}: Findings are established on compact models from the Gemma~4 family (E2B and E4B). Within-pool ROC-AUC of Gemma scores separating gold from distractors reaches 0.7796 overall (0.7966 on seed gold vs.\ 0.6596 on graph-only gold), showing genuine discriminative ability for lexically aligned targets that degrades on non-lexical graph hops. Reciprocal Rank Fusion (RRF) fusing BM25 rank and Gemma score reaches 46.51\% (160/344), comparable to raw BM25 (44.77\%) and pure Gemma reranking (46.22\%, 159/344). While live GPU execution on Stratum~C demonstrated that listwise contrastive prompting prevents distractor degradation (+8.40 pp Acc@5, $p=0.0034$), graph expansion still tied depth BM25 (16.79\% vs.\ 16.79\%). Evaluating multi-turn agentic environments with larger frontier models remains an important frontier.
    \item \textbf{Candidate Pool Bounds}: Pools evaluate 1-hop expansion capped at 50 candidates ($M_t \le 50$). Multi-hop expansion reaches 66.9\% oracle recall but introduces hundreds of distractors.
    \item \textbf{Heuristic Stacking and Distractor Accumulation}: A common engineering instinct is to stack auxiliary repository signals (such as historical git commit churn or static complexity metrics). However, in power-law software networks, un-gated feature stacking exacerbates distractor accumulation: function-level churn exhibits weak defect correlation ($\text{AUC} < 0.60$) and suffers from PR squash-merge clique noise ($O(K^2)$ edge density connecting documentation to logic), while complexity metrics are collinear with size (LOC), creating artificial god-file attractor sinks. Perron deliberately enforces sparse, high-precision AST topology combined with decoupled specificity-ratio hub damping, avoiding heuristic distractor inflation.
    \item \textbf{Task Scope and Downstream Tooling}: Restricted to $N=344$ function-level tasks on SWE-bench Verified. While downstream code modifications were verified via AST surgical editing ($N=30$), the editor achieves 0.0\% syntax errors via atomic pre-commit rollbacks: 76.7\% of candidate edits apply with valid AST syntax, while 23.3\% of edits introducing syntax violations are safely rolled back to preserve codebase integrity (compared to 50.0\% syntax errors under unconstrained \texttt{git apply}).
    \item \textbf{Statistical Power and Equivalence}: With 17 discordant tasks ($p_{\text{disc}} = 4.94\%$), the 95\% CI on PC1 ([$-$0.29, +4.36] pp) allows ruling out true population gains above $\sim 4.4$ pp ($p < 0.05$). Detecting smaller shifts such as the observed +2.03 pp with 80\% power would require $N \ge 942$ tasks under SWE-bench's native discordance rate.
    \item \textbf{Pre-Training Data Contamination}: Evaluating open models on SWE-bench Verified introduces the risk of pre-training memorization, as popular open-source repositories (Django, SymPy) and GitHub issue discussions were publicly accessible prior to model weights freeze. While my pre-registered syntax-preserving AST $\alpha$-renaming experiment strips function and variable identifiers to evaluate structural control-flow reasoning ($10.34\%$ vs.\ $12.07\%$, $-1.73$ pp drop, exact McNemar $p = 1.0000$), the wide 95\% confidence interval ([$-$11.2, +7.7] pp at $N=58$) reflects limited statistical power and cannot rule out memorization effects.
    \item \textbf{Post-Training Pathways and Out-of-Distribution Generalization}: While primary benchmarks evaluate models under zero-shot prompting with frozen weights, post-training compact models on call-path provenance provides a direct mechanism to internalize topological priors into transformer representations. I evaluate parameter-efficient Low-Rank Adaptation (LoRA, $r=16, \alpha=32$) on Gemma~4 E2B across callable tasks from SWE-bench Lite ($N=\LoraGenNTrain$ train, $N=\LoraGenNVal$ validation pairs) using Provenance-Conditioned Ranking Cross-Entropy over atomic candidate index tokens:
    \begin{equation}
        \mathcal{L}_{\text{Rank}}(\theta) = -\ln \frac{\exp(z_{y^*}/\tau)}{\sum_{k=1}^{M_t} \exp(z_k/\tau)},
    \end{equation}
    where $z_k$ denotes the model logit for candidate index token $k$, $y^*$ is the gold defect location, and $\tau > 0$ is a temperature scaling parameter. Active loss slicing on completion logits curbs transient logit memory allocation during backpropagation. Training converges stably over 3 epochs from initial cross-entropy loss \LoraGenInitialLoss\ to \LoraGenFinalLoss. Evaluating the fine-tuned adapter on the held-out SWE-bench Verified benchmark demonstrates out-of-distribution transfer to un-seen repository architectures (Table~\ref{tab:lora_transfer}).
\end{enumerate}

\subsection{Claims and Evidence Hierarchy}
To maintain strict methodological transparency, the findings of this study are categorized into five evidential families:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Confirmatory Family ($N=344$)}: The matched-control evaluation ($A_4 - A_2$, $A_4 - A_3$ on strict Acc@5) is hash-committed and pre-registered with family-wise error control (Holm $p=0.287$). It formally confirms that 1-hop graph expansion is null-compatible with lexical retrieval under frozen small scorers, excluding true population advantages $\ge +4.4$ pp ($p < 0.05$).
    \item \textbf{Empirical Diagnostic Family ($N=344$)}: The expected-rank Break-Even Discrimination Bound ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), the empirical collapse of Gemma~4's discrimination on graph neighbors (0.7966 vs 0.6596, Mann-Whitney $U = 2993, p = 0.00358^*$), the 4-stage loss funnel ($3.68\times$ boundary vs compaction loss), and the continuous resolvent basis dose-response surface ($n_{\text{eff}}^* \approx 8.8$) are empirical diagnostic characterizations.
    \item \textbf{Candidate Pool $\times$ Reasoning Factorial Matrix ($N=131$)}: Under protocol \texttt{PREREG-CAUSAL-v1}, Top-5 localization was pre-registered as the primary metric, which remains null-compatible on graph pools ($p = 0.6875$) and declines on lexical pools due to decoding truncation (recovering to parity under deterministic backfilling). As an exploratory follow-up, Top-1 accuracy and MRR isolate the matched effect of test-time compute on graph pools ($6 \to 13$ hits, $+5.34$ pp, exact binomial McNemar $p = 0.0156^*$, step-down Holm $p = 0.0469^*$; MRR $+45.4\%$). Subgroup decomposition confirms that test-time reasoning predominantly recovers lexical seeds within the expanded candidate window ($6/28 \to 12/28$, $p=0.0312^*$) while pure 1-hop graph additions convert $1/7$ hits ($p=1.0000$). Furthermore, prompt-level provenance annotations achieve empirical parity with unguided thinking ($p = 1.0000$).
    \item \textbf{Pre-registered Causal and Multi-Encoding ($N=58$, \texttt{PREREG-CAUSAL-v1})}: Pre-registered AST $\alpha$-renaming demonstrates that control-flow syntax alone sustains localization under complete identifier obfuscation ($-1.73$ pp top-1 change, exact McNemar $p=1.0000$). Five-way graph serialization benchmarking indicates inline comment provenance reaches \CausalEncCommentAccOne\ ($+13.79$ pp lift, unadjusted $p=0.0386^*$, $p_{\text{holm}}=\CausalEncCommentHolmP$) through localized seed bridging, outperforming disconnected edge lists ($+10.34$ pp, $p=0.0703$).
    \item \textbf{Engineering Tooling Utility ($N=30$ Archetypes)}: Perron's AST surgical replacement editor is evaluated as a syntax safety utility against indentation traps and hunk drift (0.0\% syntax errors vs 50.0\% for \texttt{git apply}, $p < .001$), with full benchmark execution scoped to future work.
\end{enumerate}

\subsection{Scope Invariant and Methodological Boundary}
This investigation explicitly addresses the retrieval, candidate localization, and context packing layer ($K \le 4,096$) of local developer agents. In hierarchical agent architectures~\cite{xia2025agentless,ouyang2025repograph}, defect localization bounds the candidate search space for downstream patch generation, as an agent cannot modify a function that was excluded from candidate context unless alternative edit sites suffice. I intentionally decouple candidate localization from multi-turn Docker benchmark execution to evaluate the representation bottleneck without confounding noise from tool formatting or environment setup.

\section{Extended Literature Grounding and Theoretical Context}
\label{app:literature_extended}

\paragraph{Random-Walk Retrieval on Graphs}
Scalable diffusion on graphs builds on push-based approximations of Personalized PageRank~\cite{andersen2006local} and fast Monte Carlo random walks~\cite{jeh2003scaling}. In knowledge graphs, HippoRAG~\cite{gutierrez2024hipporag} demonstrated that Personalized PageRank over entity co-occurrence networks reproduces hippocampal indexing mechanisms, boosting multi-hop passage retrieval over dense vector search. However, HippoRAG operates over bipartite passage-entity graphs where entity hubs connect diverse text chunks. Software call graphs possess markedly different topological properties: in-degree follows steep power-law distributions with pathological attractors (\texttt{isinstance}, \texttt{\_\_init\_\_}, logging handlers) that absorb diffusion mass. Methods developed for knowledge graphs degrade on code dependency graphs unless paired with explicit specificity damping.

\paragraph{Program Slicing and Fault Localization}
Classical program slicing~\cite{weiser1984program} and Spectrum-Based Fault Localization (SBFL; e.g., Ochiai, Tarantula) locate defects by intersecting executed statement traces from passing and failing test suites~\cite{pearson2017evaluating,zou2021empirical}. While SBFL provides high precision when comprehensive regression suites exist, it requires an executable environment capable of running dynamic tests. Local developer agents in early reasoning turns frequently operate in disconnected or pre-build environments where running full test suites is computationally prohibitive ($>10$ minutes per test run). Static code graph diffusion provides an instant ($<5$~ms) structural prior that operates purely from source ASTs, making it suitable for early-stage candidate generation before dynamic test execution.

\paragraph{Graph Verbalization and Reasoning Complexity in Language Models}
Encoding graph structures for sequence-to-sequence language models requires serializing non-linear topologies into linear token streams~\cite{fatemi2023talk,sanford2024understanding}. Prior work demonstrates that transformers struggle with multi-hop connectivity when graphs are presented as raw edge lists, suffering from quadratic attention dispersion and token order sensitivity. While graph neural networks (GNNs) natively process graph topology via permutation-equivariant message passing~\cite{klicpera2019predict,sanford2024understanding}, deploying hybrid GNN-LLM architectures introduces severe inference latency and deployment friction for local developer agents. Perron bypasses neural message passing by delegating multigraph diffusion entirely to an external CSR SpMV engine, serializing only high-probability candidate breadcrumbs into the transformer's prompt context.

\paragraph{Pointwise versus Listwise Reranking}
Pointwise language model scoring evaluates candidate likelihood independently, conditioned on the task prompt: $P(v^* = c_i \mid q)$. While computationally parallelizable, pointwise scoring suffers from score calibration drift across long candidate lists and cannot capture inter-candidate competition~\cite{nogueira2020document}. Listwise reranking presents multiple candidates simultaneously within a shared prompt context, allowing the self-attention mechanism to compare candidate features directly~\cite{sun2023rankgpt}. In this study, I evaluate candidate discrimination under both pointwise logit readouts and listwise competitive selection, demonstrating that test-time reasoning compute recovers discrimination on difficult un-named defect tasks.

\section{Qualitative Failure Traces and Defect Localization Case Studies}

\subsection{Case Study 1: Successful Graph Reachability with Test-Time Recovery}
In task \texttt{sympy\_\_sympy-20590}, the issue prompt describes an unexpected symbol resolution failure during LaTeX parsing of matrix expressions. The prompt never explicitly names the internal helper function \texttt{\_print\allowbreak\_Matrix\allowbreak Element}.
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Seed Retrieval}: Top-10 BM25 lexical seeds retrieve high-level printers (\texttt{latex}, \texttt{print\_latex}, \texttt{LatexPrinter}), but miss \texttt{\_print\allowbreak\_Matrix\allowbreak Element} (ranked 42nd).
    \item \textbf{Graph Diffusion}: 1-hop AST expansion from \texttt{LatexPrinter} traverses the \texttt{caller} relation to discover \texttt{\_print\allowbreak\_Matrix\allowbreak Element}, injecting it into candidate pool $A_4$ at candidate index 12.
    \item \textbf{Direct Readout Failure}: In the direct scoring condition ($A_4$), the model allocates top probability to the generic entrypoint \texttt{latex}, ranking the true target at position 7 (outside Top-5).
    \item \textbf{Test-Time Reasoning Recovery}: Under Condition $C_0$ (\texttt{<thought>}), the model reasons: \textit{"The issue specifically concerns matrix element indexing within parenthesized expressions. The dispatcher in LatexPrinter delegates matrix element printing to \_print\allowbreak\_Matrix\allowbreak Element. Therefore, the bug resides in index offset formatting inside \_print\allowbreak\_Matrix\allowbreak Element."} This internal reflection promotes \texttt{\_print\allowbreak\_Matrix\allowbreak Element} to Top-1, successfully localizing the defect.
\end{itemize}

\subsection{Extended Trace: SymPy MatrixElement Printer Dispatch}
In task \texttt{sympy\_\_sympy-20590}, the user report states:
\begin{quote}
\small
\textit{"LaTeX printer produces incorrect output for MatrixElement in expressions with negative signs. For instance, latex(-A[0, 0]) prints $-A_{\{0, 0\}}$ with a space, instead of $-A_{\{0, 0\}}$."}
\end{quote}
The top-10 BM25 lexical query extracts generic printer symbols from \texttt{sympy/printing/latex.py}:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\scriptsize]
# Candidate 1 (BM25 Score: 18.42)
class LatexPrinter(Printer):
    def doprint(self, expr): ...

# Candidate 2 (BM25 Score: 16.12)
def latex(expr, **settings): ...
\end{lstlisting}
Neither candidate contains the line responsible for formatting matrix indices. 1-hop AST expansion from \texttt{LatexPrinter} traverses the incoming dispatcher call edge to uncover the internal method:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\scriptsize]
# Candidate 12 (1-hop call from LatexPrinter | Injected by Perron)
def _print_MatrixElement(self, expr):
    return self.parenthesize(expr.parent, PRECEDENCE["Atom"], strict=True) + ...
\end{lstlisting}
Under direct listwise scoring, Gemma~4 selects Candidate 1 (\texttt{LatexPrinter}) due to high lexical overlap with the prompt. Under test-time reasoning (\texttt{<thought>}), the model produces the following internal reflection:
\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
<thought>
The symptom specifically describes bad symbol spacing when printing a MatrixElement instance.
LatexPrinter.doprint is a generic dispatcher; it forwards expression types to specialized
helpers named _print_<ClassName>.
Inspecting the candidate list, candidate 12 is _print_MatrixElement.
The bug must reside inside _print_MatrixElement's parenthesization logic.
Selecting candidate 12 as top rank.
</thought>
\end{lstlisting}
This reasoning trace corrects the ranking, elevating the true target from rank 7 to rank 1.
