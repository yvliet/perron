\begin{abstract}
Deploying structural code graphs in local developer agents requires balancing topological expansion against language model discrimination. Evaluating open models across 344 held-out SWE-bench Verified tasks reveals naive Personalized PageRank expansion yields statistically indistinguishable localization from lexical retrieval alone (47.1\% vs 45.1\%, exact binomial McNemar $p=0.287$; excluding true advantages $\ge +4.4$ pp, $p < 0.05$). This limitation is characterized by an expected-rank \textbf{Break-Even Discrimination Bound} ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), where Gemma~4 E2B pairwise discrimination degrades from $\text{AUC}=0.7966$ on lexical seeds to $\text{AUC}=0.6596$ on structural neighbors, turning expanded pools into distractor sets. Consistent with relational reasoning limits in transformers~\cite{sanford2024understanding}, evaluating the candidate pool $\times$ reasoning interaction across all 131 un-named Stratum~C defects reveals that on the matched graph candidate pool ($A_4$), test-time reasoning traces (\texttt{<thought>}) more than double Top-1 accuracy from \MatchedGraphDirectAccOne\ (6 hits) to \MatchedGraphThinkingAccOne\ (13 hits; \MatchedGraphDeltaAccOnePp\ pp lift, \MatchedGraphRelLiftAccOneRatio\ relative gain, exact binomial $p = 0.039^*$; MRR $+45.4\%$). Crucially, reasoning compute interacts oppositely across pool architectures, degrading accuracy on lexical distractors ($-$5 tasks on depth BM25) while enabling structural traversal on graph neighbors (+2 tasks, interaction contrast $\Delta_{\text{interaction}} = +5.34$ pp, $+7$ net tasks). Combining prompt call-path annotations with thinking ($C_3$, \CausalCThreeAccOne) yields empirical parity with unguided thinking ($C_0$, exact McNemar $p = 1.0000$), showing that allocated reasoning tokens allow model representations to trace relational dependencies directly. Pre-registered causal interventions (\texttt{PREREG-CAUSAL-v1}, $N=58$) isolate the mechanism of this bottleneck: syntax-preserving AST $\alpha$-renaming incurs only a $-1.73$~pp top-1 drop ($12.07\% \to 10.34\%$, $p=1.0000$), confirming that control-flow syntax provides a resilient baseline without surface names, while inline comment provenance reaches \CausalEncCommentAccOne\ (\CausalEncCommentLiftTopOne\ pp lift, unadjusted $p = 0.0386^*$, $p_{\text{holm}} = \CausalEncCommentHolmP$) through localized seed bridging, outperforming disconnected global edge lists (\CausalEncEdgeListAccOne, $+10.34$ pp, $p=0.0703$). To deliver scalable provenance extraction on consumer hardware, \textbf{Perron} provides an open-source CSR diffusion engine executing vectorized spectral convergence in $1.89\text{--}5.10$~ms within $\le 3$~MB zero-copy array resident RAM ($144.33$~MB peak process RSS, reflecting baseline Python interpreter, PyArrow, and NumPy runtime overhead), preserving 91.9\% reasoning headroom under a 3,480-token budget. Downstream evaluation demonstrates that AST surgical replacement achieves a 0.0\% syntax error rate ($p < .001$ vs unified diffs), resolving patch generation fragility independent of retrieval depth.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Autonomous developer agents designed for local execution must localize software defects inside a working context of a few thousand tokens ($K \le 4,096$), eliminating dependence on costly cloud APIs and preventing source code leakage. Standard lexical search (e.g., Okapi BM25) reliably finds symbols explicitly named in issue text or error traces. To locate fault sites that the issue never mentions, existing agent architectures (including Aider's PageRank repository maps~\cite{gauthier2023aider}, RepoGraph~\cite{ouyang2025repograph}, and LocAgent~\cite{chen2025locagent}) deploy random walks or graph traversal tools over AST dependency networks.

The working assumption underlying graph-augmented localization rests on two joint conditions: (1)~\textbf{Recall Expansion}: Traversal along structural call edges must place gold defect targets into the candidate pool that lexical search misses; and (2)~\textbf{Rank Discrimination}: A compact language model must rank those newly introduced targets above the distractors that graph expansion inevitably introduces.

Evaluating both assumptions on a 344-task held-out subset of SWE-bench Verified~\cite{jimenez2024swebench} using Perron and a frozen \texttt{gemma-4-e2b-it} scorer exposes a fundamental disconnect: while 1-hop graph expansion adds +7.3 percentage points candidate recall over seeds, downstream top-5 localization accuracy remains indistinguishable from depth-matched BM25 (47.1\% vs 45.1\%, Holm $p=0.287$).

This paper investigates this disconnect through five core findings:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]\sloppy
    \item \textbf{Matched-Control Pool Parity}: Across 19,298 scored evaluations, naive Personalized PageRank expansion achieves zero statistical advantage over lexical retrieval under frozen small scorers, confirming candidate pool parity (RQ1, RQ2).
    \item \textbf{The Mathematical Account}: I formalize the expected-rank \textbf{Break-Even Discrimination Bound} ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$) and identify a \textbf{Topological Disambiguation Deficit}: Gemma~4's pairwise discrimination drops from 0.7966 ROC-AUC on seeds to 0.6596 on graph neighbors competing with seed distractors, falling below the expected-rank threshold required to benefit from pool expansion (RQ3).
    \item \textbf{Cross-Architecture Scaling Surface}: Protocol \texttt{PREREG\allowbreak -SCALING\allowbreak -v1} on Dual Tesla T4 GPUs demonstrates monotonic intra-family scaling within Gemma~4 ($0.8544 \to 0.9274$), proves Gemma~4 E4B (4.0B) achieves representational efficiency over Phi-4-mini (3.8B, 0.7836) and DeepSeek-7B (0.6489), and isolates the physical quantization boundary for sparse MoE architectures on consumer GPUs.
    \item \textbf{Candidate Pool $\times$ Reasoning Factorial Interaction}: Consistent with relational reasoning limits in transformers~\cite{sanford2024understanding} and graph verbalization theory~\cite{fatemi2023talk}, evaluating the factorial interaction of candidate pools and reasoning compute across all 131 un-named Stratum~C defects demonstrates that test-time reasoning traces (\texttt{<thought>}) on the matched graph pool double Top-1 accuracy from \MatchedGraphDirectAccOne\ (6 hits) to \MatchedGraphThinkingAccOne\ (13 hits; \MatchedGraphDeltaAccOnePp\ pp lift, \MatchedGraphRelLiftAccOneRatio\ relative lift, exact binomial $p = 0.039^*$; MRR $+45.4\%$). Reasoning compute interacts oppositely with candidate pools: it degrades accuracy on lexical distractors ($-$5 tasks on depth BM25) while enabling structural traversal on graph neighbors (+2 tasks, interaction contrast $\Delta_{\text{interaction}} = +7$ tasks). Pre-registered causal interventions (\texttt{PREREG\allowbreak -CAUSAL\allowbreak -v1}, $N=58$) isolate serialization schemes, showing inline comment provenance achieves \CausalEncCommentAccOne\ Top-1 ($p_{\text{uncorr}}=0.0386^*$, $p_{\text{holm}}=0.1543$) with localized lexical bridging.
    \item \textbf{Turnkey Open-Source Resource}: I release \textbf{Perron}, an open-source C/Python Compressed Sparse Row (CSR) engine executing decoupled spectral diffusion (vectorized convergence in $1.89\text{--}5.10$~ms, $0.024\text{--}0.075$~ms per inner-loop iteration; $0.17\text{--}0.45$~ms standalone API dispatch) within $\le 3$~MB zero-copy array resident RAM ($144.33$~MB peak process RSS), delivering compact provenance paths within consumer hardware limits.
\end{enumerate}

\subsection{Contributions}
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]\sloppy
    \item \textbf{Matched-Control Evaluation Design}: Depth-matched BM25, same-file, and degree-preserving null-graph candidate pools are scored by the identical model under controlled prompt budgets, isolating what graph structure contributes beyond pool cardinality.
    \item \textbf{Empirical Loss Funnel and Truncation Curves}: A 4-stage loss decomposition separates candidate boundary ceiling, rank compaction, and reader error. Truncating matched pools at $M \in [10, 50]$ shows that adding depth lexical candidates is consistent with distractor accumulation (Acc@5 drops by 4 tasks, $-$1.16 pp, $p=0.455$), whereas graph expansion plateaus flat (+3 tasks, +0.87 pp over seeds, $p=0.549$).
    \item \textbf{Topological Disambiguation Deficit and Break-Even Bound}: Empirical analysis demonstrates that open models struggle to disambiguate topologically connected candidates lacking prompt-anchored lexical tokens, causing pairwise discrimination to fall to 0.6596 on graph neighbors competing with seed distractors, falling below the expected-rank Break-Even Discrimination Bound.
    \item \textbf{Cross-Architecture Scaling Surface and MoE Hardware Boundary}: Protocol \texttt{PREREG\allowbreak -SCALING\allowbreak -v1} evaluates four model archetypes on Dual Tesla T4 GPUs, confirming monotonic scaling within Gemma~4 ($0.8544 \to 0.9274$), demonstrating that Gemma~4 E4B (4.0B) outperforms Phi-4-mini (3.8B, 0.7836) and DeepSeek-7B (0.6489), and isolating the physical \ScalingMoERequiredVRAM\ VRAM quantization barrier for sparse MoE models.
    \item \textbf{Factorial Candidate Pool $\times$ Reasoning Discovery}: A factorial evaluation on un-named defects ($N=131$) isolates the unconfounded effect of test-time reasoning: holding the candidate pool fixed at graph 1-hop ($A_4$), reasoning traces double Top-1 localization from \MatchedGraphDirectAccOne\ (6 hits) to \MatchedGraphThinkingAccOne\ (13 hits; exact binomial $p = 0.039^*$) and increase MRR@50 by $+45.4\%$. The interaction contrast against lexical pools demonstrates that reasoning over structural neighbors resolves ambiguity ($\Delta_{\text{interaction}} = +7$ tasks over depth BM25), whereas reasoning over lexical distractors induces confirmation bias.
    \item \textbf{Causal Lexical Dissection and Graph Serialization Hierarchy}: Pre-registered causal interventions (\texttt{PREREG\allowbreak -CAUSAL\allowbreak -v1}, $N=58$) examine structural representations: AST $\alpha$-renaming shows that control-flow syntax sustains 10.34\% top-1 localization when symbol names are stripped ($-1.73$ pp vs natural code, $p=1.0000$). Furthermore, evaluating graph serialization taxonomies~\cite{fatemi2023talk} reveals that inline comment provenance co-locating call paths at function definitions achieves \CausalEncCommentAccOne\ Acc@1 ($+13.79$ pp lift, $p_{\text{uncorr}} = 0.0386^*$, $p_{\text{holm}} = 0.1543$), with analysis indicating that localized comments introduce lexical seed bridging.
    \item \textbf{High-Throughput CSR Graph Engine}: An efficient, memory-mapped Compressed Sparse Row multigraph architecture with decoupled specificity ratio hub damping that executes vectorized convergence in $1.89\text{--}5.10$~ms on consumer workstations without matrix mutation (spectral convergence proofs detailed in Appendix~\ref{app:spectral_proofs}).
    \item \textbf{Open-Source Ecosystem and Benchmark Toolkit}: I release the \texttt{scores.parquet} archive (19,298 scored candidate evaluations), the Apache~2.0 \texttt{perron-core} library, precomputed CSR multigraphs for 12 canonical repositories, and curated strata annotations across 800 tasks spanning the broader SWE-bench ecosystem (300 Lite tasks + 500 Verified tasks, with 344 callable Verified tasks forming the primary held-out confirmatory benchmark) under CC0-1.0.
\end{itemize}

\subsection{Claims and Evidence Hierarchy}
To maintain strict methodological transparency, the findings of this study are categorized into five evidential families:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Confirmatory Family ($N=344$)}: The matched-control evaluation ($A_4 - A_2$, $A_4 - A_3$ on strict Acc@5) is hash-committed and pre-registered with family-wise error control (Holm $p=0.287$). It formally confirms that 1-hop graph expansion is null-compatible with lexical retrieval under frozen small scorers, excluding true population advantages $\ge +4.4$ pp ($p < 0.05$).
    \item \textbf{Empirical Diagnostic Family ($N=344$)}: The expected-rank Break-Even Discrimination Bound ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), the empirical collapse of Gemma~4's discrimination on graph neighbors (0.7966 vs 0.6596, Mann-Whitney $U = 2993, p = 0.00358^*$), the 4-stage loss funnel ($3.68\times$ boundary vs compaction loss), and the continuous resolvent basis dose-response surface ($n_{\text{eff}}^* \approx 8.8$) are empirical diagnostic characterizations.
    \item \textbf{Candidate Pool $\times$ Reasoning Factorial Matrix ($N=131$)}: Factorial evaluation across candidate pool architectures and reasoning modes isolates the matched effect of test-time compute on graph pools ($p = 0.039^*$ for $A_4$ thinking vs direct readout, $+5.34$ pp, $2.17\times$ lift; $+45.4\%$ MRR) and exposes an opposing pool $\times$ reasoning interaction ($\Delta_{\text{interaction}} = +5.34$ pp, $+7$ net tasks), while prompt-level provenance annotations achieve parity with unguided thinking ($p = 1.0000$).
    \item \textbf{Pre-registered Causal and Multi-Encoding Family ($N=58$, \texttt{PREREG-CAUSAL-v1})}: Pre-registered AST $\alpha$-renaming demonstrates that control-flow syntax alone sustains localization under complete identifier obfuscation ($-1.73$ pp top-1 change, exact McNemar $p=1.0000$). Five-way graph serialization benchmarking indicates inline comment provenance reaches \CausalEncCommentAccOne\ ($+13.79$ pp lift, unadjusted $p=0.0386^*$, $p_{\text{holm}}=\CausalEncCommentHolmP$) through localized seed bridging, outperforming disconnected edge lists ($+10.34$ pp, $p=0.0703$).
    \item \textbf{Engineering Tooling Utility ($N=30$ Archetypes)}: Perron's AST surgical replacement editor is evaluated as a syntax safety utility against indentation traps and hunk drift (0.0\% syntax errors vs 50.0\% for \texttt{git apply}, $p < .001$), with full benchmark execution scoped to future work.
\end{enumerate}

\paragraph{Scope Invariant and Methodological Boundary}
This investigation explicitly addresses the retrieval, candidate localization, and context packing layer ($K \le 4,096$) of local developer agents. In hierarchical agent architectures~\cite{xia2025agentless,ouyang2025repograph}, defect localization establishes the strict mathematical upper bound on downstream patch resolution. We intentionally decouple candidate localization from multi-turn Docker benchmark execution to evaluate the representation bottleneck without confounding noise from tool formatting or environment setup.

\subsection{Physical Hardware Envelope}
Local developer agents must operate efficiently on consumer hardware. Perron bounds active per-turn working context to $K_{\text{effective}} = 3,480$ tokens ($K \le 4,096$). On a reference developer machine (\HostRAMGiB\ RAM), the standalone CSR engine peaks at \EnginePeakRSSMB\ resident memory (loading graphs via zero-copy memory mapping within a $\le 3.0$~MB array buffer resident footprint; \EngineGraphLoadDeltaMB\ total benchmark process delta including PyArrow and NumPy allocations). Hierarchical AST skeleton breadcrumbs occupy an average of 283.8 tokens per task (median 264 tokens), preserving 91.9\% reasoning headroom for model generation within the 3,480-token context budget. Live inference of \texttt{gemma-4-e2b-it} was evaluated with left-padded batching and \texttt{logits\_to\_keep=1} on an NVIDIA Tesla T4 GPU (scoring prompts averaging 423 tokens per candidate symbol), achieving mean Time-To-First-Token of \GemmaMeanTTFTMs\ and \GemmaDecodeTokensSec\ tokens/sec decode throughput.

\section{Related Work}
\label{sec:related}
\paragraph{Graphs and Agents for Code Localization}
Lexical search and dense bi-encoders struggle with vocabulary mismatch and structural execution paths. RepoCoder~\cite{zhang2023repocoder} demonstrated that iterative retrieval loops improve code completion but incur multi-turn token inflation. Aider~\cite{gauthier2023aider} introduced repository maps using Tree-sitter AST tags ranked by PageRank. Graph-guided agents such as RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent} equip frontier models with graph traversal tools to navigate codebases interactively. While LocAgent~\cite{chen2025locagent} fine-tunes specialized models for multi-turn graph traversal, Perron investigates zero-shot localization under compact open weights (Gemma 4 2B/4B), isolating the exact point where un-annotated graph expansion collapses into distractor accumulation. AutoCodeRover~\cite{zhang2024autocoderover} navigates ASTs through iterative search queries. In SWE-agent~\cite{yang2024sweagent}, specialized agent-computer interfaces improve resolve rates. Conversely, Agentless~\cite{xia2025agentless} demonstrated that a simple two-phase pipeline (hierarchical localization followed by test-filtered patch generation) resolves ~32\% of SWE-bench Lite (FSE 2025) without an agent loop, highlighting that simple pipelines establish strong baselines. These systems employ large hosted models; this paper evaluates whether graph expansion assists a small 2B model in a single scoring pass.

\paragraph{Random-Walk Retrieval on Graphs}
Scalable diffusion on graphs builds on push-based approximate Personalized PageRank~\cite{andersen2006local}, decoupled propagation architectures such as APPNP~\cite{klicpera2019predict}, and scalable indexing frameworks like PPRGo~\cite{bojchevski2020scaling}. In link prediction, rooted PageRank and stationary-normalized hitting times~\cite{liben2007link} discount popular nodes by global stationary reachability. While HippoRAG~\cite{gutierrez2024hipporag} demonstrated that Personalized PageRank over open-domain text knowledge graphs outperforms iterative retrieval, and Dong et al.~\cite{dong2024dont} showed that graph-based reranking connects isolated retrieval chunks in retrieval-augmented generation, software call graphs present static AST structures with high-in-degree utility hubs (logging routines, assertion helpers) that appear as unseeded intermediate nodes that absorb diffusion mass regardless of initial weights. Perron extends this decoupled random-walk lineage (APPNP~\cite{klicpera2019predict}, PPRGo~\cite{bojchevski2020scaling}) to static compiled CSR code multigraphs, replacing dynamic entity extraction with post-walk specificity ratio damping over static CSR matrices.

\paragraph{Program Slicing and Fault Localization}
Classical program slicing~\cite{weiser1984program} computes backward executable slices on statement-level Program Dependence Graphs (PDGs), but conservative alias analysis often retains 50\% to 80\% of an application's codebase. Spectrum-Based Fault Localization (SBFL)~\cite{pearson2017evaluating,zou2021empirical} evaluates test coverage matrices to score statement suspiciousness. Pearson et al.~\cite{pearson2017evaluating} showed that fault-localization findings on artificial faults do not reliably transfer to real-world software defects, motivating authentic issue evaluation on SWE-bench~\cite{jimenez2024swebench}. Perron extracts symbol-level AST multigraphs to pack relevant contexts into prompt budgets ($K \le 4,096$) without requiring test execution during retrieval.

\paragraph{Graph Verbalization and Reasoning Complexity in Language Models}
How structured graphs are presented to language models critically governs their reasoning efficacy. Fatemi, Halcrow, and Perozzi~\cite{fatemi2023talk} demonstrated that graph verbalization functions alter reasoning accuracy by $+4.8\%$ to $+61.8\%$, with unannotated text dumps failing to convey relational topology. In repository-level engineering, RepoGraph~\cite{ouyang2025repograph} observed that directly flattening 2-hop code graphs degrades SWE-bench resolve rates from 28.3\% to 26.0\% (below baseline) due to distractor accumulation. Furthermore, Sanford, Fatemi, Perozzi et al.~\cite{sanford2024understanding} proved that while single-layer transformers ($\mathsf{Depth1}$) solve basic retrieval lookups, graph reachability and $s$-$t$ connectivity are $\mathsf{NL}$-complete, mathematically requiring logarithmic depth or extra test-time reasoning tokens ($\mathsf{LogDepthPause}$). Consistent with Sanford et al.'s~\cite{sanford2024understanding} finding that relational reasoning in transformers requires intermediate token steps, empirical evaluations show that injecting static provenance comments without reasoning tokens (C2) fails to separate candidates, while test-time thinking traces (\texttt{<thought>}) allow compact models to traverse topological paths. Consequently, compact open-weights models cannot resolve multi-hop code graph paths in a single forward pass without explicit provenance and intermediate reasoning traces.

\paragraph{Pointwise versus Listwise Reranking}
Pointwise language model scoring (e.g., MonoT5~\cite{nogueira2020document}) evaluates each candidate independently. Under independent scoring, the expected number of distractors that outscore a gold target with score $s^*$ scales with candidate pool cardinality: $\mathbb{E}[X \mid s^*] = \sum_{j=1}^{M-1} (1 - F_{\text{dist}, j}(s^*))$. Consequently, expanding candidate pool size $M$ under a compact pointwise scorer risks distractor accumulation unless model discrimination is near-perfect. In contrast, listwise and setwise architectures~\cite{sun2023rankgpt,pradeep2023setwise} introduce direct cross-candidate attention competition, mitigating distractor dominance.

\subsection{Multiplex Transition Matrix Construction}
A codebase is represented as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where $\mathcal{V}$ denotes AST code symbols (classes, functions, methods) and $\mathcal{E}$ spans relations $r \in \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$. Directed edges $(u, v) \in \mathcal{E}_{\text{call}}$ indicate that symbol $u$ invokes $v$, while $(u, v) \in \mathcal{E}_{\text{inherit}}$ represent class C3 Method Resolution Order inheritance, $(u, v) \in \mathcal{E}_{\text{import}}$ represent module imports, and $(u, w) \in \mathcal{E}_{\text{caller}}$ denote reverse call invocations.

Relations receive asymmetric static weights:
\begin{equation}
W_{uv} = \omega_{\text{call}} A^{(\text{call})}_{uv} + \omega_{\text{inherit}} A^{(\text{inherit})}_{uv} + \omega_{\text{import}} A^{(\text{import})}_{uv} + \omega_{\text{caller}} A^{(\text{caller})}_{uv},
\label{eq:edge_weight}
\end{equation}
where $\boldsymbol{\omega} = [0.50, 0.25, 0.15, 0.10]$ and $A^{(r)}_{uv} = \mathbb{I}((u, v) \in \mathcal{E}_r)$. Let $D_u = \sum_{v} W_{uv}$ be the out-degree sum. The row-stochastic transition matrix $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ and dangling indicator $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ are defined as:
\begin{equation}
T_{uv} = \begin{cases} \frac{W_{uv}}{D_u}, & D_u > 0 \\ 0, & D_u = 0 \end{cases}, \quad d_u = \begin{cases} 1.0, & D_u = 0 \\ 0.0, & D_u > 0 \end{cases}.
\label{eq:stochastic_matrix}
\end{equation}

Memory-mapped ingestion via \texttt{numpy.load(mmap\_mode='r')} opens the CSR representation directly from disk. Post-walk specificity ratio evaluation requires only $\mathcal{O}(|\mathcal{V}|)$ vector arithmetic, eliminating runtime edge mutations and memory reallocation.

\subsection{Personalized PageRank Diffusion and Linear Algebraic Bounds}
Random walk diffusion models the propagation of bug relevance across call hierarchies. The Google transition operator $M$ with damping factor $\beta = 0.85$ is formulated as:
\begin{equation}
M = \beta \cdot (T + \mathbf{d} \mathbf{p}_0^\top) + (1 - \beta) \cdot \mathbf{1} \mathbf{p}_0^\top.
\label{eq:google_matrix}
\end{equation}

By the rank-1 perturbation spectrum of the Google matrix~\cite{haveliwala2003second}, the second-largest eigenvalue is strictly bounded by $|\lambda_2(M)| \le \beta = 0.85$, establishing an invariant spectral gap $1 - |\lambda_2(M)| \ge 1 - \beta = 0.15$ and ensuring geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance. Power iteration stops on residual $\|\boldsymbol{\pi}^{(t+1)} - \boldsymbol{\pi}^{(t)}\|_1 < 10^{-6}$, converging in at most 90 iterations on Requests (1.89 ms) and 66 iterations on SymPy (5.10 ms). By the regenerative renewal property of Markov chains with teleportation, the stationary distribution of the closed operator $M$ is algebraically identical to the normalized leaky resolvent $(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}$ (discrepancy $< 2 \times 10^{-8}$). Full proofs of the Brauer spectral bound, barycentric linearity, and leaky resolvent equivalence are provided in Appendix~\ref{app:spectral_proofs}.

\subsection{Decoupled Specificity Ratio Hub-Damping}
\label{sec:specificity}
Personalized PageRank concentrates probability mass on high-in-degree hub nodes. To suppress structural popularity without mutating the static matrix $T$, Perron computes a repository-wide stationary baseline $\boldsymbol{\pi}_{\text{global}}$ once per codebase using a uniform prior $\mathbf{p}_{\text{uniform}} = \frac{1}{|\mathcal{V}|} \mathbf{1}$. For any query, the Specificity Score is defined as:
\begin{equation}
\operatorname{Specificity}(v) = \frac{\pi_{\text{query}}(v)}{(\pi_{\text{global}}(v) + \epsilon)^{\gamma}},
\label{eq:specificity}
\end{equation}
where $\epsilon = 10^{-8}$ and $\gamma = 0.70$. Resistance to hub congestion is measured by the Hub Suppression Index at top 10 (HSI@10):
\begin{equation}
\text{HSI@10} = 1.0 - \frac{|\text{top-10} \cap \mathcal{H}_{25}|}{10},
\label{eq:hsi_metric}
\end{equation}
where $\mathcal{H}_{25}$ denotes the set of top-25 global in-degree hub nodes in the repository multigraph. The asymptotic Pointwise Mutual Information (PMI) decomposition and Neumann series analysis showing why pre-walk scaling cannot prevent sink absorption are detailed in Appendix~\ref{app:spectral_proofs}.

\subsection{Hierarchical AST Breadcrumb Context Packing}
To deliver localized code context within prompt budgets ($K \le 4,096$), Perron packs candidate symbols using hierarchical AST breadcrumb skeletons. For each candidate function, the enclosing class definition, docstring, and signature are preserved while stripping irrelevant sibling function bodies. Breadcrumb skeletons bound the context footprint to $<100$ tokens per symbol, keeping syntax parseable and variable bindings intact.

\section{Study Design and Hash-Committed Protocol}
\label{sec:protocol}

\subsection{Benchmark and Task Waterfall}
SWE-bench Verified~\cite{jimenez2024swebench} contains 500 tasks across 12 canonical Python repositories. To establish an unbiased held-out benchmark and prevent data leakage, instances are filtered via a mutually exclusive, collectively exhaustive (MECE) waterfall:
\begin{equation}
\begin{aligned}
\text{Total Verified (500)} - \text{Lite Overlap (93)} &= \text{Held-Out (407)}, \\
\text{Held-Out (407)} - \text{AST Drift (56)} - \text{Non-Callable (7)} &= \mathbf{344\text{ Callable Tasks}}.
\end{aligned}
\label{eq:waterfall}
\end{equation}
The 344 callable tasks ($\mathcal{S}_{\text{func}}$) define the callable, AST-parsable evaluation cohort of SWE-bench Verified possessing identifiable reference function targets. The 56 AST drift exclusions reflect legacy repository commits with syntax errors (such as Python 2/3 transitions) that fail standard AST parsing uniformly across all methods prior to candidate generation. Hyperparameters ($\beta=0.85, \gamma=0.70, \tau=0.15, K=25$) were fixed on development data and frozen prior to evaluation.

\paragraph{Defect Accessibility Strata}
To evaluate whether graph traversal selectively assists un-named defect localization, tasks are partitioned into three mutually exclusive strata based on issue text lexical visibility: (1)~\textbf{Stratum~A (Named, $N=\StratumACount$, \StratumAPct)}, where issue text explicitly names the gold function, method, or qualified class identifier; (2)~\textbf{Stratum~B (Traceback, $N=\StratumBCount$, \StratumBPct)}, where issue text includes a traceback or explicit file path pointing to the gold source file, but omits the function name; and (3)~\textbf{Stratum~C (Un-Named, $N=\StratumCCount$, \StratumCPct)}, where issue text contains neither the function name nor a traceback pointing to the target file. Strata are annotated via a deterministic regex extraction pipeline (\texttt{perron.analysis.strata}), validated by a manual dual-pass verification audit across 50 randomly sampled tasks with 100\% concordance, released in \texttt{swebench-strata-annotations} (CC0-1.0).

\subsection{Hash-Committed Protocol}
The study operates under two hash-committed protocol locks:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Retrieval Protocol Lock}: Frozen and publicly pushed at Git commit \href{https://github.com/yvliet/perron/commit/6908e78}{\texttt{6908e78}} on October 5, 2026 (protocol SHA-256: \texttt{89416e40\dots}; split SHA-256: \texttt{95c7ef3c\dots}).
    \item \textbf{Gemma 4 Pointwise Protocol Lock}: Frozen in two cryptographic stages (\path{benchmarks/protocol/gemma4_protocol_v1.yaml}, raw SHA-256: \texttt{96af1621\dots}; Stage~2 lock \path{gemma4_lock_v1.json}, raw SHA-256: \texttt{dbbf2920\dots}) under Gate~G0 protocol commits \href{https://github.com/yvliet/perron/commit/a13ab34}{\texttt{a13ab34}} (Stage~1 freeze) and \href{https://github.com/yvliet/perron/commit/9abe405}{\texttt{9abe405}} (Stage~2 cryptographic lock) on October 6, 2026.
\end{enumerate}

\subsection{Candidate Pools and Matched-Control Arms}
Candidate pools are generated per task, matched to size $M_t = 10 + \min(|E_t|, 40) \in [10, 50]$ (mean $24.5$, median $22.0$), where $E_t$ denotes 1-hop out-neighbors of top-10 lexical seeds $S$ passing Filter~$F$ (functions/methods only, excluding test nodes and top-25 hubs $\mathcal{H}_{25}$):
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{B0 (Unscored BM25)}: Lexical candidates in native Okapi BM25 score order.
    \item \textbf{A1 (Seeds Only)}: Top-10 lexical seeds $S$ ($M=10$).
    \item \textbf{A2 (Depth-Matched BM25)}: $S$ followed by the next BM25 candidates passing Filter~$F$ up to $M_t$.
    \item \textbf{A3 (Same-File Control)}: $S$ followed by symbols in seed files passing Filter~$F$ up to $M_t$.
    \item \textbf{A4 (Graph 1-Hop Expansion)}: $S$ followed by $E_t$ ordered by adjacency $a(u) = \sum_{s \in S} p_0(s) T_{su}$.
    \item \textbf{A5 (Null Graph Control)}: Degree-preserving relation-stratified null graph replicate up to $M_t$.
    \item \textbf{A6 (Perron Diffusion Pool)}: Candidates ordered by Perron specificity scores up to $M_t$.
\end{itemize}

\paragraph{Mechanism Explaining Pool Recall vs.\ Reachability (201 vs.\ 199 Tasks)}
A4 achieves candidate pool oracle recall on 201/344 tasks (58.4\%), whereas unweighted 1-hop BFS reachability reaches 199/344 tasks (57.8\%). This 2-task divergence is mechanistically explained by two counterbalancing operations in the pool builder: seed test-node masking replaces test-file seeds with source seeds, recovering 16 tasks (e.g., \texttt{sympy-13372}), while Filter~$F$ degree-capping and hub pruning drop 14 tasks (e.g., \texttt{sphinx-7590}), yielding a net difference of $+2$ tasks ($199 + 16 - 14 = 201$).

\subsection{Pointwise Gemma 4 Scorer}
Each candidate symbol is formatted into a prompt context averaging 423.1 tokens (issue description + AST breadcrumb + prompt instructions; breadcrumbs alone average $<100$ tokens). A frozen \texttt{gemma-4-e2b-it} model (FP16, thinking disabled) scores each candidate in a single forward pass: $s(t, v) = \operatorname{logsumexp}(z[Y]) - \operatorname{logsumexp}(z[N])$ on prompt variant P0, chosen on disjoint development data ($N=100$). The evaluation required 19,298 forward passes.

\subsection{Statistical Analysis}
A localization hit (Function Acc@$k$) is scored as 1.0 if at least one ground-truth modified function is present in the top-$k$ retrieved symbols, and 0.0 otherwise. The confirmatory family comprises two pre-specified contrasts on strict Acc@5:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{PC1}: $A_4 - A_2$ (Graph 1-hop vs.\ Depth-matched BM25).
    \item \textbf{PC2}: $A_4 - A_3$ (Graph 1-hop vs.\ Same-file matched).
\end{itemize}
Contrasts are evaluated using exact two-sided McNemar tests with step-down Holm--Bonferroni correction over family $\alpha=0.05$. Paired 95\% confidence intervals are estimated via repository-stratified bootstrapping ($B=10{,}000$). Post-hoc Contrasts are evaluated with repository-stratified bootstrap confidence intervals and exact McNemar tests.

\paragraph{Confirmatory Findings and Power Bounds}
Graph 1-hop expansion (A4) reaches 47.1\% Acc@5 compared to 45.1\% for depth-matched BM25 (A2, $\Delta = +2.03$ pp, 95\% CI [$-$0.29, +4.36], Holm $p=0.287$) and 45.6\% for same-file matching (A3, $\Delta = +1.45$ pp, 95\% CI [$-$0.58, +3.78], Holm $p=0.302$). Both contrasts are classified as null-compatible (bootstrap 95\% CIs span zero; Holm $p > 0.05$). With 17 discordant tasks ($n_{10}=12, n_{01}=5$, discordant proportion $p_{\text{disc}} = 4.94\%$), the analytical minimum detectable effect size (MDE) at $\alpha=0.05$ and $80\%$ statistical power is $3.27$ pp (11.3 tasks). Reliably detecting a subtle $+2.03$ pp gain ($n_{10}-n_{01}=+7$) at $80\%$ power would require $N = 942$ tasks under SWE-bench's native 4.94\% discordance rate. Under Two One-Sided Tests (TOST), the upper $95\%$ bootstrap confidence bound ($+4.36$ pp) allows formally excluding true population advantages $\ge +4.4$ pp ($p < 0.05$). The empirical investigation thus rules out large localization gains ($>4.4$ pp, $\sim 15$ tasks) from unguided 1-hop graph expansion, while recognizing that this sample resolution cannot isolate sub-2 pp shifts.

\paragraph{Candidate Pool Ceiling Parity}
Candidate pool oracle recall is identical: 58.4\% (201/344) for both graph expansion ($A_4$) and depth BM25 ($A_2$). Across discordant tasks, $n_{10}=18$ and $n_{01}=18$ (two-sided McNemar $p=1.0000$). With 36 discordant pairs, the 95\% CI on the recall difference is approximately $\pm 3.4$ pp. Because Acc@$k$ cannot exceed pool recall, both pools establish an identical theoretical ceiling on this sample.

\paragraph{Exploratory Comparisons}
Comparing graph expansion arm A4 to seed reranking (A1, 46.2\% Acc@5) yields a net gain of 3 tasks ($\Delta = +0.87$ pp, $n_{10}=7, n_{01}=4, p=0.549$). Gemma 4 gains 7 top-5 hits (6 from newly reachable targets, 1 from seed promotion) while distractors displace 4 existing seed hits (gross 7/4 split: $159+7-4=162$), requiring 4,988 extra model forward passes (a $2.45\times$ compute increase over seeds). Comparing A4 to the degree-preserving null graph (A5, 45.9\% Acc@5) yields $\Delta = +1.16$ pp (95\% CI [$-$0.58, +2.91], $n_{10}=7, n_{01}=3, p=0.344$), demonstrating that empirical graph topology provides no statistically detectable advantage over randomized degree-matched graphs. Similarly, comparing A4 to the Perron diffusion pool (A6, 45.6\% Acc@5) yields $\Delta = +1.45$ pp (95\% CI [+0.00, +3.20], $n_{10}=7, n_{01}=2, p=0.180$). Unscored BM25 (B0) preserves nominally higher MRR@50 (0.3439 vs.\ 0.3409) and top-1 accuracy (25.3\% vs.\ 24.7\%) than A4. Leave-Django-Out jackknife cross-validation ($N=230$) maintains candidate pool parity (57.1\% vs.\ 57.1\%, $p=1.0000$) and yields $\Delta = +2.17$ pp for $A_4 - A_2$ ($p=0.227$).

\paragraph{Model Sensitivity and Lexical Bottlenecks}
To test whether the flatline reflects an insensitive scorer rather than graph retrieval limits, I evaluated within-pool discrimination directly from the \texttt{scores.parquet} evaluation archive. Raw Okapi BM25 scores achieve a within-pool ROC-AUC of \textbf{0.8245}, which explains why unscored BM25 preserves higher top-1 accuracy (25.3\%) and MRR@50 (0.3439). Gemma~4 log-odds scores separate gold targets from distractors with an overall within-pool ROC-AUC of \textbf{0.7796}. Decomposing this discriminative ability by target provenance reveals a marked disparity: Gemma~4 achieves an ROC-AUC of \textbf{0.7966} on seed-gold targets, but drops to \textbf{0.6596} on graph-only gold targets (a degradation of nearly 0.14). Furthermore, Reciprocal Rank Fusion (RRF, $k_{\text{rrf}}=60$) combining BM25 prior rank with Gemma log-odds reaches \textbf{46.51\%} Acc@5 (160/344), exceeding both BM25 (44.77\%) and Gemma reranking (46.22\%). This demonstrates that the empirical plateau does not reflect generic model insensitivity, but rather a boundary in representation: compact language models evaluate bug relevance predominantly through surface token overlap, encountering a lexical abstraction bottleneck where non-lexical gold functions uncovered by graph traversal cannot be recognized without explicit call-path traces or dense semantic representations.

\paragraph{The Break-Even Discrimination Bound}
To quantify why candidate pool expansion plateaus under pointwise scoring, consider candidate pool dynamics under the Wilcoxon--Mann--Whitney formulation. In a candidate pool of size $M$ (comprising one target and $M - 1$ distractors), the probability that a distractor outranks the gold target under a scorer with within-pool ROC-AUC is $1 - \text{AUC}$. The expected number of outranking distractors is:
\begin{equation}
\label{eq:breakeven}
\mathbb{E}[X \mid s^*] = (M - 1)(1 - \text{AUC})
\end{equation}
yielding an expected gold target rank of $\mathbb{E}[\text{Rank}] = 1 + (M - 1)(1 - \text{AUC})$. For the target to land within the top-$k$ ($\mathbb{E}[\text{Rank}] \le k$), the reranker must satisfy:
\begin{equation}
\label{eq:auc_threshold}
\text{AUC}^*_{\text{breakeven}} \ge 1 - \frac{k - 1}{M - 1}
\end{equation}
Figure~\ref{fig:breakeven_bound}a formalizes this dynamic across candidate pool sizes $M \in [5, 50]$. This formulation provides an expected-rank diagnostic bound for two-stage retrieve-and-rerank architectures: whenever candidate pool expansion outpaces scorer discrimination, expanding candidate recall dilutes precision through distractor accumulation. Across SWE-bench Verified, candidate pools average $M = 24.5$ items. At $k = 5$, maintaining an expected rank within the top-5 requires $\text{AUC}^*_{\text{breakeven}} \ge 1 - \frac{4}{23.5} = 0.8298$ ($\approx 83.0\%$). While Gemma~4 achieves an ROC-AUC of $0.7966$ on seed targets (yielding $\mathbb{E}[X] \approx 4.78$, placing seeds around expected rank 5.8), its discrimination degrades to $0.6596$ on graph-only targets ($N=25$, 95\% CI [0.552, 0.767]), as illustrated in the empirical raincloud distributions of Figure~\ref{fig:breakeven_bound}b. At $\text{AUC} = 0.6596$, expected outranking distractors rises to $23.5 \times (1 - 0.6596) = 8.00$, pushing newly reached graph targets to an expected rank of $9.00$ (and $17.68$ in pools capped at $M=50$). Graph targets enter the candidate pool, but are probabilistically suppressed from surfacing into top-5 positions without higher scorer discrimination.

\paragraph{Stratum Asymmetry on Graph-Only Targets}
Deconstructing the 25 tasks where graph expansion recalled targets absent from seeds ($A_4 \setminus A_1$) reveals systematic polarization by issue lexical structure:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Stratum A (Named)}: 11 graph-only targets were reached, of which 6 converted into top-5 hits (54.5\% conversion, landing at ranks 1, 1, 2, 2, 3, and 4). Accounting for 1 seed promotion and 2 displaced seed hits, graph expansion yields $+5$ net tasks on Stratum~A (7 wins vs.\ 2 losses, exact binomial $p = 0.1797$).
    \item \textbf{Stratum C (Un-Named)}: 14 graph-only targets were reached, of which 0 converted into top-5 hits (0.0\% conversion, mean rank 16.3). With 2 seed hits displaced by graph distractors, graph expansion yields $-2$ net tasks on Stratum~C (0 wins vs.\ 2 losses, exact binomial $p = 0.5000$).
\end{itemize}
The aggregate net gain of $+3$ tasks ($+0.87$ pp, $p=0.549$) is thus the arithmetic sum of $+5$ tasks gained on lexically anchored bugs and $-2$ tasks lost on un-named bugs. 1-hop graph expansion is viable when guided by lexical anchors, but degrades in localization accuracy when surface tokens are absent.

\subsection{Causal Call-Path Provenance and Selective Routing}
\label{sec:causal_provenance}

The empirical plateau observed in Section~\ref{sec:rq2} and Section~\ref{sec:stratum_c} raises a fundamental mechanistic question: does the lack of graph advantage reflect an intrinsic limitation of static call graphs, or does it stem from an informational deficit in how candidate code locations are presented to the language model?

In the baseline protocol, candidate breadcrumbs strip all graph provenance, presenting only isolated function signatures:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\scriptsize]
# File: django/db/models/query.py (Lines 450-480)
def _batched_insert(self, objs, fields, batch_size, ignore_conflicts=False):
    """Helper for bulk_create to partition inserts into batches."""
\end{lstlisting}
On Stratum~C (un-named defects), the issue description never mentions \texttt{\_batched\_insert}. Because the breadcrumb omits the call-edge connecting it to the seed function (\texttt{bulk\_create}), the model cannot discern why an un-named helper function is relevant, yielding random outranking ($\text{AUC} \approx \ControlTwoGraphAuc$, expected rank 16.3). Decomposing within-pool discrimination reveals that the AUC drop on graph-only targets ($\Delta = \ControlTwoMicroGap$, seed AUC \ControlTwoSeedAuc\ vs graph AUC \ControlTwoGraphAuc, Mann--Whitney $U=2993$, $p \ControlTwoMannWhitneyP$, Cliff's $\delta = \ControlTwoCliffsDelta$) is partly driven by candidate pool selection conditioning (Control~2): seeds are selected from top-10 BM25 symbols with high query overlap, whereas graph-only targets lack surface tokens by definition. Counterfactual BM25 evaluation on the identical pairs exhibits a parallel drop (AUC $\le 0.30$), indicating that the lower discrimination reflects structural candidate difficulty under selection conditioning rather than an intrinsic model pathology.

\paragraph{Topological Provenance Audit of Graph-Only Targets}
To evaluate this mechanism causally, I audited the 25 tasks where 1-hop graph expansion successfully reached a defect absent from lexical seeds ($A_4 \setminus A_1$). Resolving structural relations against repository multigraph layers revealed that \textbf{24 of the 25 targets (96.0\%)} possess a direct, 1-hop static relationship with an issue seed:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]\sloppy
    \item \textbf{Direct Callee (\texttt{called\_by\_seed}, 10 tasks)}: Target is invoked by a seed (e.g., \texttt{\_batched\_insert} called by \texttt{bulk\_create} in \texttt{django-11951}; \texttt{as\_compatible\_data} in \texttt{xarray-2905}; \texttt{filter\_members} in \texttt{sphinx-8035}).
    \item \textbf{Direct Caller (\texttt{calls\_seed}, 14 tasks)}: Target invokes a seed (e.g., \texttt{validate\_ipv6\_address} calling \texttt{is\_valid\_ipv6\_address} in \texttt{django-13212}; \texttt{load\_middleware} in \texttt{django-13810}; \texttt{handle} in \texttt{django-16116}).

\paragraph{Mechanistic Insights and Empirical Factorial Parity}
Comparing Condition~C3 directly with Condition~C0 indicates that static call-path annotations provide no measurable advantage over unguided thinking traces ($\Delta = -0.76$ pp on Acc@1, exact two-sided McNemar $p = 1.0000$, discordant pairs $n_{10}=1, n_{01}=2$; factorial interaction $\Delta_{\text{interaction}} = -2.29$ pp, $-3$ hits). Across both arms, 11 of the 13 top-1 hits overlap identically. This parity points to a clear representational trade-off: allocated reasoning tokens allow the model's self-attention layers to trace error propagation directly from raw code signatures, rendering explicit prompt-level edge annotations redundant. In effect, test-time compute substitutes for structural prompt engineering.

Thinking traces average $\sim 120$ tokens ($\le 180$ budget), adding $10\text{--}15$ seconds of decode latency at \GemmaDecodeTokensSec\ tokens/sec on an entry-level Tesla T4 (and $<3$ seconds on desktop workstations at $50+$ tokens/sec). This grounds the systems trade-off in interactive developer latency: while CSR spectral diffusion is near-instantaneous ($1.89\text{--}5.10$~ms), allocating a modest 10-second thinking phase converts un-named defects without resorting to multi-minute cloud agent loops. Partitioning the 35 in-pool defects by seed proximity clarifies where test-time reasoning provides traction:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Seed-Adjacent Targets ($N=28$)}: For defects located in the immediate call-tree of lexical seeds, allocated thinking tokens help the model discriminate among local callers, raising top-1 localization from \CausalSeedCOneAccOne\ (3/28) in C1 to \textbf{\CausalSeedCZeroAccOne} (12/28) in both C0 and C3 on Acc@1 (+32.2 pp), and top-5 accuracy from \CausalSeedCOneAccFive\ to \CausalSeedCZeroAccFive.
    \item \textbf{Distant Graph Targets ($N=7$, Exploratory)}: For structural targets lacking direct seed overlap, isolated baseline snippets fail entirely (0/7 hits, \CausalGraphOnlyCOneAccOne). Thinking mode recovers \CausalGraphOnlyCZeroHitsFiveKN\ of the 7 targets into the top-5 (\CausalGraphOnlyCZeroAccFive, with \CausalGraphOnlyCZeroAccOne\ top-1 hit). While the overall lift across Stratum~C ($N=131$) is statistically significant ($p = 0.0063^*$), confirming separation on distant graph targets alone at $\alpha=0.05$ with 80\% power requires expanding the cohort to $N \ge 942$ tasks under SWE-bench's native 4.94\% discordance rate.
\end{itemize}

\paragraph{Causal Lexical Dissection and Multi-Encoding Graph Representations}\sloppy
To evaluate the mechanism of the Topological Disambiguation Deficit, I executed two pre-registered interventions (\texttt{PREREG\allowbreak -CAUSAL\allowbreak -v1}) on Kaggle Dual Tesla T4 GPUs across the reachable in-pool Stratum~C tasks ($N=58$, 58/131 tasks) with \texttt{google/\allowbreak gemma-4-e2b-it} (Table~\ref{tab:causal_ablation}):

While $\alpha$-renaming removes surface function names, attribute lookups, docstrings, and string literals remain intact. The model retains 10.34\% top-1 localization without function identifiers, indicating that control-flow syntax and operator structures establish a resilient representational baseline.
    \item \textbf{Graph Prompt Serialization Hierarchy}: Testing the graph serialization taxonomy of Fatemi et~al.~\cite{fatemi2023talk} reveals that prompt format governs code localization. Co-locating structural relations directly above symbol signatures ($E_1$: Inline Comment Provenance) achieves \textbf{\CausalEncCommentAccOne} Acc@1, \textbf{\CausalEncCommentAccFive} Acc@5, and an MRR of \textbf{\CausalEncCommentMRR}, lifting top-1 accuracy over isolated baseline snippets (\CausalEncBaselineAccOne, \textbf{\CausalEncCommentLiftTopOne\ pp lift}, unadjusted exact binomial McNemar \textbf{$p \CausalEncCommentVsBaseTopOneP$*}, Wilcoxon signed-rank $W=31.5$, \textbf{$p \CausalEncCommentVsBaseMRRP$*}). \paragraph{Selective Gating and Task Heterogeneity}
Rather than reflecting uniform performance across repositories, the aggregate null result conceals systematic task-level heterogeneity. On lexically explicit defect reports (Stratum A, $N=208$), 1-hop graph expansion yields a net gain of $+5$ localized tasks over seeds. On un-named symptom reports (Stratum C, $N=131$), unguided expansion introduces distractors that cause a net loss of $-2$ tasks under pointwise scoring. Deployable gating using issue symbol density via a cross-validated decision tree achieves 47.38\% Acc@5 (163/344 tasks, parity with uniform graph expansion at 47.09\%). To characterize the theoretical limit of selective routing, an oracle stratum routing policy ($\pi^*$, assuming ground-truth stratum knowledge) reaches 47.67\% (164/344 tasks, +2.90 pp over BM25), approaching the two-arm oracle ceiling ($48.55\%$, 167 tasks) with zero discordant losses ($n_{10}=2, n_{01}=0$). Furthermore, an oracle combination routing Stratum~A through pointwise graph expansion and Stratum~C through listwise reranking reaches 49.50\% Acc@5 (148/299 tasks on Strata A and C). While deployable lexical-density heuristics currently recover baseline parity, closing the gap to the 49.50\% oracle ceiling requires test-time classifiers that detect un-named defect descriptions without target knowledge.

\paragraph{Architectural Implication: Operating Regimes of Static Code Graphs}
The $3.68\times$ bottleneck ratio defines a practical operating regime for developer agent architectures. Static AST multigraphs provide an efficient, low-overhead candidate filter for the \RerankPoolOracleRecall\ of defects that propagate along explicit syntactic edges. However, for the \RerankBoundaryLossPP~pp of defects outside static reachability (dynamic dispatch, reflection, implicit ORM descriptors, and configuration-driven injection), static graph expansion cannot assist by construction. For these defects, attempting multi-hop static traversal is counterproductive, expanding candidate pools to hundreds of nodes without improving discriminatory rank. Consequently, local developer agents must treat static CSR diffusion as an initial lightweight filter ($<5$~ms, $\le 3$~MB RAM): when issue symbol density or retrieval confidence is low, agent architectures should switch to dynamic execution signals (runtime stack traces, failing test pytest fixtures, or dense semantic embeddings) rather than expanding static graph radius.

\section{Threats to Validity and Limitations}
\label{sec:threats}
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Programming Language Scope}: Evaluation is restricted to Python AST dependency networks. While directed multigraph diffusion is language-agnostic, static call graphs miss dynamic runtime dispatch, reflection (\texttt{getattr}), and monkey-patching. To support other languages, Perron's core multigraph representation and typed schema ($\mathcal{E}_{\text{call, inherit, import, caller}}$) are decoupled from Python ASTs, and the library provides Tree-sitter extractors for TypeScript and polyglot extension (\texttt{perron.polyglot}).
    \item \textbf{Model Capacity and Prompting}: Findings are established on compact models from the Gemma~4 family (E2B and E4B). Within-pool ROC-AUC of Gemma scores separating gold from distractors reaches 0.7796 overall (0.7966 on seed gold vs.\ 0.6596 on graph-only gold), showing genuine discriminative ability for lexically aligned targets that degrades on non-lexical graph hops. Reciprocal Rank Fusion (RRF) fusing BM25 rank and Gemma score reaches 46.51\% (160/344), outperforming both raw BM25 (44.77\%) and pure Gemma reranking (46.22\%). While live GPU execution on Stratum~C demonstrated that listwise contrastive prompting prevents distractor degradation (+8.40 pp Acc@5, $p=0.0034$), graph expansion still tied depth BM25 (16.79\% vs.\ 16.79\%). Evaluating multi-turn agentic environments with larger frontier models remains an important frontier.
    \item \textbf{Candidate Pool Bounds}: Pools evaluate 1-hop expansion capped at 50 candidates ($M_t \le 50$). Multi-hop expansion reaches 66.9\% oracle recall but introduces hundreds of distractors.
    \item \textbf{Heuristic Stacking and Distractor Accumulation}: A common engineering instinct is to stack auxiliary repository signals (such as historical git commit churn or static complexity metrics). However, in power-law software networks, un-gated feature stacking exacerbates distractor accumulation: function-level churn exhibits weak defect correlation ($\text{AUC} < 0.60$) and suffers from PR squash-merge clique noise ($O(K^2)$ edge density connecting documentation to logic), while complexity metrics are collinear with size (LOC), creating artificial god-file attractor sinks. Perron deliberately enforces sparse, high-precision AST topology combined with prompt-level provenance verbalization, avoiding heuristic distractor inflation.
    \item \textbf{Task Scope}: Restricted to $N=344$ function-level tasks on SWE-bench Verified. While downstream code modifications were verified via AST surgical editing ($N=30$, 0.0\% syntax errors vs 50.0\% under unified diffs) and reader localization ($N=100$), executing complete repository test suites across all 344 instances remains an active engineering goal. Defect localization establishes the strict upper bound on downstream patch resolution: an agent cannot correct an unlocated defect~\cite{xia2025agentless}. Evaluating candidate localization in isolation decouples the primary representation bottleneck from orthogonal factors such as multi-turn tool orchestration, Docker environment setup, and execution timeouts.
    \item \textbf{Statistical Power and Equivalence}: With 17 discordant tasks ($p_{\text{disc}} = 4.94\%$), the 95\% CI on PC1 ([$-$0.29, +4.36] pp) yields an analytical MDE of $3.27$ pp at $80\%$ power. Under Two One-Sided Tests (TOST), the upper bound allows formally excluding true population advantages $\ge +4.4$ pp ($p < 0.05$). The study excludes practically large gains ($\ge +4.4$ pp), though detecting the full-benchmark shift of +2.03 pp with 80\% power requires $N \ge 942$ tasks under SWE-bench's native 4.94\% discordance rate.
    \item \textbf{Post-Training Pathways}: Evaluated models utilize zero-shot prompting with frozen weights. While test-time \texttt{<thought>} traces resolve the abstraction bottleneck, post-training compact models on call-path provenance presents a compelling architectural direction. Formulating Provenance-Conditioned Direct Preference Optimization (DPO)~\cite{rafailov2023direct} over verified execution traces $\mathcal{P}$,
    \begin{equation}
        \mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l, \mathcal{P})}\left[\ln \sigma\left(\beta \ln \frac{\pi_\theta(y_w \mid x, \mathcal{P})}{\pi_{\text{ref}}(y_w \mid x, \mathcal{P})} - \beta \ln \frac{\pi_\theta(y_l \mid x, \mathcal{P})}{\pi_{\text{ref}}(y_l \mid x, \mathcal{P})}\right)\right],
    \end{equation}
    provides a mathematically principled objective to internalize structural graph priors directly into transformer weights without runtime token overhead.
\end{enumerate}

\section{Conclusion}
\label{sec:conclusion}
On 344 held-out tasks of SWE-bench Verified, 1-hop graph expansion yields no statistically detectable advantage over matched lexical controls under frozen Gemma 4 scorers (47.1\% vs 45.1\%, Holm $p=0.287$). Candidate truncation curves confirm that expanding pool breadth under pointwise scoring yields flat localization via distractor accumulation, while compact models stumble against a lexical abstraction bottleneck (0.7966 ROC-AUC on seeds vs 0.6596 on graph neighbors). Grounded in transformer graph complexity theory, factorial evaluation across pool architectures and reasoning modes confirms that test-time reasoning traces resolve this bottleneck: on the matched graph candidate pool ($A_4$), test-time reasoning traces more than double Top-1 localization on un-named defects from \MatchedGraphDirectAccOne\ (6 hits) to \MatchedGraphThinkingAccOne\ (13 hits; \MatchedGraphDeltaAccOnePp\ pp lift, \MatchedGraphRelLiftAccOneRatio\ relative gain, exact binomial $p = 0.039^*$; MRR $+45.4\%$). Crucially, reasoning interacts oppositely across pool architectures, resolving ambiguity on structural graphs ($\Delta_{\text{interaction}} = +5.34$ pp, $+7$ net tasks) while inducing distractor bias on lexical pools. Factorial contrast against topological provenance prompting reveals empirical parity ($p = 1.0000$), demonstrating that intermediate thinking tokens allow model representations to trace relational dependencies directly. Furthermore, pre-registered causal interventions (\texttt{PREREG-CAUSAL-v1}, $N=58$) confirm that control-flow syntax alone provides a resilient structural foundation under complete lexical obfuscation ($-1.73$ pp Top-1 drop under AST $\alpha$-renaming, $p=1.0000$), while co-locating call-path provenance as inline code comments reaches \CausalEncCommentAccOne\ ($+13.79$ pp lift, unadjusted $p=0.0386^*$, $p_{\text{holm}}=\CausalEncCommentHolmP$) through localized seed bridging, outperforming disconnected edge lists ($+10.34$ pp, $p=0.0703$). Downstream AST editing achieves 0.0\% syntax errors ($p < .001$ vs unified diffs). Paired with Perron's high-throughput CSR diffusion engine, these findings show that code graphs require test-time compute or localized structural provenance to unlock local developer agent performance. Under tight context budgets ($K \le 4,096$), local agents should: (1) gate graph expansion dynamically based on lexical anchor density (+0.29 pp deployable; +2.90 pp theoretical stratum oracle ceiling); (2) allocate test-time reasoning tokens; (3) format candidate graph structure as localized inline provenance; (4) prioritize compact AST breadcrumbs ($<100$ tokens/symbol, preserving 91.9\% reasoning headroom); and (5) structure reranking listwise rather than pointwise to eliminate distractor dilution.

\section{Linear Algebraic Formulations and Theoretical Proofs}
\label{app:spectral_proofs}

\subsection{Brauer Rank-1 Spectral Bound and Second Eigenvalue}
\label{prop:spectral_gap_proof}
Let $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ be a directed multigraph and $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ be the row-substochastic transition matrix defined in Equation~\ref{eq:stochastic_matrix}. Let $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ denote the dangling node indicator ($d_u = 1$ if $D_u = 0$, else $0$). The completed stochastic matrix $\bar{T} = T + \mathbf{d} \mathbf{p}_0^\top$ satisfies $\bar{T} \mathbf{1} = \mathbf{1}$. The Google transition operator with damping factor $\beta \in (0, 1)$ is formulated as:
\begin{equation}
M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top.
\end{equation}

By the Brauer rank-1 perturbation theorem applied to Markov transition matrices~\cite{haveliwala2003second}:
Let $A$ be an $n \times n$ matrix with eigenvalues $\lambda_1, \lambda_2, \dots, \lambda_n$, and let $\mathbf{x}_1$ be the right eigenvector associated with $\lambda_1$. For any vector $\mathbf{y} \in \mathbb{R}^n$, the perturbed matrix $A + \mathbf{x}_1 \mathbf{y}^\top$ has eigenvalues $\lambda_1 + \mathbf{y}^\top \mathbf{x}_1, \lambda_2, \dots, \lambda_n$.

In this formulation, setting $A = \beta \bar{T}$ yields eigenvalues $\beta \lambda_1(\bar{T}), \beta \lambda_2(\bar{T}), \dots, \beta \lambda_n(\bar{T})$. Because $\bar{T}$ is row-stochastic, its principal eigenvalue is $\lambda_1(\bar{T}) = 1$ with right eigenvector $\mathbf{x}_1 = \mathbf{1}$. Setting $\mathbf{y} = (1 - \beta) \mathbf{p}_0$ gives:
\begin{equation}
M = \beta \bar{T} + \mathbf{1} ((1 - \beta) \mathbf{p}_0)^\top.
\end{equation}
The principal eigenvalue of $M$ becomes:
\begin{equation}
\lambda_1(M) = \beta \lambda_1(\bar{T}) + ((1 - \beta) \mathbf{p}_0)^\top \mathbf{1} = \beta + (1 - \beta) = 1.
\end{equation}
All remaining eigenvalues satisfy:
\begin{equation}
\lambda_i(M) = \beta \lambda_i(\bar{T}), \quad \forall i \ge 2.
\end{equation}
Because $\bar{T}$ is row-stochastic, the Gershgorin circle theorem establishes $|\lambda_i(\bar{T})| \le 1$ for all $i$. Therefore, the second-largest eigenvalue is strictly bounded:
\begin{equation}
|\lambda_2(M)| \le \beta \cdot 1.0 = \beta.
\end{equation}
For $\beta = 0.85$, the spectral gap is uniformly lower-bounded:
\begin{equation}
1 - |\lambda_2(M)| \ge 1 - \beta = 0.15,
\end{equation}
yielding geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance regardless of graph density or disconnected components.

\subsection{Barycentric Linearity and Basis Warping Bounds}
\label{prop:convex_hull_proof}
Following Jeh and Widom~\cite{jeh2003scaling}, let $\mathbf{p}_0 = \sum_{i=1}^K w_i \mathbf{e}_{s_i}$ be any convex combination of query seed nodes with $w_i \ge 0$ and $\sum w_i = 1.0$. The stationary distribution $\boldsymbol{\pi}(\mathbf{p}_0)$ lies in the convex hull of the basis distributions:
\begin{equation}
\boldsymbol{\pi}(\mathbf{p}_0) = \sum_{i=1}^K \tilde{w}_i \boldsymbol{\pi}(\mathbf{e}_{s_i}) \in \operatorname{conv}\left(\{\boldsymbol{\pi}(\mathbf{e}_{s_i})\}_{i=1}^K\right), \quad \tilde{w}_i = \frac{w_i m_i}{\mathbf{w}^\top \mathbf{m}},
\end{equation}
where basis mass satisfies $m_i = \|(1-\beta) \mathbf{e}_{s_i} (I - \beta T)^{-1}\|_1 \in [1-\beta, 1.0]$. The maximum coordinate warping ratio is bounded by:
\begin{equation}
\frac{\max_i m_i}{\min_j m_j} \le \frac{1}{1 - \beta} = \frac{1}{0.15} \approx 6.67.
\end{equation}

\subsection{Markov Renewal Equivalence to Normalized Leaky Resolvents}
\label{prop:renewal_proof}
In the closed Markov chain $M$, dangling nodes restart according to the query teleport distribution $\mathbf{p}_0$. By the regenerative renewal property of Markov chains with state-independent resets, the stationary probability $\boldsymbol{\pi}_{\text{closed}}$ of the closed chain $M$ is algebraically identical to the normalized leaky resolvent vector:
\begin{equation}
\boldsymbol{\pi}_{\text{leaky}} = \frac{(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}}{\|(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}\|_1}.
\end{equation}
Across all 12 canonical SWE-bench repositories, the maximum numerical discrepancy satisfies:
\begin{equation}
\|\boldsymbol{\pi}_{\text{closed}} - \boldsymbol{\pi}_{\text{leaky}}\|_1 = 1.68 \times 10^{-8} < 2 \times 10^{-8},
\end{equation}
confirming exact algebraic equivalence.

\subsection{Asymptotic Pointwise Mutual Information (PMI) Decomposition}
\label{prop:pmi_proof}
For any code symbol $v$ with positive query support, the log-transformed Specificity score satisfies:
\begin{equation}
\ln \operatorname{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \operatorname{PMI}(v; q) - \gamma \ln\left(1 + \frac{\epsilon}{\pi_{\text{global}}(v)}\right).
\end{equation}
When $\pi_{\text{global}}(v) \gg \epsilon$, the residual vanishes, yielding a convex interpolation between raw reachability ($\gamma=0$) and surprise ($\gamma=1$), where the sub-linear exponent $\gamma = 0.70$ acts as a structural Inverse Document Frequency (IDF) discount.

\subsection{Neumann Series Expansion and Sink Absorption}
\label{prop:neumann_proof}
The Neumann series expansion of Personalized PageRank illustrates why pre-walk scaling cannot prevent sink absorption on software dependency graphs:
\begin{equation}
\boldsymbol{\pi} = (1-\beta)\sum_{t=0}^{\infty}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t}, \quad \Big\|\boldsymbol{\pi} - (1-\beta)\sum_{t=0}^{m}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t}\Big\|_1 = \beta^{m+1}.
\end{equation}
Walks of length $t \ge 3$ carry approximately 61\% of total diffusion mass ($\beta^3 \approx 0.614$ at $\beta=0.85$). Multi-step transitions $\bar{T}^t$ funnel mass toward scale-free sink hubs regardless of initial weights $\mathbf{p}_0'$. Perron's decoupled post-walk ratio divides the converged vector $\boldsymbol{\pi}$, scaling every walk length simultaneously and enforcing high Hub Suppression Index (HSI@10).

\section{Perron CSR SpMM Engine Architecture and Systems Benchmarks}
\label{app:csr_benchmarks}
The Perron engine is implemented in pure Python and optimized C with zero-copy memory-mapped CSR ingestion:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Ingestion Latency}: Loading a precomputed repository CSR graph from NVMe storage via memory-mapped \texttt{numpy.load} takes $<1.2$~ms warm attach ($46.97$~ms cold start) across all repositories.
    \item \textbf{Memory Footprint}: Isolated graph array resident set size (RSS) delta is $\le 3.0$~MB, while total process peak RSS during SpMM diffusion is bounded below 144.33~MB RAM even on SymPy ($|\mathcal{V}|=37{,}442$, $|\mathcal{E}|=148{,}912$).
    \item \textbf{Throughput Comparison}: Compared to standard NetworkX PageRank (320~ms on Requests) and Scipy sparse iterative solvers (28~ms), Perron executes vectorized sparse power iteration in $1.89$~ms on Requests (90 iterations, amortizing to $\sim 0.021$~ms per inner-loop SpMV step) and $5.10$~ms on SymPy (66 iterations, $\sim 0.077$~ms per step; $196\text{--}529$~qps; standalone single-step Python API calls incur $0.17\text{--}0.45$~ms dispatch overhead), achieving up to a $>50\times$ speedup suitable for interactive developer agent tool loops.
\end{itemize}

\section{Continuous Dose-Response Surface Across 186 Prior Configurations}
\label{app:dose_response}
To evaluate the entropy dispersion hypothesis systematically, a continuous resolvent basis benchmark was evaluated across the 344 Verified evaluation tasks (63,984 SpMM solves) across four parametric families:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Softmax Family}: $\mathbf{p}_0(i) \propto \exp(s_i / \tau)$ for top-$K$ seeds ($\tau \in [0.05, 1.0]$).
    \item \textbf{Power Family}: $\mathbf{p}_0(i) \propto s_i^p$ ($p \in [0.5, 4.0]$).
    \item \textbf{Linear Truncated}: $\mathbf{p}_0(i) \propto s_i$ over top-$K$ seeds ($K \in [5, 100]$).
    \item \textbf{Rank-Zeta Family}: $\mathbf{p}_0(i) \propto i^{-\alpha}$ ($\alpha \in [0.2, 2.0]$).
\end{enumerate}
Across all 186 configurations, Function Acc@10 exhibits a statistically significant quadratic relationship with prior effective support $n_{\text{eff}} = \exp(H(\mathbf{p}_0))$ ($p < 0.001$, binomial GLMM $R^2 = 0.197$), peaking near $n_{\text{eff}}^* \approx 8.8$ at 50.9\%, which exactly ties Okapi BM25 (50.9\%).

\section{Lexical Accessibility Annotation Protocol}
\label{app:strata_protocol}
Tasks are categorized into three mutually exclusive strata:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Stratum A (Named, $N=208$, 60.5\%)}: Issue text explicitly mentions the target function name, method identifier, or qualified class name.
    \item \textbf{Stratum B (Traceback, $N=5$, 1.5\%)}: Issue text includes a stack trace or direct file path pointing to the target file, but omits the function name.
    \item \textbf{Stratum C (Un-Named, $N=131$, 38.1\%)}: Issue text describes the symptom or behavior without mentioning the target symbol or providing a traceback.
\end{itemize}
Annotation was validated via a manual dual-pass verification audit across 50 randomly sampled tasks with 100\% concordance and is released in \texttt{swebench-strata-annotations} (CC0-1.0).

\section{Sparse MoE Quantization and Hardware Memory Limits}
\label{app:moe_quantization}
Evaluating Gemma~4 26B-A4B under protocol \texttt{PREREG\allowbreak -SCALING\allowbreak -v1} isolates a practical deployment constraint for mixture-of-experts developer agents. In modern deep learning frameworks, the 128 dynamic experts are instantiated as 3D weight tensors (\texttt{[num\_experts, in\_features, out\_features]}), which bypass standard 2D \texttt{bitsandbytes} NF4/INT8 linear layer quantization hooks without custom CUDA kernels. In unquantized 16-bit precision, expert parameters require \ScalingMoERequiredVRAM\ of VRAM, physically exceeding dual Tesla T4 capacity (\ScalingMoEAvailableVRAM). Attempting runtime CPU or disk offloading degrades inference speed below interactive usability. Consequently, while compact dense models ($\le 4$B parameters) operate smoothly within local GPU budgets ($\le 9.6$~GB), deploying high-capacity sparse MoE models for local developer agents requires ahead-of-time AWQ or GPTQ quantization formats with native 3D tensor support.
