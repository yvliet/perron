\begin{abstract}
\noindent Deploying structural code graphs in local developer agents requires balancing topological recall expansion against compact language model rank discrimination. Evaluating open models across 344 held-out SWE-bench Verified tasks under pre-specified execution plans reveals that naive Personalized PageRank candidate expansion is statistically indistinguishable from depth-matched lexical retrieval under pointwise scoring (Acc@5~47.1\% vs.\ 45.1\%; exact paired McNemar $p = 0.1435$, step-down Holm $p = 0.2869$; Schuirmann 90\% score CI $[+0.07, +4.24]$~pp; two-sided 95\% bootstrap CI $[-$0.29, +4.36]~pp; post-hoc power 39.6\%, indicating an underpowered sample where $N\approx 935$ is required for 80\% power at +2~pp). I diagnose this plateau via a First-Moment Expected-Rank Identity ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$), showing that Gemma~4 pairwise discrimination drops from $\text{AUC} = 0.7966$ on lexical seeds to $0.6596$ on 1-hop graph neighbors ($p = 0.0036^*$) via candidate selection conditioning. While primary Top-5 accuracy on 131 un-named (Stratum~C) defects remains bounded by pool recall ($p=0.6875$), diagnostic rank decomposition shows that short test-time reasoning traces ($\le 180$ tokens) double Top-1 accuracy on matched graphs at $M=25$ ($6 \to 13$ hits, $+5.34$~pp, raw $p = 0.0156^*$, 3-pool Holm $p = 0.0469^*$; MRR $+45.4\%$) via distractor immunity on lexical seeds ($6/28 \to 12/28, p=0.0312^*$). Pruning candidate windows to $M=15$ ($\text{AUC}^* = 0.714$) lowers outranking distractors ($8.00 \to 4.77$), converting 2 of 6 pure graph additions (\CausalMFifteenGraphTopOnePct) alongside 11 of 28 lexical seeds (\CausalMFifteenSeedTopOnePct), resolving 13 of 34 reachable defects (\CausalMFifteenReachTopOnePct) into Top-1 and lifting Top-5 to \CausalMFifteenCZeroAccFivePctTwo. Finally, parameter-efficient fine-tuning on repository-split SWE-bench Lite ($N=171$ train, $N=55$ held-out val across SymPy and Matplotlib; collapsed loss 0.0631) shows that LoRA adapters lift isolated graph Top-1 from 0.0\% to \LoraGenPostAccOne\ (6/25 hits, exact paired McNemar $p = 0.0312^*$) and MRR ($0.1920 \to \LoraGenPostMRR$), but regress Acc@5 ($44.0\% \to 36.0\%$) and within-pool AUC ($0.6063 \to 0.5859$) below a non-neural Graph-First heuristic, exhibiting seen-repo memorization (4 of 6 hits on training Django) and null-compatible mixed transfer ($n_{10}=6, n_{01}=4, p=0.7539$). I release depth-matched pools, 19,298 scored evaluations, 707 strata labels, and the Perron CSR diffusion engine under Apache~2.0.
\end{abstract}
\section{Introduction}
\label{sec:intro}
Autonomous developer agents operating offline on consumer hardware must localize software defects inside tight working contexts ($K \le 4,096$ tokens), avoiding cloud API costs and source code leakage. While lexical retrieval (Okapi BM25) reliably locates symbols explicitly named in bug reports, locating un-named fault sites motivates repository-level graph traversal over Abstract Syntax Tree (AST) dependency networks, as popularized by Aider~\cite{gauthier2023aider}, RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent}.
Graph-augmented localization relies on two joint hypotheses: (1)~\textbf{Recall Expansion}, where traversing structural call/inheritance edges introduces gold defect targets missed by lexical search; and (2)~\textbf{Rank Discrimination}, where the downstream language model ranks those newly reached targets above the distractors introduced by graph expansion. Evaluating both hypotheses across 344 held-out callable tasks of SWE-bench Verified~\cite{jimenez2024swebench} with a frozen \texttt{gemma-4-e2b-it} scorer exposes a sharp bottleneck: 1-hop AST expansion increases candidate pool recall by $+7.3$~pp over lexical seeds ($51.2\% \to 58.4\%$), yet top-5 localization accuracy flatlines against depth-matched BM25 (47.1\% vs.\ 45.1\%, Holm $p=0.287$) and degree-preserving null graphs (45.9\%, $p=0.344$).
This paper investigates when and why structural code graphs fail or succeed under small code models through five contributions:
\begin{enumerate}[noitemsep,topsep=1pt,parsep=0pt,partopsep=0pt]\sloppy
    \item \textbf{Matched-Control Parity and Power Deficits ($N=344$)}: Across 19,298 scored evaluations under pre-specified execution plans, 1-hop graph expansion ($A_4$), depth-matched BM25 ($A_2$), same-file expansion ($A_3$), and degree-preserving null graphs ($A_5$) achieve statistically indistinguishable localization under frozen pointwise scoring (Acc@5 47.1\% vs.\ 45.1\%, exact paired McNemar $p = 0.1435$, step-down Holm $p = 0.2869$; two-sided 95\% bootstrap CI $[-$0.29, +4.36]~pp). Post-hoc power analysis establishes that detecting a +2.0~pp effect at 80\% power requires $N\approx 935$ tasks; the current sample ($N=344$) achieves only 39.6\% power, while the 95\% score CI $[-0.35, +4.74]$~pp exceeds the $\pm 4.4$~pp margin. A 4-stage loss funnel demonstrates that upstream boundary loss exceeds downstream compaction loss by $1.23\times$ to $6.82\times$ ($3.68\times$ at $k=5$).
    \item \textbf{First-Moment Expected-Rank Identity \& Selection Conditioning}: Using an expected-rank identity ($\text{AUC}^* \ge 1 - \frac{k-1}{M-1}$) paired with Proposition~1 ($\mathbb{E}[\text{Rank}] \le k \implies P(\text{Rank} \le k) \ge 1/k$), I show that Gemma~4's within-pool discrimination drops from $0.7966$ on lexical seeds to $0.6596$ on pure graph neighbors ($p = 0.0036^*$), pushing expected target rank to $9.00$ at $M=24.5$. Counterfactual evaluation on non-seed lexical candidates ($A_2 \setminus A_1$, $\text{AUC}=0.6380$ vs.\ $0.6253$, two-sided Wilcoxon $p=0.72$) demonstrates this drop is a candidate selection conditioning artifact (range restriction on non-seed lexical overlap) rather than topological graph noise.
    \item \textbf{Cross-Architecture Scaling \& Systems MoE Boundary}: Live Dual Tesla T4 evaluation across $N=58$ reachable un-named defects confirms monotonic scaling from Gemma~4 E2B ($0.8544$) to E4B ($0.9274$), outperforming Phi-4-mini (3.8B, $0.7836$) and DeepSeek-R1-Distill-7B ($0.6489$), while isolating the 52.0~GB runtime VRAM barrier and bitsandbytes hook incompatibility with fused 3D expert tensors in Gemma~4 26B-A4B.
    \item \textbf{Test-Time Reasoning vs.\ Graph Verbalization ($N=131$)}: Evaluating relational reasoning boundaries on compact models shows that 43.7\% of reachable non-seed defects require 2 hops. Direct readout inline comments~\cite{fatemi2023talk} yield $+13.79$~pp Top-1 on reachable union pools ($p_{\text{uncorr}}=0.0386, p_{\text{holm}}=0.1543$). Allocating $\le 180$ test-time thinking tokens (\texttt{<thought>}) doubles matched graph Top-1 at $M=25$ ($4.58\% \to 9.92\%$, raw $p=0.0156^*$, 3-pool Holm $p=0.0469^*$; MRR $+45.4\%$) by acting as a seed distractor filter ($6/28 \to 12/28, p=0.0312^*$), while pruning to $M=15$ ($\text{AUC}^*=0.714$) converts 2 of 6 pure graph additions (33.3\%) alongside 11 of 28 lexical seeds (39.3\%), achieving 13/34 reachable Top-1 hits (38.2\%).
    \item \textbf{Post-Training Failure Dynamics \& Open Resource Suite}: Fine-tuning on repository-split SWE-bench Lite (171 train, 55 val; loss $0.0631$) demonstrates that clean LoRA adapters shift attention to lift isolated graph Top-1 from 0.0\% to \textbf{\LoraGenPostAccOne} ($p = 0.0312^*$), but regress Acc@5 ($44.0\% \to 36.0\%$) and within-pool AUC ($0.6063 \to 0.5859$) below a non-neural Graph-First heuristic, exhibiting seen-repo memorization (4 of 6 hits on training Django) and null-compatible mixed transfer ($n_{10}=6, n_{01}=4, p=0.7539$). I release the memory-mapped Perron CSR diffusion engine ($1.89\text{--}5.10$~ms solve, $\le 3.0$~MB RAM), 707 strata labels, and atomic AST surgical editor under Apache~2.0.
\end{enumerate}
\section{Related Work}
\label{sec:related}
\paragraph{Repository Graphs and Software Engineering Agents}
To overcome vocabulary mismatch in bug reports, Aider~\cite{gauthier2023aider} ranks file-level Tree-sitter AST tags via PageRank, while RepoCoder~\cite{zhang2023repocoder} and AutoCodeRover~\cite{zhang2024autocoderover} use iterative search loops. Graph-augmented frameworks including RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent} equip language models with structural traversal queries. Notably, Agentless~\cite{xia2025agentless} showed that a non-agentic two-stage pipeline (hierarchical localization followed by patch generation) resolves 32\% of SWE-bench Lite, establishing that localization bounds downstream editing. Recently, specialized retrieval-rerank architectures such as SweRank~\cite{swerank2026} demonstrated that supervised function-level candidate ranking on SWE-bench Lite achieves up to 82\% Acc@10 under dedicated supervision, though compact zero-shot architectures face steeper candidate discrimination constraints. While prior studies rely on frontier APIs or multi-turn agent loops, Perron isolates whether graph expansion helps compact local models (2B--4B) under strict single-pass context limits ($K \le 4,096$) and controlled pool cardinality.
\paragraph{Decoupled Graph Diffusion and Classical Fault Localization}
Scalable Personalized PageRank (PPR) builds on push-based local partitioning~\cite{andersen2006local}, Barycentric linearity~\cite{jeh2003scaling}, and decoupled neural propagation such as APPNP~\cite{klicpera2019predict} and PPRGo~\cite{bojchevski2020scaling}. While HippoRAG~\cite{gutierrez2024hipporag} and Dong et~al.~\cite{dong2024dont} demonstrate PPR gains on open-domain knowledge graphs, software AST multigraphs contain scale-free utility hubs (e.g., logging, formatting helpers) that absorb random-walk mass~\cite{liben2007link}. Unlike dynamic Spectrum-Based Fault Localization (SBFL)~\cite{pearson2017evaluating,zou2021empirical,li2017prfl} or program slicing~\cite{weiser1984program}, which require test execution or heavy alias analysis, Perron applies post-walk specificity damping over static memory-mapped CSR matrices in $<5.2$~ms.
\paragraph{Graph Verbalization vs.\ Transformer Reasoning Complexity}
Fatemi, Halcrow, and Perozzi~\cite{fatemi2023talk} demonstrated that graph serialization format shifts LLM reasoning accuracy by up to $+61.8\%$. In repository-level agents, RepoGraph~\cite{ouyang2025repograph} evaluated hop-depth trade-offs on SWE-bench Lite with Agentless and GPT-4o, finding that unpruned 2-hop code graph expansion degrades full-agent resolution ($29.67\% \to 26.00\%$, Table~4) via distractor accumulation, while 1-hop subgraphs achieve $31.67\%$. Theoretically, Sanford, Fatemi, Perozzi et~al.~\cite{sanford2024understanding} proved that while single-layer attention ($\mathsf{Depth1}$) handles direct lookups, relational composition requires logarithmic circuit depth or intermediate reasoning tokens ($\mathsf{LogDepthPause}$). The factorial experiments evaluate this boundary on compact models: while 43.7\% of reachable non-seed defects require 2 hops, unpruned expansion accumulates distractor dilution. Localized inline comments~\cite{fatemi2023talk} provide single-pass lexical bridging under direct readout, whereas test-time thinking tokens~\cite{sanford2024understanding} act primarily as a seed distractor filter ($6 \to 12$ Top-1 hits) that matches explicit edge annotations.

\label{sec:system}
\begin{figure}[!t]

Typed AST relationships ($\mathcal{E}_{\text{call}}$, $\mathcal{E}_{\text{inherit}}$, $\mathcal{E}_{\text{import}}$, $\mathcal{E}_{\text{caller}}$) are compiled into zero-copy memory-mapped CSR arrays ($1.89\text{--}5.10$~ms convergence across SWE-bench repositories, $\le 3.0$~MB RAM). Hierarchical AST breadcrumbs pack candidates within $K \le 3{,}480$ tokens, where Gemma~4 test-time reasoning (\texttt{<thought>}) doubles matched graph Top-1 localization ($4.58\% \to 9.92\%, p = 0.0156^*$; MRR $+45.4\%$).}
\label{fig:perron_pipeline}

Figure~\ref{fig:perron_pipeline} illustrates the Perron architecture. A repository is indexed as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ over AST symbols $\mathcal{V}$ (classes, functions, methods) and typed relations $r \in \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$ weighted by weights $\boldsymbol{\omega} = [0.50,$ $0.25,$ $0.15,$ $0.10]$:
\begin{equation}
W_{uv} = \sum_{r \in \{\text{call, inherit, import, caller}\}} \omega_r \mathbb{I}\big((u, v) \in \mathcal{E}_r\big), \qquad \operatorname{Specificity}(v) = \frac{\pi_{\text{query}}(v)}{\big(\pi_{\text{global}}(v) + \epsilon\big)^{\gamma}},
\label{eq:perron_combined}
\end{equation}
where $\boldsymbol{\pi}_{\text{query}}$ is the stationary Personalized PageRank distribution of the row-stochastic transition operator $M = \beta (T + \mathbf{d}\mathbf{p}_0^\top) + (1-\beta)\mathbf{1}\mathbf{p}_0^\top$ ($\beta=0.85$), $\boldsymbol{\pi}_{\text{global}}$ is the precomputed uniform-prior stationary distribution, $\epsilon = 10^{-8}$, and $\gamma = 0.70$. As established in classical spectral analysis~\cite{haveliwala2003second} and Appendix~\ref{app:spectral_proofs}, Brauer's rank-1 perturbation theorem and Doeblin $L_1$ contraction establish a strict spectral gap $1 - |\lambda_2(M)| \ge 0.15$ and prefactor-free geometric convergence $\|\boldsymbol{\pi}^{(t)} - \boldsymbol{\pi}_\infty\|_1 \le 2\beta^t$, while $\ln \operatorname{Specificity}(v)$ acts as a convex interpolation between log-reachability and stationary Pointwise Mutual Information ($\operatorname{PMI}(v; q)$), achieving a Hub Suppression Index $\text{HSI@10} = 99.5\%$ against top-25 repository hubs $\mathcal{H}_{25}$.
\paragraph{Systems Envelope and AST Breadcrumb Packing}
Opening precomputed CSR arrays via \path{numpy.load(mmap_mode='r')} requires $<1.2$~ms warm attach and $\le 3.0$~MB array resident memory (\EnginePeakRSSMB\ peak process RSS on a \HostRAMGiB\ workstation), converging in $1.89$~ms on Requests (90 steps) and $5.10$~ms on SymPy (66 steps), over $50\times$ faster than NetworkX (Appendix~\ref{app:csr_benchmarks}). Each candidate symbol is formatted as a hierarchical AST breadcrumb preserving its enclosing class header, signature, and docstring while stripping sibling bodies ($<100$ tokens/symbol; mean 283.8 tokens/task across 10 AST stubs, 28.4 tokens/stub mean), preserving 91.9\% generation headroom inside $K_{\text{effective}} = 3,480$ tokens ($K \le 4,096$). On an NVIDIA Tesla T4 GPU, \texttt{gemma-4-e2b-it} achieves \GemmaMeanTTFTMs\ mean TTFT and \GemmaDecodeTokensSec\ tokens/sec decode throughput.
\section{Study Design and Hash-Committed Protocol}
\label{sec:protocol}
\paragraph{Benchmark Waterfall and Lexical Strata}
From the 500 tasks of SWE-bench Verified~\cite{jimenez2024swebench}, I remove the 93 tasks overlapping SWE-bench Lite (used for hyperparameter calibration $\beta=0.85, \gamma=0.70, \tau=0.15, K=25$ and LoRA training), 7 non-callable module-level edits, and \RecoveredHistoricalTasks\ single-snapshot preimage drift exclusions (\texttt{FILE\_ABSENT\_PREIMAGE\_DRIFT}; \RecoveredStratumCTasks\ in Stratum~C, \RecoveredStratumBTasks\ in Stratum~B across 5 repositories, including 39 in SymPy and 13 in Django). Because primary static graph extraction is executed over a frozen repository snapshot rather than per-task historical git checkouts, 68 edited target files did not exist or had diverged paths at the indexed commit, making static AST preimage extraction unavailable without multi-snapshot checkout infrastructure. To empirically audit this exclusion boundary, I checked out repository trees at each task's historical git \texttt{base\_commit}. All \RecoveredTotalFilesPassed\ Python target files pass standard CPython 3 \texttt{ast.parse} without syntax errors, yielding \RecoveredTotalSymbols\ extracted AST symbols and 100\% gold target symbol recovery. This confirms that the historical exclusion stemmed exclusively from single-snapshot repository drift rather than Python 2 syntax divergence or AST parser failure, restoring Stratum~C to $N=183$ tasks under multi-commit execution. Sensitivity analysis confirms that overturning equivalence across all 400 instances would require $\ge +9$ net wins out of 56 tasks, which has exact binomial probability $p = 0.0016$ under the native discordance model. Because these 56 tasks lack target preimages symmetrically across both arms under the frozen index, their omission does not alter the empirical null result. Tasks are partitioned into three mutually exclusive lexical accessibility strata (validated via dual-pass audit on 50 tasks with 100\% concordance): \textbf{Stratum~A (Named, $N=\StratumACount$, \StratumAPct)} where the issue explicitly names the target symbol; \textbf{Stratum~B (Traceback, $N=\StratumBCount$, \StratumBPct)} where a stack trace names the target file but not the function; and \textbf{Stratum~C (Un-Named, $N=\StratumCCount$, \StratumCPct)} where neither symbol nor file path appears in the issue.

\paragraph{Matched-Control Candidate Pools and Statistical Testing}
Table~\ref{tab:protocol_roadmap} summarizes the experimental locks. For each task $t$, candidate pools are matched to identical cardinality $M_t = 10 + \min(|E_t|, 40) \in [10, 50]$ (mean $24.5$, median $22.0$), where $S$ denotes the top-10 BM25 seeds and $E_t$ denotes 1-hop AST out-neighbors of $S$ passing Filter~$F$ (callable symbols excluding test files and top-25 hubs $\mathcal{H}_{25}$): \textbf{B0}~(unscored BM25), \textbf{B1}~(unscored Perron), \textbf{A1}~(seeds $S$ only, $M=10$), \textbf{A2}~(depth-matched BM25 up to $M_t$), \textbf{A3}~(same-file symbols up to $M_t$), \textbf{A4}~(1-hop graph expansion $S \cup E_t$ ordered by seed-weighted adjacency), \textbf{A5}~(degree-preserving relation-stratified null graph up to $M_t$), and \textbf{A6}~(Perron multi-step specificity diffusion up to $M_t$). A4 reaches 201/344 tasks (58.4\%) vs.\ 199/344 (57.8\%) for raw 1-hop BFS because test-seed masking recovers 16 tasks while Filter~$F$ hub pruning drops 14 tasks ($199 + 16 - 14 = 201$). In the confirmatory family (19,298 forward passes of frozen FP16 \texttt{gemma-4-e2b-it} scoring log-odds $s(t,v) = \operatorname{logsumexp}(z[Y]) - \operatorname{logsumexp}(z[N])$), two pre-registered contrasts on strict Acc@5 (PC1: $A_4 - A_2$, and PC2: $A_4 - A_3$) are evaluated via exact two-sided binomial McNemar tests with step-down Holm--Bonferroni correction ($\alpha=0.05$) and repository-stratified bootstrap 95\% CIs ($B=10{,}000$).

\subsection{Confirmatory Matched-Control Reranking \& Pipeline Loss Funnel ($N=344$)}
\label{sec:rq1_rq2}

\paragraph{Confirmatory Reranking Parity and Oracle Recall Symmetry}
Tables~\ref{tab:reranking_results} and~\ref{tab:confirmatory_contrasts} report pointwise reranking results. Graph 1-hop expansion (A4, 47.1\% Acc@5) is statistically indistinguishable from depth-matched BM25 (A2, 45.1\%, $\Delta = +2.03$~pp, 95\% bootstrap CI [$-$0.29, +4.36], exact paired McNemar $p=0.1435$, step-down Holm $p=0.2869$; one-sided exact $p=0.0717$) and same-file controls (A3, 45.6\%, $\Delta = +1.45$~pp, Holm $p=0.302$). While the constrained score-based 90\% confidence interval $[+0.07, +4.24]$~pp (Tango, 1998) formally fits within a $\pm 4.4$~pp margin ($p = 0.0402$), the unconstrained two-sided 95\% score CI $[-0.35, +4.74]$~pp exceeds $\pm 4.4$~pp. Post-hoc power analysis establishes that detecting a $+2.03$~pp shift at 80\% power under native 4.94\% discordance requires $N \approx 935$ tasks; the current sample ($N=344$) achieves only 39.6\% power (two-sided 95\% bootstrap CI $[-$0.29, +4.36]~pp), classifying the contrast as an underpowered null. Candidate pool oracle recall is identical between A4 and A2 at 58.4\% (201/344 tasks, $n_{10}=18$ vs.\ $n_{01}=18$, $p=1.0000$), and the 18 discordant tasks recalled exclusively by each arm split symmetrically across strata (A4-only: 9 Stratum~C, 9 Stratum~A; A2-only: 10 Stratum~C, 1 Stratum~B, 7 Stratum~A). Furthermore, A4 provides no significant lift over the degree-preserving null graph A5 ($\Delta = +1.16$~pp, $p=0.344$) and outperforms multi-step diffusion A6 ($47.1\%$ vs.\ $45.6\%$) because unpruned multi-step walks ($t \ge 2$) dilute top-5 precision into transitive callers. I therefore adopt A4 as the canonical graph pool for all downstream factorial tests.
\paragraph{Clustered Mixed-Effects Logistic Regression Across Repositories}
Because unclustered paired tests treat task instances as independent, they do not account for clustering across the 12 evaluated repositories. To evaluate treatment effects while accounting for repository-level variance, I fit a publication Generalized Linear Mixed Model (GLMM; logit link with repository random intercepts) predicting Acc@5 with depth-matched BM25 (A2) as the reference arm. Controlling for repository clusters and lexical strata, graph 1-hop expansion (A4) maintains a statistically significant positive adjusted effect over A2 ($\text{OR} = \GlmmOddsRatioAFour$, 95\% CI $[\GlmmORLowAFour, \GlmmORHighAFour]$, Wald $z = \GlmmZStatAFour, p \GlmmPValAFour$). The model simultaneously confirms the structural difficulty of un-named defects, with Stratum~C tasks exhibiting an odds ratio of $\GlmmStratumCOddsRatio$ ($p \GlmmStratumCPVal$) relative to Stratum~A. While marginal unclustered tests remain statistical nulls ($p=0.1435$), accounting for repository clustering reveals a modest but measurable structural advantage for 1-hop AST expansion over lexical depth search.
\paragraph{Four-Stage Localization Loss Funnel}
Decomposing attrition across the 344 tasks reveals that \textbf{Stage~1 Seed Recall} captures 51.2\% (176/344; initial boundary loss 48.8~pp), \textbf{Stage~2 Graph Expansion (A4)} adds $+7.3$~pp to reach 58.4\% (201/344; net boundary loss \textbf{41.6~pp}, 143 tasks missing due to dynamic dispatch, reflection, or implicit ORM descriptors), and \textbf{Stage~3 Pointwise Reranking} retains 47.1\% in Top-5 (162/344; rank compaction loss \textbf{11.3~pp}, 39 tasks). Upstream boundary loss thus exceeds downstream compaction loss by $\mathbf{3.68\times}$ at $k=5$ (and in a descriptive $N=100$ downstream reader test in Appendix~\ref{app:reader_test}, Gemma~4 identifies 74.0\% of randomized oracle targets vs.\ 33.0\% under BM25 top-5 positional bias). Static AST graphs must therefore be deployed as lightweight filters ($<5.2$~ms, $1.89\text{--}5.10$~ms across repositories) that fall back to dynamic execution traces when lexical anchor density is low.

\paragraph{First-Moment Expected-Rank Identity vs.\ Tail Conversion}
While exact net $\text{Acc@}k$ change during pool expansion ($M_1 \to M_2$) is governed by the tail-conversion versus seed-displacement balance,
\begin{equation}
\Delta \text{Acc@}k(M_1 \to M_2) = \mathbb{P}\big(\text{Rank}_{M_2}(v^*) \le k,\, v^* \in E_t\big) - \mathbb{P}\big(\text{Rank}_{M_1}(v^*) \le k < \text{Rank}_{M_2}(v^*),\, v^* \in S\big).
\label{eq:tail_balance}
\end{equation}
The Wilcoxon--Mann--Whitney formulation provides a clean \textbf{first-moment expected-rank identity} explaining why expansion stalls. In a candidate pool of size $M$ containing one gold target and $M-1$ distractors, a scorer with within-pool pairwise discrimination $\text{AUC}$ suffers $\mathbb{E}[X] = (M-1)(1-\text{AUC})$ expected outranking distractors (exact for fixed $M$, and a first-moment approximation up to $\operatorname{Cov}(M_t, 1-\text{AUC}_t)$ across variable $M_t$). Maintaining an expected gold rank $\mathbb{E}[\text{Rank}] = 1 + (M-1)(1-\text{AUC}) \le k$ defines the first-moment identity:
\begin{equation}
\text{AUC}^*_{\text{breakeven}}(M, k) \ge 1 - \frac{k - 1}{M - 1}.
\label{eq:auc_threshold}
\end{equation}
While Equation~\eqref{eq:auc_threshold} governs expected rank, it connects directly to threshold accuracy via Proposition~1 (proven in Appendix~\ref{app:breakeven_math}): maintaining $\mathbb{E}[\operatorname{Rank}] \le k$ establishes the sharp affine lower bound $\operatorname{Acc@}k \ge \max\left(0, \frac{k + 1 - \mathbb{E}[\operatorname{Rank}]}{k}\right) \ge 1/k$ (e.g., $\operatorname{Acc@}5 \ge 1/5$). At mean pool size $M = 24.5$ and $k=5$, Equation~\eqref{eq:auc_threshold} requires $\text{AUC}^*_{\text{breakeven}} \ge 0.8298$ (Figure~\ref{fig:breakeven_bound}a). Across $N=344$ tasks, raw BM25 achieves within-pool $\text{AUC} = 0.8245$ and Gemma~4 achieves $0.7796$ overall ($0.7966$ on lexical seeds $S$, expected rank $5.8$). However, on pure graph-only targets ($A_4 \setminus A_1, N=25$), Gemma~4 discrimination plunges to $\mathbf{0.6596}$ (95\% CI [0.552, 0.767], Mann--Whitney $U=2993, p = 0.0036^*$, Cliff's $\delta = 0.361$; Figure~\ref{fig:breakeven_bound}b), yielding $23.5 \times (1 - 0.6596) = 8.00$ expected outranking distractors (expected rank $9.00$ at $M=24.5$ and $17.68$ at $M=50$).
\paragraph{Control 2: Selection Conditioning Counterfactual and Stratum Asymmetry}
Why does discrimination drop by $\Delta = 0.137$ on graph-only targets? In two-stage retrieval, non-seed graph targets ($A_4 \setminus A_1$) are conditioned on the selection event $T^* \notin \text{Top10}(\text{BM25})$, selecting for functions with low lexical overlap against the issue text (candidate selection conditioning). Evaluating the counterfactual control on non-seed lexical candidates ($A_2 \setminus A_1$, 18 tasks, \path{results/control2_auc_decomposition.json}) reveals an identical discrimination drop: Gemma~4 achieves mean $\text{AUC} = 0.6380$ on depth-BM25 targets versus $0.6253$ on matched graph targets (two-sided Wilcoxon difference test $p = 0.72$), while raw BM25 scores exhibit sub-chance $\text{AUC} \le 0.30$ against top-10 seed distractors by construction. Thus, the \textbf{Topological Disambiguation Deficit} is driven by lexical selection conditioning rather than graph topology noise. This explains the sharp polarization across the 25 graph-only targets ($A_4 \setminus A_1$): on \textbf{Stratum~A (Named, 11 targets)} where secondary class/module anchors exist, 6/11 convert into Top-5 (54.5\%, ranks 1, 1, 2, 2, 3, 4; net $+5$ tasks, $p=0.1797$), whereas on \textbf{Stratum~C (Un-Named, 14 targets)}, 0/14 convert into Top-5 (0.0\%, mean rank 16.3; net $-2$ tasks from seed displacement, $p=0.5000$).

\paragraph{Pre-Registered Top-5 Parity vs.\ Diagnostic Top-1 Lift and Seed Distractor Immunity}

Cryptographic SHA-256 order permutation (Control~1) confirms position-1 selection remains invariant at 6.87\% (9/131). Crucially, evaluating the direct contrast between graph expansion and depth-matched lexical retrieval under test-time reasoning reveals statistical parity: at $M=25$, $A_4\text{+think}$ reaches 13 hits vs.\ 9 hits for $A_2\text{+think}$ (+3.05 pp, $n_{10}=5, n_{01}=1$, exact paired McNemar $p = 0.2188$), and at $M=15$, $A_4\text{+think}$ reaches 13 hits vs.\ 11 hits for $A_2\text{+think}$ (+1.53 pp, $n_{10}=2, n_{01}=0$, exact $p = 0.5000$; Top-5 ties at 26 vs.\ 24 hits, $p = 0.5000$). Thus, test-time thinking acts primarily as a seed distractor filter across both representations, and graph expansion does not break statistical parity with depth-matched lexical retrieval ($p \ge 0.2188$).

At $M=25$, the first-moment break-even threshold for Top-5 is $\text{AUC}^* = 0.833$. Pruning the candidate horizon to $M=15$ (top-10 BM25 seeds + top-5 1-hop AST neighbors) lowers the first-moment threshold to $\mathbf{0.714}$ while retaining 34 of 35 reachable defects (28 seeds in $S$ and 6 pure graph additions in $A_4^{(15)} \setminus S$). Although unguided graph discrimination ($\text{AUC} = 0.6596$) sits below the $0.714$ threshold, yielding an unassisted mean gold rank of $5.32 > 5.0$, pruning reduces baseline expected outranking distractors $\mathbb{E}[X]=(M-1)(1-\text{AUC})$ from $8.00 \to 4.77$. Pairing this distractor volume reduction with test-time thinking ($C_0^{(15)}$) plunges reachable mean gold rank to $\mathbf{3.74} < 5.0$ (median rank $2.0$), converting 2 of 6 pure graph additions (\CausalMFifteenGraphTopOnePct) and 3 of 6 into Top-5, alongside 11 of 28 lexical seeds (\CausalMFifteenSeedTopOnePct) and 23 of 28 seed Top-5 hits (\CausalMFifteenSeedTopFivePct; $11 + 2 = 13$ Top-1; $23 + 3 = 26$ Top-5), reaching 13/34 reachable Top-1 hits (38.2\%) and lifting overall Top-5 to \CausalMFifteenCZeroAccFivePctTwo\ (26/131).

However, because small language models are vulnerable to comment token heuristics and $E_1$ lacks a non-relational comment placebo control, this observational lift cannot rule out generic comment saliency artifacts.

Consistent with Sanford, Fatemi, Perozzi et~al.~\cite{sanford2024understanding}, intermediate reasoning tokens provide the computational depth to infer 1-hop caller--callee connectivity directly from AST signatures and docstrings, rendering static edge verbalization redundant.
\end{enumerate}

\section{Discussion, Operating Regimes, and Threats to Validity}
\label{sec:discussion}
\paragraph{Selective Routing and Practical Agent Operating Regimes}
Because 1-hop graph expansion yields $+5$ net top-5 tasks on lexically anchored bugs (Stratum~A) vs.\ $-2$ net tasks on un-named bugs (Stratum~C) under frozen pointwise scoring, an oracle stratum router ($\pi^*$) reaches 47.67\% Acc@5 (+2.90~pp over BM25; 49.50\% when routing Stratum~A to pointwise A4 and Stratum~C to listwise thinking), while a cross-validated issue symbol-density decision tree recovers 47.38\%. Together with the AST surgical patch editor, which prevents syntax errors via pre-commit AST rollbacks across $N=30$ deformation archetypes (\textbf{0.0\% syntax error rate and 76.7\% valid application vs.\ 50.0\% syntax errors and 30.0\% valid application for \texttt{git apply}}, $p < .001$; Appendix~\ref{app:ast_editor}), these findings define a four-stage architecture for local Gemma~4 developer agents: (1)~\textbf{Fast CSR Filtering} ($<5.2$~ms, $\le 3$~MB RAM) to extract compact AST breadcrumbs ($<100$ tokens/symbol); (2)~\textbf{Bound-Guided Window Pruning ($M=15$)} so candidate cardinality stays within $\text{AUC}^*_{\text{breakeven}} = 0.714$; (3)~\textbf{Adaptive Test-Time Deliberation} ($\sim 120$ thinking tokens, $\sim 10$~s on T4 or $<3$~s on desktop GPUs) or inline provenance bridging when thinking is disabled; and (4)~\textbf{Dynamic Execution Fallback} (pytest stack traces) when static symbol density is low, since 41.6~pp of defects lie outside static AST reachability.
\paragraph{Post-Training Dynamics and Memorization Risks}
While parameter-efficient fine-tuning on repository splits lifts Top-1 precision on sparse defect candidates, 4 of the 6 converted targets belong to Django (a repository seen during Lite training). Furthermore, fine-tuning increases rank variance on trailing distractors, regressing Acc@5 and within-pool AUC below a non-neural heuristic. Without diverse cross-lingual and cross-framework training corpora, fine-tuning local models on small defect suites risks surface memorization and comment shortcut exploitation rather than robust structural code comprehension.
\paragraph{Threats to Validity}
(1)~\textit{Parser \& Language Scope}: Primary evaluation covers 344 Python tasks; 56/407 held-out tasks (52 in Stratum~C, 39 in SymPy) were excluded due to single-snapshot preimage drift (\texttt{FILE\_ABSENT\_PREIMAGE\_DRIFT}) where edited files were absent at the frozen indexed snapshot commit rather than failing AST syntax parsing. To mitigate parser drift and support polyglot repositories, `perron.polyglot` provides syntax-tolerant Tree-sitter extractors for Python and TypeScript. (2)~\textit{Single-Pass Localization vs.\ End-to-End Resolution}: I intentionally isolate the $K \le 4,096$ localization and AST surgical editing layers from multi-turn Docker test loops to avoid confounding retrieval metrics with bash orchestration noise. (3)~\textit{Pre-Training Contamination \& Power}: While AST $\alpha$-renaming ($O_1$) strips symbol identifiers ($10.34\%$ vs.\ $12.07\%, p=1.0000$), docstrings and string literals remain intact and the 95\% CI on $N=58$ ([$-$11.2, +7.7]~pp) cannot rule out moderate memorization effects, motivating post-cutoff benchmarks. (4)~\textit{Exclusion of Git Churn and Complexity Heuristics}: Function-level git churn exhibits weak defect correlation ($\text{ROC-AUC} < 0.60$) and introduces $O(K^2)$ PR squash-merge clique noise, while cyclomatic complexity is collinear with lines of code ($\text{Spearman}~\rho \ge 0.88$), contributing zero independent explanatory signal and creating scale-free attractor sinks that undermine specificity damping.

\label{sec:conclusion}

Perron provides a fast, reproducible foundation for local developer agents.

\section{Linear Algebraic Formulations and Theoretical Proofs}
\label{app:spectral_proofs}

This appendix provides the complete linear algebraic formulations, spectral bounds, and geometric convergence proofs for the Perron Compressed Sparse Row (CSR) multigraph diffusion engine.

\subsection{Multiplex Transition Matrix Construction}
\label{prop:multiplex_construction}
Let a repository codebase be formalized as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where vertices $\mathcal{V}$ represent AST symbol entities (functions, methods, classes) and edges $\mathcal{E}$ represent typed syntactic dependencies. The relation vocabulary comprises four edge types: $\mathcal{R} = \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$. Each relation $r \in \mathcal{R}$ is represented by an adjacency matrix $A_r \in \{0, 1\}^{|\mathcal{V}| \times |\mathcal{V}|}$, where $(A_r)_{uv} = 1$ if and only if there exists a directed edge of type $r$ from symbol $u$ to symbol $v$.

To balance semantic dependency importance while mitigating hub concentration, typed relation edges are aggregated via a non-negative convex weight vector $\boldsymbol{\omega} = [\omega_{\text{call}}, \omega_{\text{inherit}}, \omega_{\text{import}}, \omega_{\text{caller}}]^\top$ satisfying $\sum_{r \in \mathcal{R}} \omega_r = 1.0$:
\begin{equation}
W = \sum_{r \in \mathcal{R}} \omega_r A_r.
\label{eq:weighted_adjacency_app}
\end{equation}
The row-substochastic transition matrix $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ is formed by normalizing positive out-degree rows by their total weighted degree:
\begin{equation}
D_{uu} = \sum_{v \in \mathcal{V}} W_{uv}, \qquad T_{uv} = \begin{cases} \frac{W_{uv}}{D_{uu}} & \text{if } D_{uu} > 0, \\ 0 & \text{if } D_{uu} = 0. \end{cases}
\label{eq:stochastic_matrix_app}
\end{equation}
Let $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ denote the dangling-node indicator vector with $d_u = 1$ if $D_{uu} = 0$, and $0$ otherwise. Given an initial query personalization probability vector $\mathbf{p}_0 \in \Delta^{|\mathcal{V}|-1}$ (where $\Delta^{n}$ denotes the standard simplex), the completed row-stochastic transition operator $\bar{T}$ satisfies:
\begin{equation}
\bar{T} = T + \mathbf{d} \mathbf{p}_0^\top, \qquad \bar{T} \mathbf{1} = \mathbf{1}.
\label{eq:completed_stochastic_app}
\end{equation}
The closed Google transition operator $M \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ with teleportation damping factor $\beta \in (0, 1)$ is formulated as:
\begin{equation}
M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top.
\label{eq:google_matrix_app}
\end{equation}

\subsection{Brauer Rank-1 Spectral Bound and Second Eigenvalue}
\label{prop:spectral_gap_proof}
By the Brauer rank-1 perturbation theorem applied to Markov transition matrices~\cite{haveliwala2003second}:
Let $A$ be an $n \times n$ matrix with eigenvalues $\lambda_1, \lambda_2, \dots, \lambda_n$, and let $\mathbf{x}_1$ be the right eigenvector associated with $\lambda_1$. For any vector $\mathbf{y} \in \mathbb{R}^n$, the perturbed matrix $A + \mathbf{x}_1 \mathbf{y}^\top$ has eigenvalues $\lambda_1 + \mathbf{y}^\top \mathbf{x}_1, \lambda_2, \dots, \lambda_n$.

In this formulation, setting $A = \beta \bar{T}$ yields eigenvalues $\beta \lambda_1(\bar{T}), \beta \lambda_2(\bar{T}), \dots, \beta \lambda_n(\bar{T})$. Because $\bar{T}$ is row-stochastic, its principal eigenvalue is $\lambda_1(\bar{T}) = 1$ with right eigenvector $\mathbf{x}_1 = \mathbf{1}$. Setting $\mathbf{y} = (1 - \beta) \mathbf{p}_0$ gives:
\begin{equation}
M = \beta \bar{T} + \mathbf{1} ((1 - \beta) \mathbf{p}_0)^\top.
\end{equation}
The principal eigenvalue of $M$ becomes:
\begin{equation}
\lambda_1(M) = \beta \lambda_1(\bar{T}) + ((1 - \beta) \mathbf{p}_0)^\top \mathbf{1} = \beta + (1 - \beta) = 1.
\end{equation}
All remaining eigenvalues satisfy:
\begin{equation}
\lambda_i(M) = \beta \lambda_i(\bar{T}), \quad \forall i \ge 2.
\end{equation}
Because $\bar{T}$ is row-stochastic, the Gershgorin circle theorem establishes $|\lambda_i(\bar{T})| \le 1$ for all $i$. Therefore, the second-largest eigenvalue is strictly bounded:
\begin{equation}
|\lambda_2(M)| \le \beta \cdot 1.0 = \beta.
\end{equation}
For $\beta = 0.85$, the spectral gap is uniformly lower-bounded:
\begin{equation}
1 - |\lambda_2(M)| \ge 1 - \beta = 0.15.
\end{equation}
While $|\lambda_2(M)| \le \beta$ bounds the asymptotic spectral radius, call dependency multigraphs are generally non-normal and defective. To establish strict, prefactor-free geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance on general directed multigraphs, I invoke the Doeblin minorization and $L_1$ contraction property of the Markov transition operator. For any two probability distribution vectors $\mathbf{u}^\top, \mathbf{v}^\top$ on $\mathcal{V}$, because $(\mathbf{u}^\top - \mathbf{v}^\top)\mathbf{1} = 0$, the uniform rank-1 teleportation term $(1-\beta)\mathbf{1}\mathbf{p}_0^\top$ cancels identically:
\begin{equation}
\|(\mathbf{u}^\top - \mathbf{v}^\top) M\|_1 = \|\beta (\mathbf{u}^\top - \mathbf{v}^\top) \bar{T}\|_1 \le \beta \|\mathbf{u}^\top - \mathbf{v}^\top\|_1 \|\bar{T}\|_\infty = \beta \|\mathbf{u}^\top - \mathbf{v}^\top\|_1,
\end{equation}
since $\|\bar{T}\|_\infty = 1$. By induction, $\|\boldsymbol{\pi}^{(t)\top} - \boldsymbol{\pi}_\infty^\top\|_1 \le \beta^t \|\boldsymbol{\pi}^{(0)\top} - \boldsymbol{\pi}_\infty^\top\|_1 \le 2\beta^t$, establishing uniform geometric $L_1$ total variation contraction regardless of graph density or Jordan-block structures.

\subsection{Barycentric Linearity and Basis Warping Bounds}
\label{prop:convex_hull_proof}
Following Jeh and Widom~\cite{jeh2003scaling}, let $\mathbf{p}_0 = \sum_{i=1}^K w_i \mathbf{e}_{s_i}$ be any convex combination of query seed nodes with $w_i \ge 0$ and $\sum w_i = 1.0$. The stationary distribution $\boldsymbol{\pi}(\mathbf{p}_0)$ lies in the convex hull of the basis distributions:
\begin{equation}
\label{eq:convex_hull_weights_app2}
\boldsymbol{\pi}(\mathbf{p}_0) = \sum_{i=1}^K \tilde{w}_i \boldsymbol{\pi}(\mathbf{e}_{s_i}) \in \operatorname{conv}\left(\{\boldsymbol{\pi}(\mathbf{e}_{s_i})\}_{i=1}^K\right), \quad \tilde{w}_i = \frac{w_i m_i}{\mathbf{w}^\top \mathbf{m}},
\end{equation}
where basis mass satisfies $m_i = \|(1-\beta) \mathbf{e}_{s_i}^\top (I - \beta T)^{-1}\|_1 \in [1-\beta, 1.0]$. The maximum coordinate warping ratio is bounded by:
\begin{equation}
\frac{\max_i m_i}{\min_j m_j} \le \frac{1}{1 - \beta} = \frac{1}{0.15} \approx 6.67.
\end{equation}

\subsection{Markov Renewal Equivalence to Normalized Leaky Resolvents}
\label{prop:renewal_proof}
In the closed Markov chain $M$, dangling nodes restart according to the query teleport distribution $\mathbf{p}_0$. By the regenerative renewal property of Markov chains with state-independent resets, the stationary probability $\boldsymbol{\pi}_{\text{closed}}$ of the closed chain $M$ is algebraically identical to the normalized leaky resolvent vector:
\begin{equation}
\boldsymbol{\pi}_{\text{leaky}}^\top = \frac{(1-\beta)\mathbf{p}_0^\top (I - \beta T)^{-1}}{\|(1-\beta)\mathbf{p}_0^\top (I - \beta T)^{-1}\|_1}.
\end{equation}
Across all 12 canonical SWE-bench repositories, the maximum numerical discrepancy satisfies:
\begin{equation}
\|\boldsymbol{\pi}_{\text{closed}} - \boldsymbol{\pi}_{\text{leaky}}\|_1 = 1.68 \times 10^{-8} < 2 \times 10^{-8},
\end{equation}
confirming exact algebraic equivalence.

\subsection{Asymptotic Pointwise Mutual Information (PMI) Decomposition}
\label{prop:pmi_proof}
For any code symbol $v$ with positive query support, define the query-symbol Pointwise Mutual Information surrogate as $\operatorname{PMI}(v; q) \triangleq \ln \frac{\pi_{\text{query}}(v)}{\pi_{\text{global}}(v)}$, interpreting $\pi_{\text{query}}(v)$ as query-conditioned symbol reachability and $\pi_{\text{global}}(v)$ as global unconditioned graph background density. Because dangling-node restarts depend on $\mathbf{p}_0^{(q)}$, $\ln \frac{\pi_{\text{query}}(v)}{\pi_{\text{global}}(v)}$ acts as a surrogate stationary log-odds ratio against the uniform-prior stationary baseline rather than assuming strict marginal consistency across queries. The log-transformed Specificity score satisfies:
\begin{equation}
\ln \operatorname{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \operatorname{PMI}(v; q) - \gamma \ln\!\left(1 + \frac{\epsilon}{\pi_{\text{global}}(v)}\right).
\end{equation}
When $\pi_{\text{global}}(v) \gg \epsilon$, the residual vanishes, yielding a convex interpolation between raw reachability ($\gamma=0$) and surprise ($\gamma=1$), where the sub-linear exponent $\gamma = 0.70$ acts as a structural Inverse Document Frequency (IDF) discount.

\subsection{Neumann Series Expansion and Sink Absorption}
\label{prop:neumann_proof}
The Neumann series expansion of Personalized PageRank illustrates why pre-walk scaling cannot prevent sink absorption on software dependency graphs:
\begin{equation}
\boldsymbol{\pi}^\top = (1-\beta)\sum_{t=0}^{\infty} \beta^t \mathbf{p}_0^\top \bar{T}^t = (1-\beta)\left(\mathbf{p}_0^\top + \beta \mathbf{p}_0^\top \bar{T} + \beta^2 \mathbf{p}_0^\top \bar{T}^2 + \sum_{t=3}^{\infty} \beta^t \mathbf{p}_0^\top \bar{T}^t\right).
\end{equation}
Walks of length $t \ge 3$ carry approximately 61\% of total diffusion mass ($\beta^3 \approx 0.614$ at $\beta=0.85$). Multi-step transitions $\bar{T}^t$ funnel mass toward scale-free sink hubs regardless of initial weights $\mathbf{p}_0$. Perron's decoupled post-walk ratio divides the converged vector $\boldsymbol{\pi}$, scaling every walk length simultaneously and enforcing high Hub Suppression Index (HSI@10).

\subsection{Mathematical Derivation of the Break-Even Discrimination Bound}
\label{app:breakeven_derivation}
Let $\mathcal{C}_M = \{c_1, c_2, \dots, c_M\}$ denote a candidate pool of size $M$ presented to a ranking scorer, and let $v^* \in \mathcal{V}$ denote the true defect location. I model the localization process as a two-stage probabilistic filter:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Recall Stage}: Candidate generation captures the true target with probability $R(M) \triangleq P(v^* \in \mathcal{C}_M)$.
    \item \textbf{Discrimination Stage}: Conditioned on target presence ($v^* \in \mathcal{C}_M$), the model correctly ranks $v^*$ within the top-$k$ positions with conditional probability $D(M) \triangleq P(\operatorname{rank}(v^*) \le k \mid v^* \in \mathcal{C}_M)$.
\end{enumerate}
The unconditional end-to-end success probability is governed by the product:
\begin{equation}
P(\text{Acc@}k \mid M) = R(M) \cdot D(M).
\end{equation}
When the candidate pool is expanded from size $M_1$ to size $M_2 = M_1 + \Delta M$ (e.g., by traversing 1-hop AST call-graph neighbors), candidate pool recall changes by $\Delta R = R(M_2) - R(M_1) \ge 0$. Concurrently, presenting $\Delta M$ additional distractor symbols alters the model's conditional ranking discrimination by $\Delta D = D(M_1) - D(M_2)$. Expanding the pool yields an end-to-end localization gain if and only if:
\begin{equation}
R(M_2) D(M_2) > R(M_1) D(M_1) \iff (R(M_1) + \Delta R) D(M_2) > R(M_1) (D(M_2) + \Delta D).
\end{equation}
Rearranging terms yields the fundamental Break-Even Discrimination Bound:
\begin{equation}
\Delta R \cdot D(M_2) > R(M_1) \cdot \Delta D \iff \frac{\Delta R}{R(M_1)} > \frac{\Delta D}{D(M_2)}.
\label{eq:breakeven_formal}
\end{equation}
Under a random-ranking null model, the expected rank of a gold candidate placed uniformly at random within $M$ candidates is $\mathbb{E}[\operatorname{rank}(v^*)] = \frac{M+1}{2}$. For a parameterized scoring model whose ranking quality is characterized by receiver operating characteristic area under the curve ($\text{AUC} \in [0.5, 1.0]$) separating gold targets from distractors within the candidate pool, the expected rank of $v^*$ among $M-1$ distractors follows:
\begin{equation}
\mathbb{E}[\operatorname{rank}(v^*) \mid \text{AUC}] = 1 + (M - 1)(1 - \text{AUC}).
\end{equation}
To ensure that the expected rank falls within the top-$k$ cutoff ($\mathbb{E}[\operatorname{rank}(v^*)] \le k$), the model's within-pool discrimination must satisfy the critical first-moment threshold:
\begin{equation}
1 + (M - 1)(1 - \text{AUC}) \le k \iff \text{AUC} \ge 1 - \frac{k - 1}{M - 1} \triangleq \text{AUC}^*(M; k).
\label{eq:auc_bound_app}
\end{equation}
At cutoff $M=25$ ($k=5$), the required threshold is $\text{AUC}^* = 1 - \frac{4}{24} \approx 0.8333$. At $M=15$ ($k=5$), tightening the candidate horizon lowers the required threshold to $\text{AUC}^* = 1 - \frac{4}{14} \approx 0.7143$, unblocking target conversion.

\subsection{Mathematical Proof of Proposition 1: Sharp Affine Expected-Rank Lower Bound}
\label{app:breakeven_math}
\label{app:prop1_proof}

\paragraph{Proposition 1 (Sharp Affine Expected-Rank Lower Bound)}
\label{prop:affine_bound}
\textit{Let $\operatorname{Rank}(v^*) \in \{1, 2, \dots, M\}$ be the integer rank of the unique gold target in a candidate pool of size $M \ge k$. Define top-$k$ localization accuracy as $p \triangleq \mathbb{P}(\operatorname{Rank}(v^*) \le k) = \operatorname{Acc@}k$. Then, for any distribution on $\operatorname{Rank}(v^*)$:
\begin{equation}
\operatorname{Acc@}k \ge \max\left(0, \frac{k + 1 - \mathbb{E}[\operatorname{Rank}(v^*)]}{k}\right).
\label{eq:prop1_bound}
\end{equation}
In particular, whenever the first-moment expected-rank condition is satisfied ($\mathbb{E}[\operatorname{Rank}(v^*)] \le k$), top-$k$ localization accuracy is bounded from below by:
\begin{equation}
\operatorname{Acc@}k \ge \frac{1}{k}.
\label{eq:prop1_floor}
\end{equation}
Furthermore, the bound~\eqref{eq:prop1_bound} is sharp: for any $M \ge k + 1$ and any achievable mean rank $\mu \in [1, k+1]$, there exists an extremal probability distribution attaining exact equality in~\eqref{eq:prop1_bound}.}

\paragraph{Proof}
By definition of expectation for discrete integer-valued random variables on $\{1, \dots, M\}$:
\begin{align}
\mathbb{E}[\operatorname{Rank}(v^*)] &= \sum_{r=1}^M r \cdot \mathbb{P}(\operatorname{Rank}(v^*) = r) \\
&= \sum_{r=1}^k r \cdot \mathbb{P}(\operatorname{Rank}(v^*) = r) + \sum_{r=k+1}^M r \cdot \mathbb{P}(\operatorname{Rank}(v^*) = r).
\end{align}
Because $r \ge 1$ for all $r \in \{1, \dots, k\}$, the first summation satisfies:
\begin{equation}
\sum_{r=1}^k r \cdot \mathbb{P}(\operatorname{Rank}(v^*) = r) \ge 1 \cdot \sum_{r=1}^k \mathbb{P}(\operatorname{Rank}(v^*) = r) = 1 \cdot p.
\end{equation}
Because $r \ge k + 1$ for all $r \in \{k+1, \dots, M\}$, the second summation satisfies:
\begin{equation}
\sum_{r=k+1}^M r \cdot \mathbb{P}(\operatorname{Rank}(v^*) = r) \ge (k + 1) \cdot \sum_{r=k+1}^M \mathbb{P}(\operatorname{Rank}(v^*) = r) = (k + 1)(1 - p).
\end{equation}
Summing these two lower bounds establishes:
\begin{equation}
\mathbb{E}[\operatorname{Rank}(v^*)] \ge p + (k + 1)(1 - p) = k + 1 - k \cdot p.
\end{equation}
Rearranging terms for $p$:
\begin{equation}
k \cdot p \ge k + 1 - \mathbb{E}[\operatorname{Rank}(v^*)] \implies p \ge \frac{k + 1 - \mathbb{E}[\operatorname{Rank}(v^*)]}{k}.
\end{equation}
Since probabilities are non-negative ($p \ge 0$), this establishes Equation~\eqref{eq:prop1_bound}. When $\mathbb{E}[\operatorname{Rank}(v^*)] \le k$, substituting $\mathbb{E}[\operatorname{Rank}(v^*)] \le k$ into Equation~\eqref{eq:prop1_bound} yields:
\begin{equation}
p \ge \frac{k + 1 - k}{k} = \frac{1}{k},
\end{equation}
proving Equation~\eqref{eq:prop1_floor}.

To prove sharpness whenever $M \ge k + 1$, consider the two-point extremal distribution supported on $\{1, k+1\} \subseteq \{1, \dots, M\}$:
\begin{equation}
\mathbb{P}(\operatorname{Rank}(v^*) = 1) = p, \qquad \mathbb{P}(\operatorname{Rank}(v^*) = k + 1) = 1 - p.
\end{equation}
For this distribution, the expected rank is exactly:
\begin{equation}
\mathbb{E}[\operatorname{Rank}(v^*)] = p \cdot 1 + (1 - p)(k + 1) = k + 1 - k \cdot p,
\end{equation}
which satisfies Equation~\eqref{eq:prop1_bound} with exact equality. Specifically, for any target mean $\mu \in [1, k+1]$, choosing $p = \frac{k+1-\mu}{k} \in [0, 1]$ yields $\mathbb{E}[\operatorname{Rank}(v^*)] = \mu$ and $\operatorname{Acc@}k = p = \frac{k+1-\mu}{k}$, proving that the bound cannot be improved without higher-moment constraints. \hfill $\blacksquare$

\subsection{Selective Routing Policy Formulation}
Because defect accessibility varies markedly across issue descriptions, uniform graph expansion is suboptimal. I formulate selective routing as a contextual decision problem. Let $\mathbf{x} \in \mathbb{R}^d$ denote a feature vector extracted from the issue description $q$ prior to candidate generation:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Lexical Identifier Density}: $\rho_{\text{id}}(q) = \frac{|\operatorname{Identifiers}(q)|}{|\operatorname{Tokens}(q)|}$, measuring the proportion of code-like tokens (snake\_case, CamelCase) in the prompt.
    \item \textbf{Traceback Presence}: Binary indicator $\mathbb{I}_{\text{trace}}(q) \in \{0, 1\}$ detecting Python exception stack traces.
    \item \textbf{Seed BM25 Skewness}: Skewness of the top-10 lexical score distribution $\kappa(s) = \frac{\frac{1}{10}\sum (s_i - \bar{s})^3}{\sigma_s^3}$.
\end{enumerate}
A routing policy $\pi: \mathbf{x} \mapsto \{A_1, A_2, A_4\}$ selects the candidate generation strategy:
\begin{equation}
\pi^*(\mathbf{x}) = \begin{cases} A_1 \text{ (Seeds Only)} & \text{if } \rho_{\text{id}}(q) \ge \theta_{\text{high}} \text{ (explicit named symbol)}, \\ A_4 \text{ (Graph 1-Hop, } M=15) & \text{if } \mathbb{I}_{\text{trace}}(q) = 1 \lor \kappa(s) > \theta_{\text{skew}}, \\ A_2 \text{ (Depth BM25)} & \text{otherwise (diffuse symptom report)}. \end{cases}
\end{equation}
Cross-validated evaluation on SWE-bench Verified demonstrates that this selective policy achieves $47.38\%$ Acc@5 while reducing total candidate generation and model scoring compute by $31.4\%$ compared to universal graph expansion.

\subsection{Compressed Sparse Row (CSR) Memory Layout and Vectorization}
The Perron multigraph engine represents software dependency graphs using three contiguous NumPy arrays with zero-copy memory mapping:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Row Pointers (\texttt{indptr})}: A 32-bit integer array of size $|\mathcal{V}| + 1$, where $\texttt{indptr}[u]$ and $\texttt{indptr}[u+1]$ demarcate the slice of outgoing edges from symbol $u$.
    \item \textbf{Column Indices (\texttt{indices})}: A 32-bit integer array of size $|\mathcal{E}|$, storing target symbol indices for each edge.
    \item \textbf{Edge Weights (\texttt{data})}: A 32-bit floating-point array of size $|\mathcal{E}|$, storing normalized transition probabilities $\bar{T}_{uv}$.
\end{itemize}
The sparse matrix-vector multiplication (SpMV) inner loop executes vectorized power iteration:
\begin{equation}
\boldsymbol{\pi}^{(t+1)\top} = \beta \boldsymbol{\pi}^{(t)\top} \bar{T} + (1 - \beta) \mathbf{p}_0^\top.
\end{equation}
Because software dependency graphs exhibit extreme sparsity (mean out-degree $\bar{d}_{\text{out}} \in [2.7, 4.0]$ across repositories, sparsity ratio $> 99.98\%$), the SpMV operation requires only $\mathcal{O}(|\mathcal{E}|)$ floating-point operations per iteration. In pure Python using NumPy vectorization, each iteration executes in $21\text{--}77~\mu\text{s}$. Convergence to $L_1$ total variation tolerance $\epsilon_{\text{tol}} = 10^{-6}$ occurs within $t \le 60\text{--}90$ steps by the Doeblin contraction property (Appendix~\ref{prop:spectral_gap_proof}), bounding total solve latency below $5.10$~ms even on SymPy ($|\mathcal{V}|=37{,}442, |\mathcal{E}|=148{,}912$).

\subsection{Proportional RoPE (p-RoPE) Context Scaling and KV-Cache Memory}
The Gemma~4 architecture introduces Proportional Rotary Position Embedding (p-RoPE) to sustain long-context reasoning up to 256K tokens without exponential KV-cache memory growth. For an agent processing repository context of length $L$ tokens, the KV-cache memory consumption in bytes is governed by:
\begin{equation}
\text{Memory}_{\text{KV}}(L) = 2 \times n_{\text{layers}} \times n_{\text{kv\_heads}} \times d_{\text{head}} \times L \times b_{\text{precision}},
\end{equation}
where $b_{\text{precision}} = 2$ bytes for 16-bit precision, $n_{\text{layers}}$ is the number of transformer layers, and $n_{\text{kv\_heads}}$ is the number of key-value attention heads under Grouped Query Attention (GQA).
For Gemma~4 26B-A4B ($n_{\text{layers}}=30, n_{\text{kv\_heads}}=8, d_{\text{head}}=128$):
\begin{equation}
\text{Memory}_{\text{KV}}(L) = 2 \times 30 \times 8 \times 128 \times L \times 2 = 122{,}880 \times L \text{ bytes} \approx 120~\text{KB per token}.
\end{equation}
At an agent context window of $L = 4{,}096$ tokens, the KV-cache requires $0.49$~GB ($491.5$~MB) of VRAM. Combined with the $52.0$~GB required for unquantized 3D MoE expert weights, total memory demand reaches $52.49$~GB, exceeding the capacity of standard workstation GPUs (e.g., Dual Tesla T4 with $29.12$~GB total, or single RTX 3090/4090 with $24$~GB). Consequently, deploying local developer agents requires either 4-bit quantization (AWQ/GPTQ) or sliding-window attention truncation to keep memory allocations within consumer GPU budgets.


Evaluating Gemma~4 26B-A4B under protocol \texttt{PREREG\allowbreak -SCALING\allowbreak -v1} isolates a practical deployment constraint for mixture-of-experts developer agents. In modern deep learning frameworks, the 128 dynamic experts are instantiated as 3D weight tensors (\texttt{[num\_experts, in\_features, out\_features]}), which bypass standard 2D \texttt{bitsandbytes} NF4/INT8 linear layer quantization hooks without custom CUDA kernels. In unquantized 16-bit precision, expert parameters require \ScalingMoERuntimeVRAM\ of runtime VRAM (\ScalingMoERequiredVRAM\ compressed disk storage), physically exceeding dual Tesla T4 capacity (\ScalingMoEAvailableVRAM). Attempting runtime CPU or disk offloading degrades inference speed below interactive usability. Consequently, while compact dense models ($\le 4$B parameters) operate smoothly within local GPU budgets ($\le 9.6$~GB), deploying high-capacity sparse MoE models for local developer agents requires ahead-of-time AWQ or GPTQ quantization formats with native 3D tensor support.
