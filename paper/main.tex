\begin{abstract}
Local developer agents must localize software defects within a working context of a few thousand tokens without cloud inference. Graph walks over static call graphs are widely hypothesized to reach symbols that issue descriptions never name. In this paper, I test whether call-graph expansion assists a compact 2B local model. On a 344-task held-out subset of SWE-bench Verified ($N=\TaskCallableBenchmark$ callable tasks), under a hash-committed protocol, a frozen \texttt{gemma-4-e2b-it} scores candidate pools pointwise. Graph 1-hop expansion reaches 47.1\% Acc@5, against 45.1\% for depth-matched BM25 (+2.03 pp, 95\% CI [$-$0.29, +4.36], Holm $p=0.287$) and 45.6\% for same-file expansion (+1.45 pp, Holm $p=0.302$). Both pools contain the gold function in 201/344 tasks (58.4\%), with 18 discordant tasks each way. Compared to reranking lexical seeds alone (46.2\%, 159/344), graph expansion adds 25 newly reachable targets to the pool, but only 7 top-5 hits are gained (6 from graph reachability, 1 from seed promotion) against 4 displaced seed hits (gross 7/4 split, net +3 tasks, $+0.87$ pp, $p=0.549$), consistent with distractor accumulation under pointwise scoring. In Stratum~C ($N=131$ un-named tasks), graph expansion achieves 12.2\% Acc@5 vs.\ 8.4\% for depth BM25 (+3.82 pp, $p=0.125$), but neither beats seeds alone (13.7\%) or unscored BM25 (15.3\%). Upstream boundary loss before scoring ($41.6$ pp) exceeds downstream compaction loss ($11.3$ pp) by $3.68\times$ at $k=5$ (spanning $1.2\times$ at $k=1$ to $6.8\times$ at $k=10$). The paired 95\% bootstrap CI [$-$0.29, +4.36] pp spans zero, ruling out gains larger than $+4.4$ pp ($15$ tasks) over depth-matched lexical reranking (PC1). I release 19,298 scored candidate evaluations, the \texttt{perron-core} library, and precomputed repository graphs under Apache~2.0.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Autonomous developer agents designed for local execution must localize software defects inside a working context of a few thousand tokens, eliminating dependence on costly cloud APIs and preventing source code leakage. Standard lexical search (e.g., Okapi BM25) reliably finds symbols explicitly named in issue text or error traces. To locate fault sites that the issue never mentions, existing agent architectures (including Aider's PageRank repository maps~\cite{gauthier2023aider}, RepoGraph~\cite{ouyang2025repograph}, and LocAgent~\cite{chen2025locagent}) deploy random walks or graph traversal tools over AST dependency networks.

The working assumption underlying graph-augmented localization rests on two joint conditions:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Recall Expansion}: Traversal along structural call edges must place gold defect targets into the candidate pool that lexical search misses.
    \item \textbf{Rank Discrimination}: A compact language model must rank those newly introduced targets above the distractors that graph expansion inevitably introduces.
\end{enumerate}

In this paper, I test both conditions on a 344-task held-out subset of SWE-bench Verified~\cite{jimenez2024swebench} using Perron, a high-throughput memory-mapped Compressed Sparse Row (CSR) graph engine, and a frozen \texttt{gemma-4-e2b-it} scorer. Three empirical research questions guide the investigation:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{RQ1}: Does Personalized PageRank (PPR) diffusion, with or without post-walk hub damping, outperform BM25 at function-level code retrieval?
    \item \textbf{RQ2}: Under a frozen small model scorer, does graph 1-hop expansion outperform depth-matched BM25 and same-file pools of identical size?
    \item \textbf{RQ3}: At which pipeline stage is bug localization accuracy primarily lost?
\end{itemize}

\subsection{Contributions}
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Matched-Control Evaluation Design}: Depth-matched BM25, same-file, and degree-preserving null-graph candidate pools are scored by the identical model under controlled prompt budgets, isolating what graph structure contributes beyond pool cardinality.
    \item \textbf{Empirical Loss Funnel and Truncation Curves}: A 4-stage loss decomposition separates candidate boundary ceiling, rank compaction, and reader error. Truncating matched pools at $M \in [10, 50]$ shows that adding depth lexical candidates is consistent with distractor accumulation (Acc@5 drops by 4 tasks, $-$1.16 pp, $p=0.455$), whereas graph expansion plateaus flat (+3 tasks, +0.87 pp over seeds, $p=0.549$).
    \item \textbf{Discordant Strata Symmetry}: The 18 discordant tasks recalled exclusively by graph expansion and the 18 tasks recalled exclusively by lexical expansion are split almost identically across strata (9 vs.\ 10 in Stratum~C, 9 vs.\ 7 in Stratum~A), showing that graph expansion does not selectively rescue un-named bugs over lexical depth.
    \item \textbf{High-Throughput CSR Graph Engine}: An efficient, memory-mapped Compressed Sparse Row multigraph architecture with decoupled specificity ratio hub damping that executes localized random walks in sub-5 ms on consumer workstations without matrix mutation (spectral convergence proofs detailed in Appendix~\ref{app:spectral_proofs}).
    \item \textbf{Open-Source Ecosystem Deliverables}: I release 19,298 scored candidate evaluations (\texttt{scores.parquet}), the \texttt{perron-core} library (Apache~2.0), \texttt{perron-mcp}, and precomputed CSR graphs.
\end{itemize}

Only two primary contrasts (PC1 and PC2 on strict Acc@5) are confirmatory. Every other analysis is explicitly designated as exploratory.

\subsection{Physical Hardware Envelope}
Local developer agents must operate efficiently on consumer hardware. Perron bounds active per-turn working context to $K_{\text{effective}} = 3,480$ tokens ($K \le 4,096$). On a reference developer machine (\HostRAMGiB\ RAM), the standalone CSR engine peaks at \EnginePeakRSSMB\ resident memory, loading graphs via zero-copy memory mapping (\EngineGraphLoadDeltaMB\ delta). Hierarchical AST skeleton breadcrumbs occupy an average of 283.8 tokens per task (median 264 tokens), preserving 91.9\% reasoning headroom for model generation within the 3,480-token context budget. Live inference of \texttt{gemma-4-e2b-it} was evaluated with left-padded batching and \texttt{logits\_to\_keep=1} on an NVIDIA Tesla T4 GPU (scoring prompts averaging 423 tokens per candidate symbol), achieving mean Time-To-First-Token of \GemmaMeanTTFTMs\ and \GemmaDecodeTokensSec\ tokens/sec decode throughput.

\section{Related Work}
\label{sec:related}
\paragraph{Graphs and Agents for Code Localization}
Lexical search and dense bi-encoders struggle with vocabulary mismatch and structural execution paths. RepoCoder~\cite{zhang2023repocoder} demonstrated that iterative retrieval loops improve code completion but incur multi-turn token inflation. Aider~\cite{gauthier2023aider} introduced repository maps using Tree-sitter AST tags ranked by PageRank. Graph-guided agents such as RepoGraph~\cite{ouyang2025repograph}, CodexGraph~\cite{liu2025codexgraph}, and LocAgent~\cite{chen2025locagent} equip frontier models with graph traversal tools to navigate codebases interactively. AutoCodeRover~\cite{zhang2024autocoderover} navigates ASTs through iterative search queries. In SWE-agent~\cite{yang2024sweagent}, specialized agent-computer interfaces improve resolve rates. Conversely, Agentless~\cite{xia2025agentless} demonstrated that a simple two-phase pipeline (hierarchical localization followed by test-filtered patch generation) resolves ~32\% of SWE-bench Lite (FSE 2025) without an agent loop, highlighting that simple pipelines establish strong baselines. These systems employ large hosted models; this paper evaluates whether graph expansion assists a small 2B model in a single scoring pass.

\paragraph{Random-Walk Retrieval on Graphs}
Scalable diffusion on graphs builds on push-based approximate Personalized PageRank~\cite{andersen2006local}, decoupled propagation architectures such as APPNP~\cite{klicpera2019predict}, and scalable indexing frameworks like PPRGo~\cite{bojchevski2020scaling}. In link prediction, rooted PageRank and stationary-normalized hitting times~\cite{liben2007link} discount popular nodes by global stationary reachability. HippoRAG~\cite{gutierrez2024hipporag} demonstrated that Personalized PageRank over knowledge graphs outperforms iterative retrieval, formulating node specificity as inverse passage frequency $s_i = |P_i|^{-1}$ applied as a pre-walk teleport multiplier ($\mathbf{p}_0(i) \leftarrow \mathbf{p}_0(i) \cdot s_i$). However, on software call graphs, high-in-degree utility hubs (logging routines, assertion helpers) are unseeded intermediate nodes that absorb diffusion mass regardless of $s_i$. Perron decouples diffusion from a post-walk stationary baseline ratio over static CSR matrices.

\paragraph{Program Slicing and Fault Localization}
Classical program slicing~\cite{weiser1984program} computes backward executable slices on statement-level Program Dependence Graphs (PDGs), but conservative alias analysis often retains 50\% to 80\% of an application's codebase. Spectrum-Based Fault Localization (SBFL)~\cite{pearson2017evaluating,zou2021empirical} evaluates test coverage matrices to score statement suspiciousness. Pearson et al.~\cite{pearson2017evaluating} showed that fault-localization findings on artificial faults do not reliably transfer to real-world software defects, motivating authentic issue evaluation on SWE-bench~\cite{jimenez2024swebench}. Perron extracts symbol-level AST multigraphs to pack relevant contexts into prompt budgets ($K \le 4,096$) without requiring test execution during retrieval.

\paragraph{Pointwise versus Listwise Reranking}
Pointwise language model scoring (e.g., MonoT5~\cite{nogueira2020document}) evaluates each candidate independently. Under independent scoring, the expected number of distractors that outscore a gold target with score $s^*$ scales with candidate pool cardinality: $\mathbb{E}[X \mid s^*] = \sum_{j=1}^{M-1} (1 - F_{\text{dist}, j}(s^*))$. Consequently, expanding candidate pool size $M$ under a compact pointwise scorer risks distractor accumulation unless model discrimination is near-perfect. In contrast, listwise and setwise architectures~\cite{sun2023rankgpt,pradeep2023setwise} introduce direct cross-candidate attention competition, mitigating distractor dominance.

\section{Theoretical Foundations and The Perron Graph Engine}
\label{sec:system}
\subsection{Multiplex Transition Matrix Construction}
A codebase is represented as a directed multigraph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where $\mathcal{V}$ denotes AST code symbols (classes, functions, methods) and $\mathcal{E}$ spans relations $r \in \{\text{call}, \text{inherit}, \text{import}, \text{caller}\}$. Directed edges $(u, v) \in \mathcal{E}_{\text{call}}$ indicate that symbol $u$ invokes $v$, while $(u, v) \in \mathcal{E}_{\text{inherit}}$ represent class C3 Method Resolution Order inheritance, $(u, v) \in \mathcal{E}_{\text{import}}$ represent module imports, and $(u, w) \in \mathcal{E}_{\text{caller}}$ denote reverse call invocations.

Relations receive asymmetric static weights:
\begin{equation}
W_{uv} = \omega_{\text{call}} A^{(\text{call})}_{uv} + \omega_{\text{inherit}} A^{(\text{inherit})}_{uv} + \omega_{\text{import}} A^{(\text{import})}_{uv} + \omega_{\text{caller}} A^{(\text{caller})}_{uv},
\label{eq:edge_weight}
\end{equation}
where $\boldsymbol{\omega} = [0.50, 0.25, 0.15, 0.10]$ and $A^{(r)}_{uv} = \mathbb{I}((u, v) \in \mathcal{E}_r)$. Let $D_u = \sum_{v} W_{uv}$ be the out-degree sum. The row-stochastic transition matrix $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ and dangling indicator $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ are defined as:
\begin{equation}
T_{uv} = \begin{cases} \frac{W_{uv}}{D_u}, & D_u > 0 \\ 0, & D_u = 0 \end{cases}, \quad d_u = \begin{cases} 1.0, & D_u = 0 \\ 0.0, & D_u > 0 \end{cases}.
\label{eq:stochastic_matrix}
\end{equation}

Memory-mapped ingestion via \texttt{numpy.load(mmap\_mode='r')} opens the CSR representation directly from disk. Post-walk specificity ratio evaluation requires only $\mathcal{O}(|\mathcal{V}|)$ vector arithmetic, eliminating runtime edge mutations and memory reallocation.

\subsection{Personalized PageRank Diffusion and Linear Algebraic Bounds}
Random walk diffusion models the propagation of bug relevance across call hierarchies. The Google transition operator $M$ with damping factor $\beta = 0.85$ is formulated as:
\begin{equation}
M = \beta \cdot (T + \mathbf{d} \mathbf{p}_0^\top) + (1 - \beta) \cdot \mathbf{1} \mathbf{p}_0^\top.
\label{eq:google_matrix}
\end{equation}

By the rank-1 perturbation spectrum of the Google matrix~\cite{haveliwala2003second}, the second-largest eigenvalue is strictly bounded by $|\lambda_2(M)| \le \beta = 0.85$, establishing an invariant spectral gap $1 - |\lambda_2(M)| \ge 1 - \beta = 0.15$ and guaranteed geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance. Power iteration stops on residual $\|\boldsymbol{\pi}^{(t+1)} - \boldsymbol{\pi}^{(t)}\|_1 < 10^{-6}$, converging in at most 90 iterations on Requests (1.89 ms) and 66 iterations on SymPy (5.10 ms). By the regenerative renewal property of Markov chains with teleportation, the stationary distribution of the closed operator $M$ is algebraically identical to the normalized leaky resolvent $(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}$ (discrepancy $< 2 \times 10^{-8}$). Full proofs of the Brauer spectral bound, barycentric linearity, and leaky resolvent equivalence are provided in Appendix~\ref{app:spectral_proofs}.

\subsection{Decoupled Specificity Ratio Hub-Damping}
\label{sec:specificity}
Personalized PageRank concentrates probability mass on high-in-degree hub nodes. To suppress structural popularity without mutating the static matrix $T$, Perron computes a repository-wide stationary baseline $\boldsymbol{\pi}_{\text{global}}$ once per codebase using a uniform prior $\mathbf{p}_{\text{uniform}} = \frac{1}{|\mathcal{V}|} \mathbf{1}$. For any query, the Specificity Score is defined as:
\begin{equation}
\text{Specificity}(v) = \frac{\pi_{\text{query}}(v)}{(\pi_{\text{global}}(v) + \epsilon)^{\gamma}},
\label{eq:specificity}
\end{equation}
where $\epsilon = 10^{-8}$ and $\gamma = 0.70$. Resistance to hub congestion is measured by the Hub Suppression Index at top 10 (HSI@10):
\begin{equation}
\text{HSI@10} = 1.0 - \frac{|\text{top-10} \cap \mathcal{H}_{25}|}{10},
\label{eq:hsi_metric}
\end{equation}
where $\mathcal{H}_{25}$ denotes the set of top-25 global in-degree hub nodes in the repository multigraph. The asymptotic Pointwise Mutual Information (PMI) decomposition and Neumann series analysis showing why pre-walk scaling cannot prevent sink absorption are detailed in Appendix~\ref{app:spectral_proofs}.

\subsection{Hierarchical AST Breadcrumb Context Packing}
To deliver localized code context within prompt budgets ($K \le 4,096$), Perron packs candidate symbols using hierarchical AST breadcrumb skeletons. For each candidate function, the enclosing class definition, docstring, and signature are preserved while stripping irrelevant sibling function bodies. Breadcrumb skeletons bound the context footprint to $<100$ tokens per symbol, keeping syntax parseable and variable bindings intact.

\section{Study Design and Hash-Committed Protocol}
\label{sec:protocol}

\subsection{Benchmark and Task Waterfall}
SWE-bench Verified~\cite{jimenez2024swebench} contains 500 tasks across 12 canonical Python repositories. To establish an unbiased held-out benchmark and prevent data leakage, instances are filtered via a mutually exclusive, collectively exhaustive (MECE) waterfall:
\begin{equation}
\begin{aligned}
\text{Total Verified (500)} - \text{Lite Overlap (93)} &= \text{Held-Out (407)}, \\
\text{Held-Out (407)} - \text{AST Drift (56)} - \text{Non-Callable (7)} &= \mathbf{344\text{ Callable Tasks}}.
\end{aligned}
\label{eq:waterfall}
\end{equation}
The 344 callable tasks ($\mathcal{S}_{\text{func}}$) define the callable, AST-parsable evaluation cohort of SWE-bench Verified possessing identifiable reference function targets. The 56 AST drift exclusions reflect legacy repository commits with syntax errors (such as Python 2/3 transitions) that fail standard AST parsing uniformly across all methods prior to candidate generation. Hyperparameters ($\beta=0.85, \gamma=0.70, \tau=0.15, K=25$) were fixed on development data and frozen prior to evaluation.

\paragraph{Defect Accessibility Strata}
To evaluate whether graph traversal selectively assists un-named defect localization, tasks are partitioned into three mutually exclusive strata based on issue text lexical visibility: (1)~\textbf{Stratum~A (Named, $N=\StratumACount$, \StratumAPct)}, where issue text explicitly names the gold function, method, or qualified class identifier; (2)~\textbf{Stratum~B (Traceback, $N=\StratumBCount$, \StratumBPct)}, where issue text includes a traceback or explicit file path pointing to the gold source file, but omits the function name; and (3)~\textbf{Stratum~C (Un-Named, $N=\StratumCCount$, \StratumCPct)}, where issue text contains neither the function name nor a traceback pointing to the target file. Strata are annotated via a deterministic regex extraction pipeline (\texttt{perron.analysis.strata}), validated by manual spot-check audit across 50 randomly sampled tasks with 100\% agreement, released in \texttt{swebench-strata-annotations} (CC0-1.0).

\subsection{Hash-Committed Protocol}
The study operates under two hash-committed protocol locks:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Retrieval Protocol Lock}: Frozen and publicly pushed at Git commit \href{https://github.com/yvliet/perron/commit/6908e78}{\texttt{6908e78}} on October 5, 2026 (protocol SHA-256: \texttt{89416e40\dots}; split SHA-256: \texttt{95c7ef3c\dots}).
    \item \textbf{Gemma 4 Pointwise Protocol Lock}: Frozen in two cryptographic stages (\path{benchmarks/protocol/gemma4_protocol_v1.yaml}, raw SHA-256: \texttt{96af1621\dots}; Stage~2 lock \path{gemma4_lock_v1.json}, raw SHA-256: \texttt{dbbf2920\dots}) under Gate~G0 commit \href{https://github.com/yvliet/perron/commit/29e0066}{\texttt{29e0066}} on October 6, 2026.
\end{enumerate}

\subsection{Candidate Pools and Matched-Control Arms}
Candidate pools are generated per task, matched to size $M_t = 10 + \min(|E_t|, 40) \in [10, 50]$ (mean $24.5$, median $22.0$), where $E_t$ denotes 1-hop out-neighbors of top-10 lexical seeds $S$ passing Filter~$F$ (functions/methods only, excluding test nodes and top-25 hubs $\mathcal{H}_{25}$):
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{B0 (Unscored BM25)}: Lexical candidates in native Okapi BM25 score order.
    \item \textbf{A1 (Seeds Only)}: Top-10 lexical seeds $S$ ($M=10$).
    \item \textbf{A2 (Depth-Matched BM25)}: $S$ followed by the next BM25 candidates passing Filter~$F$ up to $M_t$.
    \item \textbf{A3 (Same-File Control)}: $S$ followed by symbols in seed files passing Filter~$F$ up to $M_t$.
    \item \textbf{A4 (Graph 1-Hop Expansion)}: $S$ followed by $E_t$ ordered by adjacency $a(u) = \sum_{s \in S} p_0(s) T_{su}$.
    \item \textbf{A5 (Null Graph Control)}: Degree-preserving relation-stratified null graph replicate up to $M_t$.
    \item \textbf{A6 (Perron Diffusion Pool)}: Candidates ordered by Perron specificity scores up to $M_t$.
\end{itemize}

\paragraph{Mechanism Explaining Pool Recall vs.\ Reachability (201 vs.\ 199 Tasks)}
A4 achieves candidate pool oracle recall on 201/344 tasks (58.4\%), whereas unweighted 1-hop BFS reachability reaches 199/344 tasks (57.8\%). This 2-task divergence is mechanistically explained by two counterbalancing operations in the pool builder: seed test-node masking replaces test-file seeds with source seeds, rescuing 16 tasks (e.g., \texttt{sympy-13372}), while Filter~$F$ degree-capping and hub pruning drop 14 tasks (e.g., \texttt{sphinx-7590}), yielding a net difference of $+2$ tasks ($199 + 16 - 14 = 201$).

\subsection{Pointwise Gemma 4 Scorer}
Each candidate symbol is formatted into a prompt context averaging 423.1 tokens (issue description + AST breadcrumb + prompt instructions; breadcrumbs alone average $<100$ tokens). A frozen \texttt{gemma-4-e2b-it} model (FP16, thinking disabled) scores each candidate in a single forward pass: $s(t, v) = \text{logsumexp}(z[Y]) - \text{logsumexp}(z[N])$ on prompt variant P0, chosen on disjoint development data ($N=100$). The evaluation required 19,298 forward passes.

\subsection{Statistical Analysis}
A localization hit (Function Acc@$k$) is scored as 1.0 if at least one ground-truth modified function is present in the top-$k$ retrieved symbols, and 0.0 otherwise. The confirmatory family comprises two pre-specified contrasts on strict Acc@5:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{PC1}: $A_4 - A_2$ (Graph 1-hop vs.\ Depth-matched BM25).
    \item \textbf{PC2}: $A_4 - A_3$ (Graph 1-hop vs.\ Same-file matched).
\end{itemize}
Contrasts are evaluated using exact two-sided McNemar tests with step-down Holm--Bonferroni correction over family $\alpha=0.05$. Paired 95\% confidence intervals are estimated via repository-stratified bootstrapping ($B=10{,}000$). Post-hoc Contrasts are evaluated with repository-stratified bootstrap confidence intervals and exact McNemar tests.

\subsection{Reachability vs.\ Ranking Dynamics}
Top-10 lexical seeds directly cover 50.9\% (175/344) of gold functions. Expanding along code graph edges yields 57.8\% 1-hop reachability (199/344, median $|N_1|=27$) and 66.9\% 2-hop reachability (230/344, median $|N_2|=324$). Crucially, same-file containment also reaches 66.9\% (230/344), exhibiting an exact symmetric discordance: 17 targets reached across files via 2-hop graph paths are perfectly offset by 17 targets within seed files that lack static AST call edges within 2 hops. Degree-preserving null-graph controls reach 63.8\% 2-hop reachability (+3.02 pp difference over empirical graphs, 95\% CI [$-$0.42, +6.41], $p=0.083$). Topological reachability gains are modest and driven primarily by degree sequence rather than high-order semantic organization.

\paragraph{Confirmatory Findings}
Graph 1-hop expansion (A4) reaches 47.1\% Acc@5 compared to 45.1\% for depth-matched BM25 (A2, $\Delta = +2.03$ pp, 95\% CI [$-$0.29, +4.36], Holm $p=0.287$) and 45.6\% for same-file matching (A3, $\Delta = +1.45$ pp, 95\% CI [$-$0.58, +3.78], Holm $p=0.302$). Both contrasts are classified as null-compatible (bootstrap 95\% CIs span zero; Holm $p > 0.05$). The primary contrast (PC1) rules out gains larger than $+4.4$ pp ($15$ tasks) over depth-matched lexical reranking.

\paragraph{Candidate Pool Ceiling Parity}
Candidate pool oracle recall is identical: 58.4\% (201/344) for both graph expansion ($A_4$) and depth BM25 ($A_2$). Across discordant tasks, $n_{10}=18$ and $n_{01}=18$ (two-sided McNemar $p=1.0000$). With 36 discordant pairs, the 95\% CI on the recall difference is approximately $\pm 3.4$ pp. Because Acc@$k$ cannot exceed pool recall, both pools establish an identical theoretical ceiling on this sample.

\paragraph{Exploratory Comparisons}
Comparing graph expansion (A4) directly to seed reranking (A1, 46.2\% Acc@5) yields a net gain of only 3 tasks ($\Delta = +0.87$ pp, $n_{10}=7, n_{01}=4, p=0.549$). Gemma 4 gains 7 top-5 hits (6 from newly reachable targets, 1 from seed promotion) while distractors displace 4 existing seed hits (gross 7/4 split: $159+7-4=162$), requiring 4,988 extra model forward passes (a $2.45\times$ compute increase over seeds). Comparing A4 to the degree-preserving null graph (A5, 45.9\% Acc@5) yields $\Delta = +1.16$ pp (95\% CI [$-$0.58, +2.91], $n_{10}=7, n_{01}=3, p=0.344$), demonstrating that empirical graph topology provides no statistically detectable advantage over randomized degree-matched graphs. Similarly, comparing A4 to the Perron diffusion pool (A6, 45.6\% Acc@5) yields $\Delta = +1.45$ pp (95\% CI [+0.00, +3.20], $n_{10}=7, n_{01}=2, p=0.180$). Unscored BM25 (B0) preserves nominally higher MRR@50 (0.3439 vs.\ 0.3409) and top-1 accuracy (25.3\% vs.\ 24.7\%) than A4. In Leave-Django-Out jackknife cross-validation ($N=230$), candidate pool parity holds (57.1\% vs.\ 57.1\%, $p=1.0000$) and reranked Acc@5 yields $\Delta(A_4 - A_2) = +2.17$ pp ($p=0.227$).

\paragraph{Model Sensitivity and Positive Controls}
To test whether the flatline reflects an insensitive scorer rather than graph retrieval limits, I evaluated within-pool discrimination and rank fusion directly from \texttt{scores.parquet}. Across all 176 tasks where gold targets are present in candidate pools, Gemma~4 log-odds scores separate gold targets from distractors with an ROC-AUC of \textbf{0.718} (95\% CI [0.682, 0.754]), confirming genuine discriminative ability above chance (0.50). Furthermore, Reciprocal Rank Fusion (RRF, $k_{\text{rrf}}=60$) combining BM25 prior rank with Gemma log-odds score reaches \textbf{46.51\%} Acc@5 (160/344), outperforming both raw BM25 (44.77\%) and pure Gemma reranking (46.22\%). This demonstrates that the empirical plateau is driven by independent pointwise calibration noise across expanded candidate pools rather than model blindness.

\paragraph{Direct Distractor Accounting}

Expanding candidate pools adds newly reachable targets without increasing per-distractor confusion, but newly appended targets enter too far down the tail under pointwise scoring to convert into localization gains.

\subsection{Diffusion Diagnostics and Continuous Dose-Response Surface (Post-Hoc)}
\label{sec:lite_diagnostics}

\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]

\label{sec:threats}
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Programming Language Scope}: Evaluation is restricted to Python AST dependency networks. While directed multigraph diffusion is language-agnostic, static call graphs miss dynamic runtime dispatch, reflection (\texttt{getattr}), and monkey-patching.
    \item \textbf{Model Capacity and Prompting}: Findings are derived from one compact model (\texttt{gemma-4-e2b-it}) with pointwise scoring. Within-pool ROC-AUC of Gemma scores separating gold from distractors is 0.718 across the 176 recalled tasks, showing genuine discriminative ability above chance (0.50). Reciprocal Rank Fusion (RRF) fusing BM25 rank and Gemma score reaches 46.51\% (160/344), outperforming both raw BM25 (44.77\%) and pure Gemma reranking (46.22\%). However, independent pointwise scoring penalizes pool breadth; evaluating listwise scoring prompts or scaled models remains a key direction.
    \item \textbf{Candidate Pool Bounds}: Pools evaluate 1-hop expansion capped at 50 candidates ($M_t \le 50$). Multi-hop expansion reaches 66.9\% oracle recall but introduces hundreds of distractors.
    \item \textbf{Task Scope}: Restricted to $N=344$ function-level tasks on SWE-bench Verified. Patch generation and full test execution were not evaluated.
    \item \textbf{Statistical Power}: With realized discordance counts, the 95\% CI on PC1 admits true gains up to $+4.36$ pp. The finding is that gains are not demonstrated and large effects are ruled out, not that true effect is strictly zero.
\end{enumerate}

\label{sec:ecosystem}
To support reproducible research, Perron is released as an open-source software and evaluation ecosystem:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{\path{scores.parquet}}: 19,298 scored candidate evaluations across all 344 SWE-bench Verified tasks under Apache~2.0 (\url{https://github.com/yvliet/perron}).

\section{Conclusion}
\label{sec:conclusion}
On SWE-bench Verified, call-graph 1-hop expansion does not demonstrate a statistically detectable advantage over matched lexical pools under a frozen Gemma 4 scorer, nor does it expand candidate reachability beyond lexical depth. While graph expansion adds 7.3 pp of candidate pool recall over seeds alone, the small model converts only $\sim 1$ pp of it into top-5 accuracy. Matched pool truncation curves show that expanding candidate pool breadth under pointwise scoring yields flat or declining localization, consistent with distractor accumulation; in un-named defect tasks, neither expansion beats seeds alone or unscored BM25. Upstream boundary loss ($41.6$ pp) exceeds downstream compaction loss ($11.3$ pp) by a factor of $3.68\times$ at $k=5$ ($1.2\times$ at $k=1$, $6.8\times$ at $k=10$). While point estimates nominally favor graph expansion (+0.87 to +2.03 pp), gains are statistically undetectable in 344 tasks and do not justify a $2.45\times$ compute increase ($4,988$ extra forward passes over seeds; $5\times$ pool cap). For local developer agents under tight compute budgets, retrieval engineering is more safely directed toward high-precision first-stage lexical retrieval and compact AST breadcrumb packing; exploring whether listwise reranking architectures can overcome distractor accumulation remains a key direction for future research.

\section{Linear Algebraic Formulations and Theoretical Proofs}
\label{app:spectral_proofs}

\subsection{Brauer Rank-1 Spectral Bound and Second Eigenvalue}
\label{prop:spectral_gap_proof}
Let $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ be a directed multigraph and $T \in \mathbb{R}^{|\mathcal{V}| \times |\mathcal{V}|}$ be the row-substochastic transition matrix defined in Equation~\ref{eq:stochastic_matrix}. Let $\mathbf{d} \in \{0, 1\}^{|\mathcal{V}|}$ denote the dangling node indicator ($d_u = 1$ if $D_u = 0$, else $0$). The completed stochastic matrix $\bar{T} = T + \mathbf{d} \mathbf{p}_0^\top$ satisfies $\bar{T} \mathbf{1} = \mathbf{1}$. The Google transition operator with damping factor $\beta \in (0, 1)$ is formulated as:
\begin{equation}
M = \beta \bar{T} + (1 - \beta) \mathbf{1} \mathbf{p}_0^\top.
\end{equation}

By the Brauer rank-1 perturbation theorem applied to Markov transition matrices~\cite{haveliwala2003second}:
Let $A$ be an $n \times n$ matrix with eigenvalues $\lambda_1, \lambda_2, \dots, \lambda_n$, and let $\mathbf{x}_1$ be the right eigenvector associated with $\lambda_1$. For any vector $\mathbf{y} \in \mathbb{R}^n$, the perturbed matrix $A + \mathbf{x}_1 \mathbf{y}^\top$ has eigenvalues $\lambda_1 + \mathbf{y}^\top \mathbf{x}_1, \lambda_2, \dots, \lambda_n$.

In our formulation, setting $A = \beta \bar{T}$ yields eigenvalues $\beta \lambda_1(\bar{T}), \beta \lambda_2(\bar{T}), \dots, \beta \lambda_n(\bar{T})$. Because $\bar{T}$ is row-stochastic, its principal eigenvalue is $\lambda_1(\bar{T}) = 1$ with right eigenvector $\mathbf{x}_1 = \mathbf{1}$. Setting $\mathbf{y} = (1 - \beta) \mathbf{p}_0$ gives:
\begin{equation}
M = \beta \bar{T} + \mathbf{1} ((1 - \beta) \mathbf{p}_0)^\top.
\end{equation}
The principal eigenvalue of $M$ becomes:
\begin{equation}
\lambda_1(M) = \beta \lambda_1(\bar{T}) + ((1 - \beta) \mathbf{p}_0)^\top \mathbf{1} = \beta + (1 - \beta) = 1.
\end{equation}
All remaining eigenvalues satisfy:
\begin{equation}
\lambda_i(M) = \beta \lambda_i(\bar{T}), \quad \forall i \ge 2.
\end{equation}
Because $\bar{T}$ is row-stochastic, the Gershgorin circle theorem guarantees $|\lambda_i(\bar{T})| \le 1$ for all $i$. Therefore, the second-largest eigenvalue is strictly bounded:
\begin{equation}
|\lambda_2(M)| \le \beta \cdot 1.0 = \beta.
\end{equation}
For $\beta = 0.85$, the spectral gap is uniformly lower-bounded:
\begin{equation}
1 - |\lambda_2(M)| \ge 1 - \beta = 0.15,
\end{equation}
guaranteeing geometric convergence $\mathcal{O}(\beta^t)$ in $L_1$ total variation distance regardless of graph density or disconnected components.

\subsection{Barycentric Linearity and Basis Warping Bounds}
\label{prop:convex_hull_proof}
Following Jeh and Widom~\cite{jeh2003scaling}, let $\mathbf{p}_0 = \sum_{i=1}^K w_i \mathbf{e}_{s_i}$ be any convex combination of query seed nodes with $w_i \ge 0$ and $\sum w_i = 1.0$. The stationary distribution $\boldsymbol{\pi}(\mathbf{p}_0)$ lies in the convex hull of the basis distributions:
\begin{equation}
\boldsymbol{\pi}(\mathbf{p}_0) = \sum_{i=1}^K \tilde{w}_i \boldsymbol{\pi}(\mathbf{e}_{s_i}) \in \operatorname{conv}\left(\{\boldsymbol{\pi}(\mathbf{e}_{s_i})\}_{i=1}^K\right), \quad \tilde{w}_i = \frac{w_i m_i}{\mathbf{w}^\top \mathbf{m}},
\end{equation}
where basis mass satisfies $m_i = \|(1-\beta) \mathbf{e}_{s_i} (I - \beta T)^{-1}\|_1 \in [1-\beta, 1.0]$. The maximum coordinate warping ratio is bounded by:
\begin{equation}
\frac{\max_i m_i}{\min_j m_j} \le \frac{1}{1 - \beta} = \frac{1}{0.15} \approx 6.67.
\end{equation}

\subsection{Markov Renewal Equivalence to Normalized Leaky Resolvents}
\label{prop:renewal_proof}
In the closed Markov chain $M$, dangling nodes restart according to the query teleport distribution $\mathbf{p}_0$. By the regenerative renewal property of Markov chains with state-independent resets, the stationary probability $\boldsymbol{\pi}_{\text{closed}}$ of the closed chain $M$ is algebraically identical to the normalized leaky resolvent vector:
\begin{equation}
\boldsymbol{\pi}_{\text{leaky}} = \frac{(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}}{\|(1-\beta)\mathbf{p}_0 (I - \beta T)^{-1}\|_1}.
\end{equation}
Across all 12 canonical SWE-bench repositories, the maximum numerical discrepancy satisfies:
\begin{equation}
\|\boldsymbol{\pi}_{\text{closed}} - \boldsymbol{\pi}_{\text{leaky}}\|_1 = 1.68 \times 10^{-8} < 2 \times 10^{-8},
\end{equation}
confirming exact algebraic equivalence.

\subsection{Asymptotic Pointwise Mutual Information (PMI) Decomposition}
\label{prop:pmi_proof}
For any code symbol $v$ with positive query support, the log-transformed Specificity score satisfies:
\begin{equation}
\ln \text{Specificity}(v) = (1 - \gamma) \ln \pi_{\text{query}}(v) + \gamma \text{PMI}(v; q) - \gamma \ln\left(1 + \frac{\epsilon}{\pi_{\text{global}}(v)}\right).
\end{equation}
When $\pi_{\text{global}}(v) \gg \epsilon$, the residual vanishes, yielding a convex interpolation between raw reachability ($\gamma=0$) and surprise ($\gamma=1$), where the sub-linear exponent $\gamma = 0.70$ acts as a structural Inverse Document Frequency (IDF) discount.

\subsection{Neumann Series Expansion and Sink Absorption}
\label{prop:neumann_proof}
The Neumann series expansion of Personalized PageRank illustrates why pre-walk scaling cannot prevent sink absorption on software dependency graphs:
\begin{equation}
\boldsymbol{\pi} = (1-\beta)\sum_{t=0}^{\infty}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t}, \quad \Big\|\boldsymbol{\pi} - (1-\beta)\sum_{t=0}^{m}\beta^{t}\,\mathbf{p}_0'^{\top}\bar{T}^{t}\Big\|_1 = \beta^{m+1}.
\end{equation}
Walks of length $t \ge 3$ carry approximately 61\% of total diffusion mass ($\beta^3 \approx 0.614$ at $\beta=0.85$). Multi-step transitions $\bar{T}^t$ funnel mass toward scale-free sink hubs regardless of initial weights $\mathbf{p}_0'$. Perron's decoupled post-walk ratio divides the converged vector $\boldsymbol{\pi}$, scaling every walk length simultaneously and enforcing high Hub Suppression Index (HSI@10).

\section{Continuous Dose-Response Surface Across 186 Prior Configurations}
\label{app:dose_response}
To evaluate the entropy collapse hypothesis systematically, a continuous resolvent basis benchmark was evaluated across the 344 Verified evaluation tasks (63,984 SpMM solves) across four parametric families:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Softmax Family}: $\mathbf{p}_0(i) \propto \exp(s_i / \tau)$ for top-$K$ seeds ($\tau \in [0.05, 1.0]$).
    \item \textbf{Power Family}: $\mathbf{p}_0(i) \propto s_i^p$ ($p \in [0.5, 4.0]$).
    \item \textbf{Linear Truncated}: $\mathbf{p}_0(i) \propto s_i$ over top-$K$ seeds ($K \in [5, 100]$).
    \item \textbf{Rank-Zeta Family}: $\mathbf{p}_0(i) \propto i^{-\alpha}$ ($\alpha \in [0.2, 2.0]$).
\end{enumerate}
Across all 186 configurations, Function Acc@10 exhibits a statistically significant quadratic relationship with prior effective support $n_{\text{eff}} = \exp(H(\mathbf{p}_0))$ ($p < 0.001$, binomial GLMM $R^2 = 0.197$), peaking near $n_{\text{eff}}^* \approx 8.8$ at 50.9\%, which exactly ties Okapi BM25 (50.9\%).

\section{Lexical Accessibility Annotation Protocol}
\label{app:strata_protocol}
Tasks are categorized into three mutually exclusive strata:
\begin{itemize}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{Stratum A (Named, $N=208$, 60.5\%)}: Issue text explicitly mentions the target function name, method identifier, or qualified class name.
    \item \textbf{Stratum B (Traceback, $N=5$, 1.5\%)}: Issue text includes a stack trace or direct file path pointing to the target file, but omits the function name.
    \item \textbf{Stratum C (Un-Named, $N=131$, 38.1\%)}: Issue text describes the symptom or behavior without mentioning the target symbol or providing a traceback.
\end{itemize}
Annotation was validated via an independent 50-task spot check with 100\% inter-rater agreement and is released in \texttt{swebench-strata-annotations} (CC0-1.0).
