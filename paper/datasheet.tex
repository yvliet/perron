\section{Datasheet for Datasets: SWE-bench Strata and Repository Multigraphs}
\label{app:datasheet}

Following the documentation standard of Gebru et al.~\cite{gebru2021datasheets}, this datasheet provides formal documentation for the open research assets released with Perron, covering task stratification annotations, repository-level AST multigraphs, and scored model evaluation telemetry.

\subsection{Motivation}
\textbf{Purpose}: The dataset was constructed to evaluate the empirical boundaries of static graph expansion, distractor dilution, and test-time reasoning in repository-level code intelligence, addressing the lack of structural task stratification in existing software engineering benchmarks.
\textbf{Author and Funding}: Sultan Haikal (GitHub: \texttt{@yvliet}). The dataset was developed independently for the Google DeepMind Gemma~4 Developer Agent competition (Track 2: Research Monograph and Resource Track). Model inference was executed on Kaggle dual Nvidia Tesla T4 GPU environments.

\subsection{Composition}
The dataset comprises three primary components:
\begin{enumerate}[noitemsep,topsep=2pt,parsep=0pt,partopsep=0pt]
    \item \textbf{SWE-bench Strata Annotations} (\path{data/swebench_strata_annotations.jsonl}): 800 evaluation records across 707 unique task instances (300 in SWE-bench Lite, 500 in SWE-bench Verified, with 93 overlapping pairs). Each instance is classified into Stratum A (\texttt{A\_named}), Stratum B (\texttt{B\_trace}), or Stratum C (\texttt{C\_unnamed}). The 500 SWE-bench Verified tasks follow a strict CONSORT partition: 344 callable evaluated tasks, 93 exploratory Lite overlap, 56 file-preimage drift, and 7 module-level non-callable edits ($344 + 93 + 56 + 7 = 500$).
    \item \textbf{Repository AST Multigraphs (Two-Tier Design)}:
    \begin{itemize}[noitemsep,topsep=1pt,parsep=0pt,partopsep=0pt]
        \item \textbf{Per-Task Base-Commit Multigraphs} (\path{data_release/graphs/}, $N=300$ Lite tasks): CSR matrices and symbol tables extracted from checkouts at each task's immutable git base commit for community benchmarking.
        \item \textbf{Single-Snapshot Repository Multigraphs} (\path{artifacts/swebench_graphs/}, 12 repositories): monolithic CSR graphs ($109{,}240$ nodes, $341{,}892$ directed edges) indexed at a frozen snapshot to benchmark static offline caching on SWE-bench Verified ($N=344$).
    \end{itemize}
    \item \textbf{Scored Model Telemetry} (\path{scores.parquet}, \path{gemma4_e4b_scores.parquet}): 19{,}298 candidate evaluations from Gemma~4 E2B and 8{,}113 candidate evaluations from Gemma~4 E4B across SWE-bench Verified.
\end{enumerate}

\subsection{Collection Process}
For SWE-bench Lite ($N=300$, \path{data_release/graphs/}), repository trees were checked out at each task's exact historical git \texttt{base\_commit} and parsed via Python's standard \texttt{ast} module. For the confirmatory SWE-bench Verified evaluation ($N=344$, \path{artifacts/swebench_graphs/}), 12 repositories were indexed from a single frozen release snapshot to evaluate static offline agent caching without per-task re-indexing. Tasks whose target files were absent at the frozen snapshot commit ($N=56$, \texttt{FILE\_ABSENT\_PREIMAGE\_DRIFT}) were audited via historical \texttt{base\_commit} checkouts, confirming 100\% CPython 3 AST parseability (68 files, 3{,}827 symbols) and proving that exclusions were an operational artifact of single-snapshot caching rather than parser failure. Strata classifications were assigned via deterministic regular expression matching with strict identifier boundaries (\path{perron/analysis/strata.py}). Telemetry was captured during offline inference in FP16 precision.

\subsection{Preprocessing, Cleaning, and Classifier-vs-Human Validation Audit}
File paths were normalized to POSIX standards. Missing distances are encoded as JSON null in compliance with RFC~8259. To verify that the deterministic regex heuristic represents genuine linguistic ground truth, an independent human validation audit was conducted on a stratified random sample of $N=\StrataSampleSize$ tasks ($N_A=45, N_B=15, N_C=40$, seed=42) against raw GitHub issue statements without access to regex tags.
The audit demonstrated an observed concordance of \StrataHumanConcordance\ (\StrataConcordantCount/\StrataSampleSize\ tasks) and an empirical Cohen's $\kappa = \StrataCohenKappa$ (95\% CI $[0.849, 0.988]$, chance agreement $p_e = \StrataChancePe$). Under Landis and Koch criteria, $\kappa = \StrataCohenKappa$ reflects almost perfect agreement, confirming that the automated heuristic reliably mirrors human expert classification.

\subsection{Uses}
The dataset is intended for benchmarking repository-level code search, graph neural networks for program analysis, and test-time reasoning architectures. Researchers should preserve the pre-specified confirmatory split ($N=344$ callable Verified) to prevent selection conditioning.
